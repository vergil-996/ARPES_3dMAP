# BandScope 科研图片导出：调研、实施计划与 Agent 提示词

初次调研：2026-09-21；完善日期：2026-09-22；方案版本：v2。范围：当前代码检查、截图样式设计、交互约定及实施验收；本次只更新计划，不修改应用代码。文献配图原图访问受限，文献结论以正文和图注为依据，不声称逐像素复刻其版式。九个样式及其具体参数是本项目的设计建议，不是期刊官方模板。

## 1. 建议结论

把“截图”升级为独立的科研图片导出流程：**识别左侧当前视图 → 展示该视图的多种样式预览 → 选择样式 → 点击截图输出**。

模板就是样式。同一个 3D 视图应有多种 3D 截图样式，同一个 2D 视图应有多种 2D 截图样式，同一个 1D 视图应有多种曲线截图样式。视图类型由左侧当前页面决定，不是供用户选择的模板。核心交付是每类视图内部可直观看到差别的样式库。

模板只管理输出的排版和表现。选择模板、修改色条、打开预览、保存或取消，都不能修改左侧视图及其数据、相机、色阶锁定和页面状态。保留顶部“截图”入口，增加模板选择及“预览与设置”；配置一次后，点击“截图”即可按当前模板生成文件。

第一版覆盖已有的 3D、2D、1D、曲线比较和瀑布图。多面板组图、跨时间批量导出可后续开发；第一版不新增差分计算、能量标定或任意注释编辑器。

### 1.1 必须明确的边界

| 内容 | 样式能否改变 | 约定 |
|---|---|---|
| 画布背景、字体、字号、线宽、边框、图例位置、色条位置和刻度排版、留白 | 可以 | 仅作用于独立导出场景 |
| 曲线的类别颜色/线型 | 有条件 | 默认继承身份映射；白底不可读时使用确定的深色替代，并同步图例，样式之间不重新分配曲线身份 |
| 标题、面板编号、已有科学标注的显示 | 可以 | 只改变是否显示和布局，不自动编造物理条件 |
| 数据值、ROI/裁剪范围、帧、积分范围、E 翻转、坐标数值及其顺序 | 不可以 | 从同一固定快照读取 |
| 色图、clim、gamma、归一化、对数/线性坐标、透明度函数、插值方法 | 样式不改变 | 继承当前正式科学显示；不在样式面板中新增分析或强度调整入口 |
| 3D 相机方向、投影类型、科学对象变换 | 不可以 | 继承当前正式视图；排版需要的留白在独立画布中处理 |

“科研级”在本计划中指：数据与标签正确、图中没有软件 UI、最终尺寸下可读、文件质量符合所选参数。不能靠样式自动完成物理标定或保证满足任意期刊的全部要求。

### 1.2 第一版完成定义

必须交付九种真实可选样式、同数据预览卡片、独立正式导出、按视图族记忆偏好，以及第 7 节的数据和状态隔离验收。所有图型支持 PNG；1D/2D 同时支持 PDF（热图可为栅格，文字和曲线保留矢量）。TIFF、SVG、透明画布及自定义命名样式属于后续增强，不影响九样式主流程完成；不得以仅完成独立渲染器代替样式库交付。

仓库 `docs/images/main-3d-plot.png` 确实包含右上角状态条。当前 `on_screenshot()` 的 3D 分支调用 VTK 截图，单凭代码不能断言它一定会包含兄弟 Qt 覆盖层；该示例也可能来自窗口捕获。实现时应实际复现各分支，不能把示例图片当作当前所有导出路径的执行证据。

## 3. 文献与规范中可借鉴的做法

### 3.1 ARPES 图应按科学任务区分

Lv、Qian、Ding 的综述 Fig. 4 将费米面强度图、能量—动量色散图、曲率处理图及计算能带分别展示。其图注明确交代切面、费米能和动量位置。可借鉴的是：导出适配器应识别当前结果的科学含义，保留切片条件和处理类型，不能把所有结果都叫 Intensity，也不能给任意等能切片自动冠以“费米面”。同一结果的各个样式使用相同科学标签。[文献及 Fig. 4](https://www.nature.com/articles/s42254-019-0088-5/figures/4)

Dong 等的 WSe₂/graphene trARPES 工作，Fig. 1b 展示三维能量—动量数据；Fig. 2a–d 展示不同延迟的能量—动量切片，Fig. 2e 标明能量和时间积分条件；Fig. 3 包含 EDC 与差分谱。这很适合 BandScope 的现有结果类型。模板应能容纳切片、时间、积分区间和少量科学标注，并保留未来多面板扩展位置。论文还明确说明部分能带图使用了对比度增强；导出不能悄悄新增这种处理。[论文 Fig. 1–3 及正文](https://www.nature.com/articles/s41467-023-40815-8)

### 3.2 色彩必须表达数值含义

Crameri 等讨论了不均匀色图带来的视觉失真及色觉可访问性问题。普通强度适合感知较均匀的顺序色图，有物理零点的有符号差分数据可使用以零为中心的发散色图；不能因为是“二阶导”就机械地套红蓝。这些是科学配色的参考原则。本次截图样式始终继承主视图已选色图和映射；用户若需要调整强度色图，应在主视图完成后更新预览。[The misuse of colour in science communication](https://www.nature.com/articles/s41467-020-19160-7)

### 3.3 出版质量取决于最终尺寸

Nature 官方指南给出单栏 89 mm、双栏 183 mm 的参考宽度，普通文字 5–7 pt、最终线宽 0.25–1 pt，并要求尽可能保留可编辑文字和线条。可提供这些尺寸预设，但不能称它们是所有期刊通用要求。PNG 的 600 dpi 是本项目建议默认值，不是统一投稿标准。[Nature final submission](https://www.nature.com/nature/for-authors/final-submission)

建议九个样式共用的默认参数：白色画布、7 pt 轴名与普通文字、6 pt 刻度/图例、0.6 pt 坐标轴、0.8 pt 曲线、2 pt 主刻度长度。单栏宽 89 mm，可改双栏 183 mm 或自定义；面板编号可用 8 pt 粗体。建议初始画布宽×高：3D 为 89×85 mm、2D 为 89×75 mm、1D 为 89×65 mm。宽高是独立输出参数，同组样式切换时保持不变，不能为了塞下文字偷偷扩大文件或缩小字号。

## 4. 模板与交互设计

按当前视图自动进入对应样式库。第一版建议每类三个样式，共九个预设。下面是设计起点，具体间距和字号应根据实际预览打磨；所有样式保留当前数据、轴方向、色阶和 3D 视角。样式切换改变边框、色条排布、刻度密度、字体、线条和留白，不产生另一种科学结果。

视图族来自结果的实际 `view`，不能只看页面名称或最初创建页面的功能。`3d → 3d`、`2d → 2d`、`1d/1d_comparison/waterfall → 1d`；配置页不可导出。比如某个积分页当前显示 2D 图，就展示 2D 样式。

### 左侧为 3D：同一体渲染的三种样式

| 样式 | 轴与边框 | 色条与排版 |
|---|---|---|
| 3D · 极简（`3d_minimal`，默认） | 白底黑字，保留必要轴线/轴名/刻度，无完整盒框，无网格 | 右侧窄竖色条，无色条黑框，目标 3 个数值刻度，宽松留白 |
| 3D · 盒框（`3d_boxed`） | 白底黑字，细黑完整包围盒，无背部网格 | 右侧竖色条，0.4 pt 轮廓，目标 5 个数值刻度，轴标签与盒框对齐 |
| 3D · 横条紧凑（`3d_horizontal`） | 白底黑字，简化轴框，无网格，保留必要刻度 | 下方短横色条，目标 3 个数值刻度，减少右侧空白，图主体居中 |

### 左侧为 2D：同一强度图的三种样式

| 样式 | 轴与边框 | 色条与排版 |
|---|---|---|
| 2D · 标准框线（`2d_boxed`，默认） | 白色画布，四边细黑坐标框，刻度向内，无网格 | 右侧竖色条，目标 5 个数值刻度，标准留白 |
| 2D · 顶部横条（`2d_topbar`） | 白色画布，四边细框，较少主刻度 | 上方短横色条，目标 3 个数值刻度，可选面板编号，紧凑留白 |
| 2D · 开放轴线（`2d_open`） | 白色画布，仅左下轴线，刻度向外，无网格 | 右侧窄色条，无色条轮廓，目标 3 个数值刻度，较疏朗排版 |

### 左侧为 1D：同一条或同一组曲线的三种样式

| 样式 | 轴与线条 | 图例与排版 |
|---|---|---|
| 1D · 简洁开放（`1d_open`，默认） | 白底，仅左下轴，刻度向外，统一曲线线宽，无网格 | 无边框图例，放在不遮挡曲线的空白区域；无合适位置则放图外 |
| 1D · 四边框线（`1d_boxed`） | 白底，四边细黑框，刻度向内，统一线宽，无网格 | 无边框图例，标准留白，可选顶部/右侧刻度但不重复数字 |
| 1D · 紧凑排版（`1d_compact`） | 白底，左下轴，精简主刻度，统一线宽，无网格 | 图例放上方图外，减少多余留白，可选面板编号 |

单曲线、比较曲线和瀑布图复用 1D 样式库，保留各自已有曲线数、顺序、归一化和偏移；不能把“比较曲线”或“瀑布图”本身当作一种样式。通常 1D 没有色条，不应强行添加；已有用连续变量编码曲线颜色的结果才保留相应科学色标。

1D 的图例策略按子类型适配：单曲线没有明确标签时默认不造图例；比较曲线保留每条曲线身份及基准标识；瀑布图保留原有动量/序列标签及偏移方向，不为每条线自动生成冗长图例。过长标签可以换行，不能省略成改变含义的文本。

### 4.1 共用布局规则

- 色条初始厚度建议 2.2 mm、与数据区间隔 2.5 mm；横色条建议占数据区宽度的 55%–70%。具体尺寸由最终画布和文字外接框约束，不能只固定归一化屏幕坐标。
- 先确定固定画布，再为刻度、轴名、色条标题、图例和面板号预留位置。按实际字体测量文字外接框；碰撞时优先移动标签/图例、减少重复刻度或增加内部间隔，不能裁掉内容或无提示缩小到不可读字号。
- 同组预览卡片保持相同目标画布尺寸、相同数据和相同主刻度数值依据，展示真实版式差别，不拉伸图片填满卡片。选中大图提供“适应窗口 / 100%像素”查看；不声称屏幕显示等于真实印刷毫米尺寸。
- 保留主视图有效的 2D/1D 可见坐标范围、log/linear 状态、轴方向和数据比例规则。已有 equal aspect 时继续等比例并用留白适配；已有 auto aspect 时按冻结的数据显示区比例等比放置。样式不自动改成 equal，不为紧凑改变数据范围；如果科学比例存在问题，应在主视图功能中另行修正。
- 3D 主体使用固定的相机方向与投影；色条改变位置后，为场景保留一致比例的视口并等比放置，不通过 reset_camera 偷偷改变取景。必要时留白，不能拉伸体渲染或自动裁掉边缘信号。
- “目标 3/5 个刻度”是排版上限的偏好，不强制产生重复、越界或虚假的数值；最终刻度由冻结映射与可用空间决定。

色条刻度密度、数值/Low–High、边框、字体等可在选定样式后微调，并可恢复该样式默认值。第一版只保存视图族的最近样式和各样式的局部覆盖参数；自定义命名样式后续增加。Low/High 是可选定性标注，不代表跨图可比性。选择另一种样式时不把上一个样式的横色条等覆盖参数自动带过去，避免三个样式最终变得一样。

交互流程：

1. 顶部提供 `截图` 主按钮及 `截图样式` 入口，可用同一个分体按钮减少工具栏占用。主按钮保留快捷键，直接使用当前视图族已确认的样式并选择保存路径；首次也有上述默认样式，不强制配置。按钮提示中显示当前样式名，例如“截图：3D · 极简”。
2. 样式选择面板按当前视图展示三个预览卡片，例如“当前：3D 视图”，下方并列“极简 / 盒框 / 横条紧凑”。卡片使用同一份当前数据生成，让用户能直接比较外观；选中卡片后提供大图预览。附注“仅影响截图，不改变左侧视图”。
3. 先选样式即可出图，不要求用户逐项配置色条和边框。微调设置折叠展示；尺寸与格式独立设置，不与视图类型混成模板选项。
4. 预览和保存绑定同一个 snapshot、样式参数与布局引擎。卡片可采用较低输出像素数，但使用完整科学数据；不能因三种卡片各自降采样而改变峰位或映射。选中卡片后生成正式布局预览，生成期间显示状态并禁用“导出此预览”；正式预览由目标文件的同一排版结果生成。
5. 主页面数据变化时，已有预览保持原快照并显示来源页/帧；通过“更新预览”重新取快照，避免保存结果与刚看过的预览不一致。直接点击主按钮则冻结点击时的目标状态。
6. 按视图类型分别记住样式，例如 `publication_export/v1/3d/style_id`、`2d/style_id`、`1d/style_id`。主页面从 3D 切到 1D 后，下一次打开样式面板只列出 1D 样式；切回 3D 恢复此前的 3D 样式。已打开的快照预览继续绑定原视图，更新预览时才切换相应样式库。不写回图像/渲染控件设置。

### 4.2 面板操作的确定语义

| 操作 | 行为 |
|---|---|
| 点击样式卡片或微调 | 只改本次面板草稿及独立预览，不立即覆盖持久化偏好 |
| 使用此样式 | 提交该视图族的样式与覆盖参数，关闭面板；不输出图片 |
| 导出此预览 | 输出当前面板绑定的快照；文件写入成功后提交该视图族偏好，可留在面板继续比较 |
| 取消文件路径选择 / 写入失败 | 保留面板草稿供重试，不提交偏好，不改变左侧状态 |
| 取消 / 关闭面板 | 丢弃尚未提交的样式修改；先前已成功导出的文件和已提交偏好保留 |
| 恢复该样式默认值 | 仅清除当前样式草稿覆盖，不清除其他样式或输出尺寸 |
| 更新预览 | 重新冻结当前主页面科学状态，按新视图族加载其样式；不自动提交旧草稿 |

面板只打开一个实例。顶部明确展示来源页、帧/时间及科学结果类型；这些信息位于预览图片外。主页面发生变化时显示“预览来自之前的页面/帧”，不静默刷新或导出另一帧。应用必须区分“截图主按钮导出点击时状态”和“导出此预览导出预览绑定状态”，避免看见 A 却保存 B。

## 5. 必须支持的图形细节

### 色条

- 显示/隐藏；右、左、上、下；长宽、距主图间隔；标题位置；横竖方向由位置自动匹配。
- 刻度模式：真实数值、仅端点数值、Low/High、无文字。数值默认约 3–5 个好读刻度；支持自动/固定小数/科学计数法。第一版不开放手工色阶范围、新增归一化或更换 norm。
- 真实数值必须对应同一 LUT/norm/transfer function。不要把灰场滑块值机械当成视觉中点。
- 当前结果已经归一化时显示该结果的真实归一化刻度与标签；未经归一化的结果不能只把现有刻度字符串改成 0、0.5、1。非线性映射按实际 norm 放置标量刻度，不能用等距文字伪装线性色条。
- 原始计数只有来源明确时才写 counts；一般未标定强度可写 `Intensity (a.u.)`；真正归一化的数据写 `Normalized intensity`；导数图按实际计算量命名。
- 若上下限截断数据，用端点标记或导出说明表达。色条隐藏不等于取消色阶锁定。
- 3D 色条解释输入标量的颜色映射；体渲染最终像素还受透明度和视线累计影响，不应把像素亮度当作该点强度。
- 对极小值、大数量级和负数自动选择有效精度，去除无意义的负零；公共科学计数指数只显示一次且为它预留位置。常量数据不能为美观生成看似具有变化的多级真实刻度；保留既有明确的显示范围，必要时显示单个有效值。全无效数据明确提示不能生成科学图片。

### 四类边框分别控制

1. 整张画布外框：默认无。
2. 2D 坐标轴边框：无 / 左下 / 四边，线宽可调；强度图默认细四边框。
3. 色条轮廓：独立开关，默认关闭或极细。
4. 3D 包围盒与网格：分开开关；关闭盒框不应同时删除轴名和刻度。

图像内部的黑色低强度像素属于色图，不能按“去黑边”把它们删除或裁掉。

### 坐标、注释和数据真实性

- 所有模板排除运行状态、CPU/GPU 信息、工具栏、鼠标提示、交互拖拽手柄、裁剪控制框。科学 ROI 线或积分范围线可显式选择保留，不能与交互控制框混为一谈。
- 默认不显示软件自动页面标题；允许短科学标题、时间、切片值、积分区间和面板编号。科学条件从快照读，不从文件名推测。
- kx/ky 只有单位明确时才标 Å⁻¹；数据比例继承快照。改变画布尺寸时等比放置原数据显示区域，必要时保留空白，不把动量空间里的圆拉成椭圆。
- 区分 `E − E_F`、binding energy、kinetic energy 与 energy index；不得由模板自动变换符号、零点或上下方向。未知标定用索引或中性 E 标签，不编造 eV。时间单位同理。
- 支持降序坐标，避免翻转两次。首版准确支持均匀网格；遇到非均匀坐标时，仅在独立 renderer 能准确绘制真实网格且对应显示语义已定义的情况下导出，否则明确提示该网格暂不支持。不能仅用两端 extent 冒充均匀采样，不能在样式功能中悄悄重采样。后续再扩展真实非均匀网格渲染。
- 只改变图形表现，不新增去噪、锐化、平滑、对称化、背景扣除或拟合。第一版继承当前正式映射与插值，不在样式面板中提供这些处理入口。
- 标签必须来自带来源的轴描述或计算结果元数据；有坐标数组但缺单位时不猜单位。未提供 E 坐标与提供了坐标但没有 E_F 标定是两种不同状态，不能一律写成 binding energy。

## 6. 技术实施方案

建议小模块拆分，避免继续把所有逻辑加进 `refactored_app.py`。

```text
PublicationSnapshot  +  ExportStyle  +  ExportOptions
                   ↓
            PublicationRenderer
              ↙             ↘
      独立 Figure       独立 VTK 场景
              ↘             ↙
           同一布局的预览/正式文件
```

- `publication_models.py`：快照、样式注册表、输出选项及序列化版本。样式按视图族分组，每个样式具有独立 style_id 和参数，结构为 `styles[view_family][style_id]`，不能写成一个视图对应一个模板。快照包含来源页/数据版本、完整结果数据、真实坐标及单位来源、ROI、时间、处理信息、轴方向、映射、锁定范围、相机和投影参数。大数组使用稳定版本引用或必要复制；不能只 shallow-copy 字典后让底层数组继续变化，也不要复制整份 4D 数据。仅把共享数组标为只读不代表底层内容不会被其他所有者修改，需要明确版本所有权及生命周期。
- `publication_export.py`：结果 context → 快照适配与导出协调。按 `view`（3d/2d/1d/1d_comparison/waterfall）分发，不只按当前 stacked widget 下标判断。配置页和无数据状态禁用科研导出。
- `publication_renderers.py`：2D/1D 新建 Figure/Agg，不复用活动 axes，也不复制全部 artists；3D 新建 off-screen Plotter/VolumeRenderSession，复用稳定的数据和显式传入的映射。提前验证 Windows 打包版和实际驱动上的离屏渲染，不假设所有 OpenGL 操作能放进通用工作线程。
- `publication_dialog.py`：模板选择、预览和少量设置；保存前验证排版，保存失败不给成功 toast，临时资源及时释放。

文件划分是建议，不要求为每个概念再建一层抽象。最小接口应明确职责：`capture_export_request()` 在 GUI 线程冻结输入；`resolve_snapshot(request)` 获取匹配的完整结果；`render(snapshot, style, output_options)` 只生成独立产物；`save(artifact, path)` 负责可靠写入。预览与正式导出调用同一个 renderer。

### 6.1 数据契约

| 对象 | 必要字段 | 禁止包含 |
|---|---|---|
| ExportRequest | request_id、page_id、source_revision、视图族、完整页/处理参数、帧/时间区间、ROI、旋转/翻转、冻结的显示映射、样式与输出参数版本 | 供后台读取的活动 Qt 控件、会随主界面改变的参数引用 |
| PublicationSnapshot | 已解析且有完整精度标记的结果数组/曲线、轴值/单位来源、显示变换、可见范围、LUT/clim/透明度、相机和几何元数据、稳定源版本 | 活动 Figure、Axes、Plotter、camera/actor/mapper 等可变场景对象 |
| ExportStyle | style_id、view_family、样式版本、布局和排版参数、按科学身份适配的曲线表现 | 数据操作、处理强度、clim/gamma、科学 ROI、帧选择 |
| ExportOptions | width_mm、height_mm、dpi、format、文件命名和输出选项 | 主视图设置、科学计算参数 |

配置分开存储：样式及 overrides 按视图族和 style_id 记录；尺寸/DPI/格式属于输出偏好，恢复样式默认不重置它们。保存的 style_id 不存在或版本不兼容时回退到该视图族默认值；不支持当前图型的格式在 UI 中明确禁用，不暗中改后缀或把 PNG 装进其他扩展名。

### 6.2 异步快照与预览一致性

1. 截图按钮被按下或打开样式面板时，在 GUI 线程冻结当时已经提交的页面参数及其目标结果版本；未提交的文本框草稿不算一次新科学状态。若画布仍在呈现旧结果，导出面板显示“等待所选帧完整结果”，不混用旧数据和新标签。
2. 优先复用匹配的正式缓存。匹配依据至少包括 source_revision、page_id、处理/ROI/时间签名、显示变换和映射签名；全局 `_render_exact_ready` 布尔值或当前 page_id 不足以证明匹配。
3. 没有匹配结果时，独立导出请求按冻结输入计算；不能直接调用主界面的 `request_refresh()` 并假设旧 generation 会一直保留。可以复用无副作用的计算服务和数值缓存，但请求标识、取消状态及结果接收必须独立。
4. 源页面切换、关闭或加载新数据不改写既有导出。稳定数据版本能继续保留则完成原请求；不能保留则明确取消并说明原因，不降级到最新帧、旧帧或 PREVIEW。导出不能为了冻结而暂停主页面播放、切页或修改锁定按钮。
5. 每次换样式、改输出尺寸或更新快照递增 preview_revision。结果返回时核对 request_id、snapshot_id、style/options 签名及 preview_revision，过期结果丢弃。旧任务不能覆盖新预览，也不能在取消后触发保存。
6. 状态机：`等待完整结果 → 排版/渲染 → 正式预览就绪 → 写入 → 完成`，各阶段可失败或取消。不能在正式预览未就绪时保存上一版内容。状态文字显示在导出 UI，绝不画进图片。

### 6.3 渲染隔离与科学显示适配

先审计现有 `_compute_render_context()`、`_render_context_for_visual_flip()` 以及 1D 绘图路径的副作用，再抽取可复用的纯计算逻辑。`current_render_context` 当前保存于 E 翻转前，不能直接等同于屏幕显示；快照中应冻结已解析的显示变换，并只应用一次。3D 的 E 翻转已由相机处理，不能再翻体数据；1D 和瀑布图按它们现有的科学显示规则适配。

相机需要复制 position/focal point/view-up、投影类型、parallel scale/view angle、clipping range 及必要 actor 变换；只复制 camera_position 不够。3D 还需保留 data_bounds/full_shape、绝对 extent、spacing/origin、裁剪平面、正式 opacity map、scalar opacity unit distance 和完整质量策略。当前场景把轴映射到 0–200 且 ROI 保留绝对 extent，不得仅按裁剪后 shape 建一个新原点。数据缓冲区可以按不可变版本共享，camera、actor、mapper、VTK 标量包装和 transfer function 必须独立；NumPy buffer 持有至场景关闭。

已有 `log_curve` 属于 1D 家族，它可能已是 log10(Intensity) 计算结果，不能因为名字包含 log 就再次取对数；继承真实 y 值、ylabel 和轴尺度。比较曲线的基准强调、类别颜色、连续变量颜色编码不能被通用线宽或颜色规则抹掉。体渲染导出应使用正常透明度，而非交互拖拽产生的临时 dim 效果。

GUI 线程读取控件和相机；数值 worker 只接收冻结输入。不能把读取 Qt 状态并修改缓存的 `_compute_render_context()` 整体丢入 worker。第一步在 GUI 线程验证独立 VTK 场景，之后依据耗时和驱动实测决定分步执行或经过验证的专用进程/渲染线程；不能让主线程和 worker 共享同一个 OpenGL 场景。Matplotlib 使用独立 Figure/Agg、显式样式参数和受控串行渲染，不修改全局 rcParams 或全局 PyVista theme。

3D 第一版做原生目标像素尺寸的高质量 PNG，色条与文字也由独立场景生成。TIFF 或体渲染图层与矢量注释层组合留给后续。禁止承诺体渲染能无损成为纯矢量；普通“嵌入 PNG 的 PDF”也不能称为矢量科学图。

2D 强度图在 PDF/SVG 中可以是栅格热图 + 矢量坐标、文字和色条，1D 曲线保留矢量。字体应嵌入或保持可编辑文本，检查 Å、负号、上下标。已确认 Matplotlib 支持这些导出参数；PyVista 提供 off-screen 和按 window_size/scale 导出能力，实际可用版本以环境为准。[Matplotlib savefig](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.savefig.html)、[PyVista screenshot](https://docs.pyvista.org/api/plotting/_autosummary/pyvista.plotter.screenshot)

物理尺寸由 mm/25.4 转英寸，再乘 dpi 得目标像素。600 dpi 的 89 mm 宽约 2102 px。使用固定画布及经过计算的内边距，避免盲目 `bbox_inches='tight'` 改变文件的物理尺寸。预览与导出应使用同一最终布局；不要仅放大屏幕截图或只改 DPI 元数据。

第一版格式矩阵：所有图型 PNG；1D/2D 另支持 PDF；3D 的 PDF 禁用并说明首版仅支持 PNG。TIFF、SVG、3D 混合 PDF、透明背景作为增强阶段，只有实际验证后才显示为可用。白底为首版固定默认，保留以后扩展背景样式的接口。可选同名 JSON 元数据也是增强项；核心内部仍须保留样式、尺寸、映射、来源页/帧、处理参数与版本以保证可追溯。

### 6.4 性能、保存与失败恢复

- 同一组卡片只解析/计算一次科学结果，三个样式共享该快照；卡片优先生成已选样式，其他依次排队。3D 复用导出专用数据资源，避免同时创建三个完整体场景和三份 4D 数据。
- 缓存键包含 snapshot/version、style/version、overrides、目标尺寸及预览分辨率；使用有容量上限的缓存，关闭窗口时释放临时 VTK/OpenGL 和大图资源。微调预览采用短延迟合并（建议 150–250 ms），只渲染最新请求。
- 不承诺所有硬件固定秒数。实施者记录真实样例的数据尺寸、设备、首张预览/三卡完成/正式输出耗时与内存；给出进度、取消和重试。取消是协作式的，不从另一线程强杀正在执行的 VTK 调用。
- PNG 先渲染为确定产物，再用同一图像生成预览与写盘；PDF 共用同一场景与最终布局。后台延迟返回时再次确认请求仍有效，不能突然保存用户已取消的图片。
- 文件写入使用同目录临时文件，写入验证成功后原子替换目标；覆盖确认沿用文件对话框。失败保留已有目标文件，只清理本请求的临时文件。不自动安装新依赖，不因离屏失败退回抓屏，也不靠无限重试掩盖驱动错误。

## 7. 分阶段交付与验收

### 7.1 实施顺序与阶段出口

| 阶段 | 工作 | 可检查的产物 / 进入下一阶段的条件 |
|---|---|---|
| A：隔离和数据正确性 | 审计当前 diff；明确快照契约和图型适配；最早验证 Windows 3D 离屏；三个视图族各打一条独立输出路径 | 带已知峰位的数据导出正确；源视图及共享色阶状态不变；各一个样式仅是内部里程碑 |
| B：九样式可比较 | 实现样式注册表和共用布局；同一快照生成每族三个样式；适配比较、瀑布和 log 曲线 | 三组同数据三样式输出，可直观看见边框/色条/图例差异，科学内容相同 |
| C：用户可用闭环 | 卡片与大图预览、微调草稿、提交/取消、视图族记忆、独立请求与过期结果处理、顶部直接截图 | 首次无需配置即可保存；预览保存一致；快速切页/切样式不会串图或污染主视图 |
| D：第一版交付 | PNG 全图型及 PDF 的 1D/2D 支持；尺寸和字体检查；保存失败恢复；实际环境回归 | 第 7.2–7.4 节通过，交付示例文件和检查报告；至此才算首版需求完成 |
| 后续增强 | TIFF/SVG/透明背景、3D 混合 PDF、自定义命名样式、旁文件、复杂非均匀网格 | 单独评估；不阻塞九样式首版，也不提前在菜单承诺支持 |

阶段 A 必须先于 UI 大规模开发，避免最后发现共享状态或驱动限制。实现中复用已有计算逻辑，但不能以顺便重构为由重写分析模块。若只能完成部分阶段，必须报告未完成项，不能宣布用户目标已完成。

### 7.2 样式与交互验收

| 场景 | 可核验结果 |
|---|---|
| 首次在 3D/2D/1D 点击截图 | 使用该族默认样式，直接选路径生成文件，无强制配置步骤 |
| 打开某类样式面板 | 恰好展示该族三个真实数据卡片；当前选择及“已微调”状态清楚 |
| 切样式、微调后取消面板 | 原来的长期偏好不变，左侧状态不变 |
| 使用此样式后切到另一图型再返回 | 恢复原图型已提交的 style_id 和该样式覆盖参数 |
| 切换样式 / 恢复默认 | 不带入另一个样式的覆盖参数；不重置尺寸/DPI/格式 |
| 导出此预览成功 | 文件匹配本预览快照与样式，提交该视图族偏好；更新按钮提示的样式名 |
| 保存路径取消 / 模拟写入失败 | 不提交草稿、不提示成功、旧文件无损，面板可以重试 |
| 预览中切到别的页面/帧 | 原预览不变，来源提示更新；导出预览仍是原快照，更新预览才换数据 |
| 连续点击卡片并马上保存 | 正式预览未就绪时不可导出旧图；最终文件匹配最后确认的样式版本 |

九样式视觉验收分别使用一份 3D、一份 2D、一份 1D 数据，在同尺寸下生成三组三张独立文件及对照图；曲线比较、瀑布、log 曲线另有覆盖样例。对照图允许是评审用拼图，不代表首版需要提供组图编辑功能。

### 7.3 科学正确性与状态隔离

必要验收：

- 样式库结构正确：同一 3D 数据可选三种 3D 样式，同一 2D 数据可选三种 2D 样式，同一 1D 数据可选三种曲线样式。每组输出在边框/色条/图例/留白上确有可见区别；切换左侧页面类型后恢复该类型上次选择。提供三组各三张同数据对比图供验收。
- 主视图不变：打开预览、切换所有模板、调色条/边框、保存、取消、模拟失败后，相机、视图尺寸、页面、轴范围、数据、色图、色阶锁定及下一次刷新行为均一致。
- 图像干净：不得包含计算状态条、鼠标提示、工具栏、拖拽手柄；配置页不生成科研图片。
- 数值准确：用含已知峰值位置的非对称测试数据验证轴向/转置/ROI/E 翻转；用已知标量与 LUT 验证刻度，而不是只做像素截图对比。
- 映射正确：线性/非线性、锁定/未锁定、负值、常数、NaN、全无效数据均有确定行为；无效数据不伪造峰。当前结果已归一化与未归一化的真实标签可区分；样式不新增归一化。
- 数据版本准确：连续切帧、快速拖动、未完成 EXACT 时点击截图，最终文件属于冻结的目标状态；错误不静默退回旧帧或 PREVIEW 数据。
- 单位真实：已有校准、缺坐标、缺单位分别验证；README 的缺 E 坐标样例不可输出虚假的 eV。
- 排版可靠：四个色条方向、长标题、极小/极大数、负号、上下标及不同纵横比均无遮挡和裁切；89/183 mm 两种尺寸下可读。
- 格式可靠：核验 PNG 像素与 DPI 元数据及 PDF 页尺寸（容许像素取整带来的不超过 1 px 误差）；PDF 检查文字与线条是否真正保留；3D 不宣传纯矢量。增强阶段再验收 SVG/TIFF。
- 环境可靠：至少验证当前 Windows 的实际 GPU/驱动和打包运行路径；不支持的输出明确报错，不悄悄改为抓屏。

测试集中于状态隔离、物理坐标、映射和异步数据版本等实质风险；无需为每个样式常量编写机械测试。用真实 WSe₂ 样例和带已知坐标的合成数据做目视复查。

### 7.4 必须实际执行的竞争与失败场景

至少覆盖：PREVIEW 中点击截图后连续切帧；等待导出时关闭源页/加载新数据；换样式后立即保存；取消任务后后台结果迟到；一次写入失败后成功重试；预览前后锁定色阶并刷新下一帧；3D 交互框拖动临时 dim 时导出；主视图处于缩放、E 翻转或 log 曲线状态时导出。

检查结果以 request/source 版本、已知峰位、方向、实际映射及主界面状态为准。3D 允许目标分辨率与抗锯齿造成正常像素差异，不强求与屏幕低分辨率截图逐像素相等。自动化测试覆盖确定的数值和状态契约；排版通过文件尺寸检查、文字边界检查和实际样例目视复核。

提交物建议保存在独立的验收输出目录：九张样式图片、三组对照图、比较/瀑布/log 代表图、1D/2D PDF 样本，以及简短的验证报告（环境、数据规模、格式支持、耗时/内存、通过/失败/未测项）。这些由实施 agent 实际生成，本次计划不代表已实现或已通过测试。
