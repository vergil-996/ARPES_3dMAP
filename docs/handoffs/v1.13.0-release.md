# v1.13.0 发布

2026-10-13。状态：本地发布前检查完成，等待推送源码与标签并跟进 Actions。

用户明确授权把 EDC 瀑布图插件化迁移（API 3）的全部工作区改动随本版发布，并把
版本号提升到 1.13.0。主程序、安装器与开发文档示例统一为 1.13.0；`edc_waterfall`
首版 1.0.0，其 `requires_app` 定为 `>=1.13.0,<2.0.0`（API 3 首次随本版提供；
更早的主程序会在兼容检查里先报“需要宿主接口版本 3”）。平带增强插件内容不变
（1.2.2，保持上一版目录中的摘要）。共享文件由当前集成任务统一提交，未提交
`.local/` 数据、日志、产物或签名材料。

发布说明：`docs/archive/releases/v1.13.0.md`（Release 工作流按标签读取该文件）；
README 增加 v1.13.0 更新。迁移记录见
[EDC 瀑布图插件化迁移交接](edc-waterfall-migration-2026-10-12.md) 与
[当前计划](../plans/edc-waterfall-plugin.md)。

## 发布前验证

- `.venv/Scripts/python.exe scripts/release/check_release_version.py v1.13.0`：通过；
  `v1.12.9` 按预期被拒。
- `.venv/Scripts/python.exe -m unittest discover -s tests -t .`：1123 项，
  1120 通过、1 跳过、2 失败；两项失败为 `tests/integration/test_crop_controls.py`
  的裁剪窗口几何断言，在未改动的干净工作区同样失败（本机 `QT_SCALE_FACTOR=2.0`
  环境），与本版内容无关。日志 `.local/logs/v1.13.0-regression.log`。
- `.venv/Scripts/python.exe scripts/validation/verify_plugin_release_flow.py`：全部通过
  （打包 → 签名 → 目录 → 验签 → 官方来源安装 → 重启加载 → 篡改拒绝）。
  日志 `.local/logs/v1.13.0-plugin-release-flow.log`。
- 插件打包：本机（Python 3.14，CRLF 工作区）重建 `edc_waterfall 1.0.0`
  （sha256 `367dd96a…`）与 `flat_band_opacity 1.2.2`（sha256 `6d978480…`），
  产物在 `.local/outputs/v1.13.0/`。**线上目录（CI）**：`edc_waterfall 1.0.0`
  sha256 `43ade902…`、`flat_band_opacity 1.2.2` sha256 `df70a756…`——
  平带摘要与 v1.12.5 线上目录一致，聚合未被拒。逐条目核对线上包与本机包：
  内容（CRC、解压尺寸、行尾、条目顺序）完全相同，只有压缩字节不同，属本机
  Python 3.14 与 CI Python 3.12 的 zlib 差异；跨版本聚合依赖的是 CI 每次重建
  的稳定性，本机摘要不能与线上目录逐字比对（详见[构建与发布](../development/releasing.md)）。
- 真实数据验收（本机 `D:\ARPES_3Dmap\npzfiles\mose2.npz`）：
  `verify_derived_waterfall.py` 23/23 通过；`export_acceptance.py` 全项通过。
