# BandScope 按钮图标高 DPI 优化交接计划

2026-11-22 · 已实施；2012 项全量回归、多倍率像素与单屏实窗验收通过；真实双屏跨屏移动待验。已随 v1.22.4 发布到 GitHub 与 MatElab（2026-11-22）。本文为本事项的状态主记录。

## 目标与边界

修复仓库直接引用的 **24 个 Fluent 图标**。保留现有 SVG、主题颜色、按钮布局和图标逻辑尺寸。在 100% 缩放下保持现有外观，在高 DPI 屏幕上按实际需要的物理像素重新绘制。太阳、月亮等细线图标在 100% 下的线条粗细以当前版本为准。

调查已完成源码盘点和 Qt 按钮离屏对照。在 125%、150%、175%、200% 缩放下，当前 16 逻辑像素图标可提供的位图宽度均为 16 个物理像素。本机调查图按原尺寸位图与同一 SVG 按目标尺寸绘制的结果逐个对照。[24 个图标的本机对照图](../../.local/outputs/icon-dpi-audit/fluent-button-comparison.png)

## 实现决策

1. **实现可缩放的图标引擎。** 在 BandScope 内实现 `QIconEngine`，从现有 SiliconUI 图标包读取已着色的 SVG 字节，通过 `QSvgRenderer` 绘制。保留 `theme.fluent_icon()`、`theme.set_button_icon()` 和 `page_kind_icon()` 的现有签名，以及图标缺失时返回空 `QIcon` 的行为。复用图标时按图标名和实际颜色区分。沿用现有依赖和资源包。[公共图标入口](../../bandscope/ui/theme.py)
2. **分别实现 Qt 5 的两条绘制路径。** 本机已用 PyQt 5.15.11、Qt 5.15.2 和真实 `QPushButton` 做离屏原型验证。`pixmap(size, mode, state)` 收到目标物理尺寸，例如 16 逻辑像素在 125% 和 200% 下分别收到 20 和 32。按传入尺寸创建透明位图，由外层 Qt 设置 DPR；重复乘倍率或限制回 16 会导致尺寸错误。`paint()` 收到逻辑矩形，使用目标画笔的设备变换绘制。实现 `clone()`，让 `actualSize()` 尊重请求尺寸，沿用 Qt 样式生成禁用、活动和选中模式的外观。
3. **由消费端明确逻辑尺寸。** 主题按钮为 14，数据库与出版导出动作为 15，常规按钮与页面类型为 16，设置与 Blender 标题为 18，新建分组为 20。补齐日月按钮及两个出版导出按钮的 `iconSize`。页面树从直接调用 SiliconUI 的 `toIcon()` 改为复用公共工厂。[页面树入口](../../bandscope/ui/page_tree.py) · [出版导出按钮](../../bandscope/exporting/publication_dialog.py)
4. **在三个装饰标签重绘时绘制图标。** 数据源数据库、工作区页面类型、Blender 标题立方体共用一个轻量图标标签，在 `paintEvent` 中通过 `QIcon.paint()` 按指定逻辑尺寸居中绘制。保留容器尺寸、背景、边框及显隐。换主题时更新颜色，换页时更新图形，清空页面时清空图形。跨屏绘制使用标签所在窗口的当前绘制设备。[工作区标题](../../bandscope/ui/result_workspace.py) · [Blender 标题](../../bandscope/exporting/blender_project_dialog.py)

## 验收与完成条件

- **像素验证。** 使用项目的 `ActionButton`，将实际按钮截图中的图标区域与同一份 SVG 按目标物理尺寸直接绘制的参考图比较。覆盖 100%、125%、150%、175%、200%，另覆盖已有 Windows 实窗记录中的 DPR 1.5625。在相同 Qt 环境、颜色、尺寸和正常态下，100% 与旧版逐像素一致。高倍率核对轮廓、居中位置和逻辑尺寸。现有图标非空断言可继续保留，另需检查实际绘制结果。
- **尺寸与状态。** 覆盖 14、15、16、18、20 五档逻辑尺寸，以及深浅主题、禁用按钮、可勾选按钮、专注模式切换、树项选中、插件拼图、三个图标标签和缺失图标回退。重点检查 14、15 逻辑像素在分数缩放下的取整，以及图标旁文字的位置。
- **Windows 实窗。** 检查主窗口、插件管理、出版导出和 Blender 标题。在不同倍率的双屏之间往返移动同一个已打开窗口，确认图标随窗口重绘。现场只有单屏时，分别记录离屏多倍率结果与待验的真实跨屏操作。
- **集成交付。** 运行受影响模块测试，再运行 `python -m unittest discover -s tests -t . -v`。将 24 个图标的前后对照和实窗截图放入 `.local/outputs/icon-dpi-audit/`，在本文记录实测环境、通过项和待验项。交付包括源码、测试和验收记录。

## 实施与验收记录

- **已实现。** `bandscope/ui/fluent_icon.py` 提供 SVG `QIconEngine` 与实时绘制标签；主题工厂按图标名和实际颜色缓存。主窗口、画布、页面树、工作区、出版导出、Blender 标题及宿主插件列表均沿用公共入口。日月和两个出版按钮已显式设置逻辑尺寸，页面类型映射、回退、显隐和 Z 字母叠加保持不变。
- **自动化。** 新增 `tests/ui/test_fluent_icon.py`，覆盖五档尺寸、六种 DPR、正常／禁用／活动／选中、克隆、缓存、缺失图标、直接 `paint()` 和标签换主题／换图／清空；消费端补有按钮尺寸、专注切换、Blender 标签和工作区换页／清空断言。相关主题、页面树、主窗口和导出测试通过；`compileall` 通过。`python -m unittest discover -s tests -t . -v` 全量 **2012 项通过**（149.402 秒）。
- **按钮像素。** Windows、Qt 5.15.2、PyQt 5.15.11；真实 `ActionButton` 在 DPR 1、1.25、1.5、1.5625、1.75、2 下各验证 24 图标和禁用／勾选两状态，全部通过。100% 下 26 个案例均与旧版完整按钮逐像素一致。高倍率均与目标物理尺寸 SVG 经 Qt 5 实际目标矩形绘制的参考逐像素一致；直绘 SVG 对照同时保留。分数 DPR 下部分尺寸遵循 Qt 5 的 `int(物理尺寸 / DPR)` 位图逻辑尺寸取整，旧版亦同，脚本未额外补偿 DPR。[像素报告](../../.local/outputs/icon-dpi-audit/fluent-button-pixel-report.json) · [200% 对照](../../.local/outputs/icon-dpi-audit/fluent-button-comparison.png)
- **Windows 实窗。** 使用 WSe₂ 时间分辨数据，在本机 DISPLAY1、DPR 1.25 下完成深浅主题的主窗口、专注模式、出版导出和 Blender 标题截图并人工查看；图标旁文字与布局未见回归。另用真实构建的临时平带插件完成插件管理全部检查，深浅主题列表均显示清晰的拼图图标。[实窗报告](../../.local/outputs/icon-dpi-audit/windows/fluent-icon-window-report.json) · [插件深色](../../.local/outputs/icon-dpi-audit/plugin-management/settings_plugins_dark.png) · [插件浅色](../../.local/outputs/icon-dpi-audit/plugin-management/settings_plugins_light.png)
- **验收限制。** 现场仅一台显示器，同一窗口在不同 DPR 双屏间往返移动未执行，仍需双屏环境补验。通用 `verify_ui_themes.py` 本轮在既有 XY 预设 `isChecked()` 断言处中止；未改动相机功能，本事项窗口由专用 `verify_fluent_icon_windows.py` 完整覆盖。
