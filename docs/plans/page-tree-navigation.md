## 目标与交互

将现有窄图标栏和树浮层替换为常驻页面树，采用 Windows 文件导航的操作方式，保留当前深色主题。

- **完整层级**：按页面来源显示父子关系，所有拥有子节点的页面显示展开箭头；点击箭头只展开或收起，点击名称切换页面。
- **拖动调宽**：树与画布之间增加分隔条，初始宽度 240 像素、最小宽度 180 像素，并保证画布至少保留 320 像素。栏宽跨重启保存。
- **长名称**：提供横向滚动和完整名称提示，保留页面类型图标。
- **状态记忆**：当前会话内保留展开状态、排序和滚动位置；新增页面自动展开祖先并定位。
- **辅助操作**：提供“全部展开”“全部折叠”“定位当前页”。上下键移动选择，左右键展开收起，Enter 切页。

## 改名、删除与搜索

### 改名

- 右键“重命名”或 F2 在树中直接编辑；Enter 或失焦保存，Esc 取消。
- 复用现有命名规则：去除首尾空白，空名称恢复原名，重复名称追加编号。
- 右键提供“恢复自动名称”；保留页眉改名弹窗，两种入口共用提交逻辑。
- 改名同步树、页眉、来源提示与导出名称，页面身份及来源关系保持稳定。主页可改名，工具页沿用现有限制。

### 删除

- 右键“删除页面”、树内 Delete、页眉关闭按钮及 Ctrl+W 使用统一规则。
- **所有删除都确认**：显示目标名称与删除总数，默认选中取消；父页连同全部后代删除，数量包含被搜索隐藏的页面。
- 主页及不可关闭页面受保护；包含受保护节点的整支删除不可执行。
- 删除集合包含当前页时，切换到删除根的最近存活父页，没有则回到主页；删除其他分支时保持当前页面。
- 删除只作用于当前会话的页面和相关状态，原始数据文件不受影响。

### 搜索与排序

- 树顶部增加名称搜索，采用不区分大小写的包含匹配；显示命中页面及其祖先，并临时展开路径。
- 清空搜索后恢复原来的展开状态和滚动位置；无匹配时显示空结果提示，画布保持当前页面。
- “定位当前页”清空搜索并展开祖先。新建或外部切换到被隐藏的页面时，同样清空搜索后定位。
- 支持同级拖拽排序，父节点携带整支移动；禁止跨父节点移动。搜索期间禁用排序。

## 实现与接入

- 在 `bandscope/ui/` 增加独立页面树组件，使用现有 Qt 树控件与水平分隔器；`ResultWorkspace` 继续持有页面记录，以 `page_id` 关联节点。
- 增加树内改名提交、删除请求及同级排序接口；命名校验复用现有主窗口逻辑。更新宿主、测试和验收脚本中对旧图标按钮、浮层的访问。
- 删除采用统一的批量核心：先确定完整集合，按子页到父页清理，逐页发出既有关闭通知，最后统一刷新导航并激活存活页面。加载新数据的内部重置不弹删除确认。
- 修复“删除非当前祖先后，当前后代已不存在却未切页”的问题；清理后台任务、裁剪、轴标题、缓存及失去引用的裁剪数据域，避免已删除状态被重新保存。
- 树及编辑框获得焦点时，方向键归树操作或文本编辑处理，避免触发时间轴逐帧；Delete 不干扰文本删除。数字切页按树中当前可见行顺序执行。
- 保留正在进行的轴标题和页面命名改动，由集成任务协调共享文件；不改变插件公开 API、依赖或打包配置。

### 调查所得的接入注意事项

- 当前 `ResultWorkspace` 使用固定 56 像素图标栏和 `ResultTreePopup`；浮层重建会调用 `expandAll()`。改造应移除旧导航逻辑，避免双份树状态。
- `AnalysisPageSpec.source_page_id` 表示来源关系；不能通过拖放改写它。现有 `_tab_order` 已存页面 ID，可按此顺序排列各组真实同级节点；排序时只调整目标同级组，保留其他组相对顺序。
- Qt 默认树内拖放允许修改父子关系，需要限制为同级排序。搜索使用临时展开状态，不能覆盖未搜索时保存的状态。
- 结果页 ID 为随机 UUID，当前没有会话恢复能力。展开状态按 ID 在会话内保存，不按标题保存；栏宽可使用 QSettings 跨重启保存。
- 现有 `_rename_page`、`_make_unique_page_title`、`set_page_title` 及恢复自动名称逻辑应复用。树内编辑提交后再重新过滤，过滤变化不能改写真实当前页面。
- 当前 `close_page_and_descendants` 仅判断被删根是否为当前页，遗漏当前页是后代的情况；逐项关闭还会反复重建导航。需先计算删除集合，再统一处理回退和刷新。
- `on_result_page_closed` 已负责裁剪、刷新任务、缓存和裁剪数据域清理。保留逐页通知契约，并核对当前显示源、`active_page_spec`、`last_visual_page_id` 和轴标题交互的清理。
- 主窗口 `_handle_frame_step_shortcut` 会消费左右键，需要在树持有焦点时排除。`rail_page_ids()`、`page_buttons` 等旧入口仍被宿主或验收脚本引用，替换时同步更新调用点。
