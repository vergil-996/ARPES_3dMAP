# BandScope 视图复现文件方案

- 日期：2026-10-20
- 状态：源码已实现（2026-10-20），并随 v1.16.0 采用“新增数据源”语义发布；原生文件对话框及维护者交互验收待完成。
- 负责范围：`bandscope/core/` 的格式与数据来源模型、`bandscope/app/` 的状态捕获和恢复、`bandscope/exporting/` 的配对导出，以及对应 UI、插件宿主内部接入和测试。
- 共享接入点：主窗口、页面状态与树模型、图片导出面板和插件宿主，由集成任务统一协调；现有公开插件 API 保持兼容，不新增依赖，不调整打包配置或 CI。
- 交付物：版本化复现文件、配对导出与加载流程、自动化测试、真实窗口验收记录及用户说明。

## 已确认的行为

- 图片导出时增加“同时保存复现文件”，默认开启。
- 使用可编辑的 UTF-8 JSON：例如 `figure.png` 对应 `figure.png.bsview.json`，保存在同一目录。
- 保存目标视图所需的来源分支、有效处理链和最终参数，同时保存出版排版。
- 打开复现文件后，在当前窗口恢复树形结构，展开来源分支并选中目标视图。
- 允许保存必要的结果快照；无法重新计算时明确标注。

## 文件内容与格式

新增版本化的 `ViewRecipeDocument` 数据契约，包含以下内容，不直接序列化运行时窗口对象。

| 内容 | 保存的信息 |
|---|---|
| 数据来源 | SHA-256、数组 key、形状、轴映射、坐标来源与单位；不保存 NPZ 路径 |
| 有效处理链 | 操作类型及版本、输入依赖、实际生效参数，包括全局去噪、旋转、积分、二阶导、裁剪与裁空 |
| 页面树 | 页面类型、父子关系、顺序、自定义名称、ROI 定义及目标页面 |
| 显示状态 | 时间帧、切片、轴翻转、色图、透明度、黑白灰场控件值及实际强度值、映射方式、锁定范围、局部增强 |
| 相机与构图 | 四个读数，以及完整位置、观察中心、向上方向、投影、缩放、裁剪面和原视口宽高比 |
| 标题与出版设置 | 轴标题及位置、解析后的样式参数、尺寸、DPI、透明背景、曲线顺序、样式、图例与标注 |
| 复现依据 | 应用、算法和插件版本；必要的数值快照及其恢复能力 |

JSON 使用缩进和中文直写；曲线缺测值保存为 `null`。数据来源不保存本机路径，兼容读取旧版路径字段但不使用它自动定位。

原始数据身份在实际加载时建立，避免导出时磁盘文件已被替换、内存仍是旧数据。摘要计算放后台，配对导出前必须完成。

## 状态记录与恢复

- 在 `core` 增加独立格式模型、校验和编解码；在 `app` 增加捕获与恢复服务。主窗口只负责接入，现有公开插件 API 保持兼容。
- 页面导航树与计算来源分开保存。生成结果、复制曲线、提交分析和成功重算时，冻结实际使用的输入与参数；后续修改产生新的配方记录，不能改写旧来源。
- 内置处理使用显式数据和参数重新计算，补齐当前依赖活动控件的状态读取。全局去噪、ROI 和轴标题单独恢复。
- 旧插件分析结果保存来源、提交参数与数值快照；已有稳定重算入口的插件仅在版本和内容匹配时重算，否则恢复快照并禁用需要该插件重算的操作。
- 3D 插件效果保存实际生效的一维倍率。恢复时冻结倍率优先，避免本地插件设置覆盖或重复应用效果。
- 跨文件比较保存额外来源记录与曲线快照；首版不扩展为多个原始 NPZ 同时编辑的工作区。

加载流程为：解析校验 → 强制用户选择主原始 NPZ 并检查身份 → 准备数据和必要结果 → 作为新数据源恢复工作区（不替换已有分析）→ 选中保存的目标视图。预检失败、取消或提交失败都保留现有数据源与后台任务。摘要不符则停止完整复现；仅用于快照引用的额外数据无需选择。页面 ID 在导入时重新分配为全局唯一，避免多份数据之间页面、任务和缓存串源。

恢复后，出版设置保存在该视图的会话状态中，不覆盖用户的全局默认偏好。

## 导出一致性与交互

- 科学配方与现有导出预览同时冻结；点击导出时再冻结排版草稿。打开面板后切页或改参数，不得导致图片与复现文件错配。
- 插件计算失败而界面保留上次成功结果时，导出绑定那份成功结果及其有效配方。
- 图片和 JSON 均写入临时文件后再提交，替换失败执行回滚并明确报告结果；两份文件都成功才提示配对导出成功。
- 每次启动默认勾选保存；本次运行内记住用户的勾选选择。关闭后只导出图片。
- 现有“打开文件”入口增加 `.bsview.json`。加载后恢复树、目标视图及出图草稿，不自动再次导出图片。

## 验收与边界

- 使用合成 NPZ 验证导出后在全新窗口加载，检查树关系、数值结果、参数、相机和出版设置。
- 覆盖所有可导出的视图类型，以及全局去噪、ROI、多次裁剪/裁空、局部增强、降序轴和缺测曲线。
- 专项验证冻结预览、来源页修改、跨文件剪贴板、插件缺失或版本不同、失败后保留旧结果。
- 验证导出不含路径、旧版路径被忽略、每次强制选择数据源、数据摘要不符、损坏或未知格式、取消和配对写入失败；随后运行受影响测试及 `python -m unittest discover -s tests -t . -v`。
- 真实窗口验收默认使用 `.local/data/WSe2_step.npz`，另行记录人工视觉结果。

复现文件不嵌入原始 3D/4D 数据，不记录数据源路径或每次滑块拖动。其他科学参数被手改后必须重新校验和计算，不能继续套用不匹配的结果快照。复现目标是计算结果、显示参数和出版设置一致；不同 GPU、字体或软件环境下不承诺图片逐像素或文件字节相同。
