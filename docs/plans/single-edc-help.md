- 日期：2026-10-12
- 状态：**已被“移除处理分析页并迁移积分创建入口”改造取代，不再实施**（2026-11-20）。
- 取代原因：「处理分析」页和「其他积分」下拉已移除，原计划的选择框旁悬停图标没有接入位置。现行流程是在 E（Z）轴积分的矩形裁剪页上选择「视图右键 → 处理分析 → 单条 EDC 曲线」。
- 原负责范围：主程序 UI 控件及处理分析页，由实施任务负责集成。
- 原共享文件：`bandscope/ui/ui_controls.py`、`bandscope/ui/page_data_process_v2.py`；无需修改主窗口、插件 API、依赖、打包配置或 CI。
- 原交付物：悬停帮助控件、单条 EDC 入口接入、验证记录。以下内容仅保留作方案追溯，不作为待实施指令。

## 原目标与交互（不再实施）

首轮只为“单条 EDC 曲线”增加帮助提示，使用固定说明。

- 在“其他积分”的类型选择框右侧放置小圆形问号，仅选中“单条 EDC 曲线”时显示。
- 鼠标悬停自动出现气泡，采用 Qt 默认提示延迟；移开后关闭。
- 图标与气泡沿用现有深色主题，说明自动换行。
- 为图标预留位置，切换选项时选择框不移动、不改变宽度。

## 原气泡文案（旧入口）

> ① 在“对坐标轴积分”中选择“Z轴”，点击“应用”，生成 Kx–Ky 二维结果。  
> ② 用顶部“裁剪”框选矩形区域，再点击裁剪窗口中的“裁剪”。  
> ③ 保持裁剪结果页为当前页，选择“单条 EDC 曲线”并点击“应用”。
