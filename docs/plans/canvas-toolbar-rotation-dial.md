# BandScope 画布工具栏与 Z 轴旋钮改造

2026-11-21 · 已实施。定向功能回归、Windows 替代数据与 WSe₂ 实数据窗口验收均通过。

将「显示坐标」「图像翻转」「Z 轴旋转」移到画布右上角的悬浮工具栏。前两项改为图标开关，Z 轴旋转改为按需展开的旋钮。底部宽度全部留给位置和时间滑条。

## 画布工具栏

- 在现有「重置视角」下方、「裁剪」上方新增一组按钮，依次为「显示坐标」「图像翻转」「Z 轴旋转」。沿用工具栏现有按钮尺寸，补齐悬停提示、键盘焦点和无障碍名称。
- 坐标与翻转按钮点击即切换，开启时高亮。旋转按钮使用带 `Z` 的弧形箭头，角度非零时持续高亮，悬停显示当前值，例如「Kx–Ky 平面旋转 −7.5°」。
- 三个入口沿用各自在现有页面上的可用行为，单独成组。低高度窗口按工具栏的实际内容高度收起现有视角预设组，确保新增按钮和底部操作可达。

## Z 轴旋转面板

- 点击 `Z`，在按钮左侧展开「Kx–Ky 平面旋转」面板。圆盘外圈用于拖动，中央可直接编辑带正负号的角度，下面放「归零」。再次点击 `Z`、点击面板外或按 `Esc` 收起。
- 拖动从当前角度开始，跨过圆盘顶部时保持连续，到 `−360°` 或 `+360°` 停止。中央输入支持两位小数，键盘上下键按 `1°` 调整。输入 `−7.5°` 后，指针、读数和按钮提示同步更新。
- 拖动期间复用现有旋转预览，松手时提交一次精确刷新。数值输入在回车或结束编辑时提交。「归零」立即提交 `0°` 并熄灭角度高亮，相机位置和朝向保持原值。
- 切换页面或数据源时先结束旧页面的编辑并关闭面板，再恢复目标状态，避免延迟的编辑信号改写新页面。

## 底栏布局与状态接入

- `TimelineBar` 只排布位置和时间两组滑条。两组同时显示时等分可用宽度，放不下才改为上下两行。只有一组时占满整行，两组都隐藏时折叠底栏。路径页的选段条独立显隐。
- `CanvasToolOverlay` 持有新的视图控件。保留现有 `TimelineBar` 状态读写入口，统一转接到同一组控件，让裁剪、插件、导出和验证脚本继续取得相同的值。
- 沿用 `switch_axes`、`switch_flip`、`rotation_angle` 三个保存字段。恢复数据源或旧配方时一次同步按钮、旋钮和角度读数，避免重复翻转或触发多次刷新。

## 验收

- **交互**。用合成数据验证负角度、小数、跨零拖动、两端限位、键盘输入和归零。确认一次拖动只在松手时提交一次精确刷新，归零后可继续全帧 ROI 裁剪。
- **状态**。覆盖 3D 与切片页切换、两个数据源往返、旧配方恢复和导出。重点检查面板收起后的非零高亮，以及切换后首次打开时的角度读数。
- **布局**。更新原先要求视图控件常驻底栏或换到第三行的断言。在 Windows 实际窗口使用 `.local/data/WSe2_step.npz` 验证宽窗、窄窗、低高度和系统缩放，检查滑条能否占满可用宽度、路径选段条是否保留，以及旋钮弹层能否在原生 VTK 画布上正常显示和接收拖动。
- 先运行画布工具栏、旋转预览、滑条布局和状态恢复的定向测试，再运行全量回归 `python -m unittest discover -s tests -t . -v`。窗口视觉验收单独记录。
