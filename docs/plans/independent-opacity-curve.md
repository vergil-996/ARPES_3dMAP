# 移除强度归一化卡片，改造独立不透明度曲线

2026-11-21 · 已实施；WSe₂ 验收待补，全量回归存在其他任务失败

移除主窗口的「强度归一化」卡片和 Blender 工程编辑器中对应的范围选项。新旧视图统一使用完整强度范围。三维「独立不透明度」卡片改为一张可直接拖动的曲线图，沿用已有四个参数和渲染公式。

## 强度范围

- 颜色和三维不透明度共用当前调整对象中有限强度值的最小值与最大值。色阶直方图继续显示实际强度。黑、灰、白场和输出色带沿用现有交互。
- 保留跨帧锁定。锁定时记录当前完整范围，换帧后沿用，解锁后恢复逐帧计算。背景和局部增强区域沿用各自的范围。
- 读取旧配方时先验证原文件完整性，再将独立模式下的百分位、手动范围和缺省策略统一转为完整范围。旧视图若锁定了已移除策略的范围，在恢复帧上按完整范围重新建立锁定。保存配方、出版导出和 Blender 导出均使用转换后的有效范围。

## 独立不透明度卡片

横轴表示相对强度，纵轴显示按现有透明度公式计算的曲线。保留紧凑数值框，支持精确输入。

| 控件 | 拖动行为 |
|---|---|
| 黑场手柄 | 左右拖动设阈值。阈值及以下完全透明。拖动时保留过渡宽度，过渡终点随它移动。 |
| Gamma 手柄 | 在阈值与 100% 强度之间左右拖动。左拖让弱信号更明显，右拖压低弱信号。手柄对应幂曲线的中点，位置由阈值和 Gamma 决定。 |
| 密度手柄 | 固定在 100% 强度处，上下拖动调整整体密度。直接上下拖曲线也执行同一操作。密度为零时可以直接向上拖起，阈值及各手柄的横坐标保持稳定。 |
| 过渡终点标记 | 放在横轴下方，可单独拖动。终点减去阈值就是过渡宽度，两者重合时宽度为零。到达终点表示平滑起步结束，此后不透明度仍可继续上升。 |

- Gamma 手柄采用 `阈值 + (100% − 阈值) × 0.5^(1/Gamma)` 定位。阈值为 100% 时仍可通过数值框编辑 Gamma。
- 保留现有参数范围和精度。过渡宽度最大为 100%，因此终点可能超过 100%。编辑时横轴可展开至阈值加 100%。黑场与过渡终点使用上下分开的命中区，默认宽度为零时也能分别选中。
- 卡片仅在三维独立模式显示。拖动复用现有预览，松手提交最终精确帧。单独调整不透明度时复用已有颜色结果。沿用当前背景、局部区域和「全部显示」的调整目标。
