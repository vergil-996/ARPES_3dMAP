# 不透明度曲线支持平滑、直线和垂直阶跃

2026-11-22 已实施；1988 项全量回归与 WSe₂ 真实窗口 56 项验收通过。真实 Blender 进程渲染及维护者人工视觉复核未执行。已随 v1.22.4 发布到 GitHub 与 MatElab（2026-11-22）。现有折线编辑器的设计与验收记录见[三维不透明度曲线直接编辑](opacity-curve-control-points.md)。

新建曲线默认「平滑」，已有曲线按保存的模式打开，旧文件按「直线」还原。控制点可以任意接近，也可以停在同一强度上。每个点始终保留自己的顺序，拖到邻点就停，反向拖动即可重新拉开。

## 控件与拖动

- 在「不透明度」标题行右侧放置「平滑／直线」双段选择器，与左侧折叠按钮分别响应点击。切换作用于当前显示对象的整条曲线，所有点保持原位，编辑器和体图同步刷新。
- 移除固定最小间距 `1e-4`、近邻合并和靠近端点时自动吸附的逻辑。鼠标拖动和方向键微调共用同一条限位规则。内部点的横坐标限制在左邻点到右邻点的闭区间，纵向仍可在 `α = 0…1` 内调整。首尾两点分别固定在强度 0 和 1。
- 底轨上推时，候选强度与已有点不同，即使两者落在同一命中半径内，也能新增独立点。精确碰到已有点则沿用选中该点的手势。普通点击选最近的点。多个点在屏幕上完全重叠时，连续单击可逐个选中。按住拖动期间始终锁定同一个点。

## 曲线取值与加点

- 「直线」逐段线性连接。「平滑」采用保形三次插值 PCHIP，经过控制点并保留平台和局部峰谷。两种模式都支持垂直阶跃。例如相邻两点为 `(40%, 0.1)` 和 `(40%, 0.8)`，左侧曲线抵达 0.1，图上在 40% 处画竖线。强度恰好等于 40% 时取 0.8，右侧从 0.8 继续。多个同强度点按原顺序保留，精确命中时取最后一个点的 α。平滑计算在阶跃处分段。
- 沿平滑曲线加点时，在碰线处精确拆分原三次曲段，保留两侧切线。松手即保存新增点及维持曲形所需的信息，体图保持原样。实际移动控制点后，再对受影响曲段重新平滑。连续加点、切到直线再切回、保存重开，都应能还原原来的平滑形状。
- 编辑器绘图、底轨碰线、CPU、CUDA 和导出共用同一套分段系数与阶跃取值规则。按实际控制点位置求值，避免窄过渡被固定分辨率的查找表抹平。

## 保存与兼容

- 将插值模式保存为 `opacity.interpolation`，与有序点列、平滑曲段的拆分信息一同随显示样式传递。页面复制、局部增强的背景与选区、视图复现和 Blender 点列编辑器均保留这些信息。
- 更新复现文件和 Blender 点列编辑格式的版本。读取旧文件时先校验原摘要。旧点列、旧四参数和兼容映射转换出的曲线均明确标记为直线。已保存为两个点的记录按原顺序恢复。历史文件中已经合并掉的点无法追溯。

## 验收标准

- **拖动与选择**。鼠标和键盘都能让两点贴齐、分别上下移动、再拉开。连续向邻点外侧拖动不会越位或推动邻点。覆盖三个点同强度、与端点重合、间距小于 `1e-4`、重叠点轮选及单独删除。
- **曲线与体图**。验证上升和下降阶跃的左侧、精确位置、右侧取值。验证平滑曲线经过各点、平台恒定、峰谷无过冲。对非直线曲段连续加点，对比加点前、松手后和保存重开后的 α，确认在浮点精度内一致。
- **集成**。使用合成数据核对 CPU、CUDA（可用时）、出版图与 Blender 密度结果，覆盖旧文件迁移。运行受影响模块测试及全量 `python -m unittest discover -s tests -t . -v`，再用默认 WSe₂ 数据运行 `python scripts/validation/verify_independent_opacity_curve.py .local/data/WSe2_step.npz`，检查窄面板布局、模式切换和拖动阶跃时的体图反馈。

## 实施记录

- 新增 `bandscope/core/opacity_curve.py` 作为唯一数值契约：点列稳定排序并保留重复强度和任意小间距；直线与 PCHIP 都按相邻点生成曲段，重复强度形成垂直阶跃，精确命中取该强度最后一个点的 α；PCHIP 在阶跃处分段，保持平台并避免局部峰谷过冲。
- 平滑曲段以归一化三次 Hermite 系数保存。沿曲线加点直接拆分原三次多项式，保留两侧切线；连续加点、松手提交、直线／平滑往返、页面复制和保存重开均保持曲形。实际移动或删除点后清除旧系数并重新平滑，编辑器一次批量求值绘制，避免多点时平方级开销。
- 「不透明度」标题行右侧加入「平滑／直线」双段选择器，与折叠按钮独立；新曲线默认平滑。鼠标与键盘共用闭区间邻点限位，无最小间距、合并或端点吸附；支持端点重合、同强度三点、重叠点轮选与独立删除。底轨仅在候选强度与已有点不同且碰线时新增独立点，松手提交新增点。
