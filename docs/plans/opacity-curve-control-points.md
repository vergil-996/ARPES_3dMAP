# 三维不透明度曲线直接编辑方案（修订版）

2026-11-21 · 已实施；WSe₂ 真实窗口与各渲染路径验收通过，真实 Blender 进程渲染与维护者人工视觉复核未执行

**底轨只负责加点，曲线上的左键拖动只负责编辑。** 已有控制点拖到零线以下时，α 固定为 0，即使在底轨松手也保留该点。删除内部点使用右键菜单或 `Delete` 键。

## 初始界面

- 三维页面打开即可编辑。新页面默认有三个控制点 **（0%，0）、（50%，0.5）、（100%，1）**，按强度顺序以直线相连。默认画面匹配原“兼容映射 → 线性”在默认色阶下的效果。之后调整颜色黑、灰、白场时，不透明度曲线保持独立。
- 从“独立不透明度”卡片移除黑场、过渡宽度、透明度 Gamma、整体密度四个输入框及其旧手柄。曲线上的控制点使用**黑色实心圆且不带外轮廓**（选中时也不画焦点轮廓）；底轨加点手柄仍为黑色实心圆加分离的外轮廓。
- 从“色阶调整”卡片移除显示模式切换、四种强度映射选项及对应的“应用设置”按钮。保留区域选择、色带锁定、输入色阶和输出色带。二维及路径切片页面仅显示适用的颜色控件。

## 控制点交互

| 操作 | 行为 |
|---|---|
| 在底轨定位 | 水平拖动底轨圆点选择强度。细竖虚线连接圆点与曲线上对应的位置。用户可以在同一次拖动中转向上推，也可以先松手，再从该位置向上拖。 |
| 从底轨加点 | 向上拖动时内层黑点脱离外轮廓，外轮廓留在底轨原位；黑点沿细竖虚线连续跟随光标上下移动（包括底轨与横轴之间的间距），候选强度在开始上推时锁定。把黑点拖回底轨轮廓内会重新挂回手柄，可继续水平拖动。黑点碰到或跨过曲线即在交点生成并选中新点。插入瞬间曲线形状不变，保持按住即可继续移动新点。碰线前松手时黑点落回原位轮廓、不生成点；碰到已有点则选中并接着拖动该点。 |
| 底轨圆点回填 | 开始上推时外轮廓留在底轨原位。成功放点后，原位轮廓中的黑点从中心向外逐渐填满，约 200 毫秒完成。移动底轨圆点和播放动画只重绘控件，不触发三维渲染。 |
| 编辑曲线 | 左键拖动内部点可同时调整强度和 α，横向限制在相邻点之间。两个端点分别固定在 0% 和 100% 强度，可上下调整。纵向超出图框时，α 钳制到 0 或 1。点间采用线性插值，支持平台和下降段。拖动曲线上的点不带动底轨圆点。 |
| 删除内部点 | 右键点击内部点并选择“删除控制点”，或在曲线控件有焦点时按 `Delete` 删除当前选中内部点。删除后连接左右邻点。两个端点始终保留。 |

悬停或拖动时显示强度百分比和 α。改变曲线时沿用拖动预览，松手提交精确帧；菜单或键盘删除后直接提交。

## 保存、渲染与旧文件

- 显示样式保存按强度排序的归一化 `(强度, α)` 点列。页面复制、跨源恢复、背景、增强区域、“全部显示”和跨帧锁定沿用现有作用范围。只改曲线时复用颜色缓存。
- CPU、GPU、出版导出与 Blender 采用相同的分段线性曲线和参考距离换算。默认外观以旧兼容线性的参考距离为基准。正采样距离下正确处理 α＝0 和 α＝1，Blender 写入体密度时沿用有限消光上限。
- 旧复现文件先按原格式校验，再转换为可编辑点列。四参数曲线按原公式转换；兼容曲线计入保存时的色阶、Gamma、映射方式及参考距离。保留端点和关键转折，自适应补点，使参考距离下的 α 误差控制在 `1/255` 以内。旧页面可有三个以上控制点。旧二维路径切片继续还原已保存的分段颜色映射，新建路径段默认线性。
- 升级复现文件和 Blender 工程格式。新版 Blender 工程编辑窗口复用同一曲线控件。旧工程仍可按原格式读取和更新，需要保存自由控制点时另存为新版工程。

## 验收

1. **优先验证零线编辑与删除互不干扰。** 将内部点一路拖过零线，在底轨松手，确认点数不变、该点 α＝0、重新打开后仍保留。随后分别用右键菜单和 `Delete` 删除内部点，验证邻点重新连线、端点受保护，焦点离开曲线后 `Delete` 不影响曲线。
2. 覆盖水平定位后直接上推、分两次拖动加点、快速跨过曲线、碰线后继续拖动、提前松手、命中已有点，以及 α＝0 处加点。窗口检查深浅主题、窄面板、细虚线和底轨回填动画。
3. 用合成梯度对比默认三点和旧兼容线性的渲染结果。用带下降段和平台的曲线核对 CPU、可用 GPU、出版与 Blender 输出，验证调色阶不改变 α、旧文件迁移满足误差要求、新曲线保存后能准确还原。
4. 实施时保留工作区已有的色阶、主题及验收脚本修改。运行受影响测试和全量 `python -m unittest discover -s tests -t . -v` 回归，并使用约定的 `.local/data/WSe2_step.npz` 做真实窗口验收；数据缺失时单列该项为未执行。

## 实施记录

- 显示样式的不透明度改为按强度排序的归一化 `(强度, α)` 点列，新页面默认 `(0%, 0)、(50%, 0.5)、(100%, 1)`。`display_style` 负责排序、去重、端点固定与旧四参数／兼容曲线转换；`display_transfer` 提供分段线性求值、`opacity_reference_distance()`（完整显示网格上的旧兼容线性参考距离）与 `rebase_opacity()`。默认三点曲线在默认色阶、未裁剪数据上与旧“兼容映射 → 线性”逐体素一致。
- `bandscope/ui/opacity_controls.py` 重写为可直接编辑的曲线：曲线控制点是不带外轮廓和焦点轮廓的黑色实心圆；底轨手柄为黑色实心圆加分离外轮廓，向上拖动时内层黑点脱离外轮廓、沿竖直虚线随光标上移，外轮廓留在原位，碰到曲线插入并选中新点后原位轮廓由中心填黑约 200 毫秒；碰线前松手黑点落回原位、不生成点；命中已有点改为拖动该点；内部点可拖到 α＝0 并保留，端点在 0%／100% 强度固定；拖动曲线上的点不带动底轨圆点；右键“删除控制点”和 Delete 删除内部点并直接提交。
- 「独立不透明度」卡片移除黑场、过渡宽度、Gamma、密度四个输入框与旧手柄；「色阶调整」卡片移除显示模式、四种强度映射和“应用设置”，仅保留区域选择、色带锁定、输入色阶和输出色带。二维与路径切片页面只显示适用的颜色控件；新建路径段默认线性，旧分段映射继续按保存值还原。
