# BandScope 自动轴分配与加载后重设

2026-11-21 · 已实施；已补做 WSe₂ 真实窗口验收（18 项通过）

加载数据时先自动分配轴，直接进入工作区。用户可以随时点击左栏「搜索页面」下方的**数据源卡片**查看和修改分配。第四轴作为扫描轴，支持时间、角度、温度和自定义类型。同一套切帧、区间求和和强度曲线操作使用实际轴名与单位。

## 自动分配

- 分别记录原始数组的哪一维对应 `Kx / Ky / E / 扫描轴`、坐标值取自哪个文件变量，以及扫描轴代表什么物理量。用户既能交换两根等长的轴，也能只把时间改为温度而保留帧顺序。
- 优先采用文件明确声明的轴序和类型，再结合坐标键名、单位和维度长度匹配。保留已有 MAT/HDF5 排列和等长 `Kx/Ky` 的默认顺序。仅凭裸键 `T` 无法区分时间与温度时，将其标为待确认。
- 有歧义也先打开。卡片指出具体疑点，例如「Kx、Ky 等长，按文件顺序分配」。无法识别第四轴时显示「扫描轴（索引）」，按帧号浏览。明确为时间且有文件坐标时沿用缺单位默认 `fs` 的约定。
- NPZ 和 MAT 使用同一套分配规则。MAT 转换保留长度匹配的候选数值向量、原键名和可用单位，包括行向量和列向量。静态三维数据继续按静态显示，带扫描维的三维数据支持补齐缺失的单例分析维。

## 卡片与重设

- 卡片摘要显示当前分配和待确认状态。点击整张卡片或用键盘激活「重新分配轴」，打开当前数据源的分配窗口。即使正在查看裁剪页，窗口也显示**原始数组**的维度和长度。
- 每个分析槽位可选择原始维度，以及等长的文件坐标或索引。扫描轴另外可选时间、角度、温度或自定义，并可编辑名称与单位；同一区域提供只作用于扫描轴的滑块停靠与连续拖动时整段平移设置。窗口预览坐标首末值，支持恢复自动分配，提交前校验维度唯一、坐标有效且长度匹配。
- 只有原始主页、没有裁剪或派生分析时，在当前源应用修改。有裁剪、ROI 或派生页时，按钮明确显示「作为新数据源打开」。只改滑块设置时仍更新当前源，不重新应用轴分配或新建数据源；取消保留原滑块设置。应用后切到新源，原分析可从源切换器返回。取消或应用失败都保留原工作区。重排基于原始强度数组的转置视图，避免为同一大数据体再复制整块内存。

## 分析、导出与复现

- 底部扫描控件、快捷键、区间求和及「切片内强度积分」统一读取扫描轴定义。例如温度扫描可逐点查看，可将所选温区内的帧求和，也可生成横轴为「温度 / K」的强度曲线。角度和温度沿用文件或用户给定的单位，缺单位时只显示名称。
- 图题、坐标标签、出版图、插件宿主提供的帧说明及数值导出同步采用实际轴定义。时间数据继续提供现有时间导出字段，非时间数据导出扫描坐标、类型、名称、单位和所选区间。插件接口以可选字段补充扫描轴信息，兼容现有调用。
- 手工分配保存在当前源会话以及普通、Blender 配套复现文件中。直接重开原始文件时重新自动识别。复现时以文件 SHA-256 验证原始数据，以文件摘要和轴分配共同区分同一文件的不同分析来源。旧复现文件按其保存的轴序与时间含义恢复。
