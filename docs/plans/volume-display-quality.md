# BandScope 体渲染显示与质量改进计划

日期：2026-11-10。状态：首期已实现；自动化、真实数据及 CPU／NVIDIA 开发冻结包验收通过，已随 v1.20.0 发布（2026-11-13，GitHub 与 MatElab），保留维护者人工视觉复核。本文是本事项唯一状态主记录。

## 1. 目标与首期范围

让现有 PyVista/VTK 管线能够独立调节颜色、背景透明度和能带厚度，并通过同参数对照，验证与 Blender 连续体渲染的差异。

首期包含独立透明度、强度归一化、自定义透明度参数、渲染质量及完整保存/导出链路；不包含等值面、自由控制点曲线编辑器、能带拟合或更换渲染引擎。

已确认的默认策略：

- 全新页面使用新显示默认；旧页面、旧复现文件和旧 Blender 工程保持兼容模式。
- 页面复制、派生和跨源恢复继承来源设置，不强制切换新默认。
- 不修改科学强度数组、实验坐标或能带位置。
- 保留工作区已有 Blender 改动。本事项状态统一在本文维护，计划索引只保留入口。

## 2. 显示控制与计算规则

### 控件和归属

沿用现有“背景／增强区域／全部显示”选择方式，每个对象保存自己的颜色与透明度样式；渲染质量属于整个页面。

- **颜色**：保留色带、黑场、白场和颜色 Gamma。
- **归一化**：增加“完整范围、百分位范围、手动范围”；显示实际强度上下限。
- **透明度**：仅在 3D 显示独立卡片，提供阈值、起始过渡宽度、透明度 Gamma、整体密度，均支持滑条和数值输入。
- **自定义**：直接编辑四个透明度参数，默认标记为自定义。2026-11-11 移除预设下拉框与“应用预设”按钮；旧状态中的命名预设仅用于兼容读取，不再提供应用入口。阈值、起始过渡宽度与透明度 Gamma 的标题通过 SiliconUI `setHint()` 提供悬停说明，滑条保留原数值提示。
- 兼容模式保留原四条映射曲线和原计算行为；用户显式切换后启用独立控制。
- 原“复制色带”继续只复制颜色色阶，不悄然扩展为复制透明度或归一化范围。

### 独立透明度

建立统一纯数值显示解析入口，主视图、出版图、GPU 映射和 Blender 导出共用规则。

设归一化强度为 `q=(I−low)/(high−low)`：

- 颜色继续经过自己的黑白场和 Gamma。
- 透明度独立计算：`s=max(q−threshold,0)`，`σ=(density/200) × s^gamma × gate`。
- 过渡宽度为零时不额外衰减；大于零时，`gate` 使用从阈值开始的 smoothstep 过渡。
- 使用 `α=1−exp(−σ×unit_distance)` 转为 VTK 不透明度，单位距离必须与实际体对象一致。
- 新模式下归一化下限及阈值以下完全透明；颜色饱和不截断密度。
- 继续在基础 alpha 后应用插件的一维倍率，不修改插件 API。旧模式保留既有区域距离修正；新模式直接使用统一显示空间密度，避免重复修正。

参数范围：阈值和过渡宽度为归一化强度的 0～100%；透明度 Gamma 为 0.1～4；整体密度为 0～100。

| 新模式预设 | 阈值 | 过渡宽度 | 透明度 Gamma | 整体密度 |
|---|---:|---:|---:|---:|
| 保留弱信号，默认 | 0% | 0% | 1.4 | 12 |
| 突出强信号 | 21.739% | 0% | 1.3 | 40 |

### 归一化和性能

- 新样式默认使用有限样本的 P0～P99.5；黑场 0、颜色 Gamma 1、白场 100，保留现有色带选择。
- 零值参与统计，NaN/Inf 不参与；空数据和常量数据沿用现有保护。
- 兼容现有区域共同范围的包络规则、重叠区域优先级和锁定行为。
- 锁定时同时保存策略及实际范围；派生科学结果沿用现有重新锁定机制。
- 百分位统计按数据代次、区域及策略缓存，在后台计算；拖动颜色或透明度控件不重复统计。统计未完成时不得将旧范围当作精确结果用于导出。
- CPU 为参考实现，同步扩展现有 GPU 映射；不支持的设备明确回退 CPU。2D 使用颜色归一化，alpha 仍为 1。

## 3. 状态、接口与兼容

- 增加统一显示样式结构，承载归一化和透明度配置；页面另存质量配置。明确区分“创建新样式”和“读取缺字段的旧样式”，禁止用新默认补旧状态。
- 覆盖背景、区域、共同样式、控件保存恢复、源切换、复制及派生路径；恢复控件前完整补齐状态，防止沿用上一页面的值。
- 出版快照增加独立副本形式的显示配置、已解析范围和质量设置；导出不得重新读取活动控件或另算百分位。
- 视图复现文件升级至 **schema 2**，读取兼容 1/2。先验证旧文件摘要，再进行内存迁移；新参数纳入摘要保护，不改科学处理节点版本。
- 新 Blender 工程升级至 **schema 10**、编辑格式 2，同步更新导出、回读、编辑对话框及预览。
- schema 7～9 工程继续按旧模式原位更新；启用新显示模式必须新导出 schema 10。保持旧工程相机、材质、文字、灯光及原位更新事务约定。
- 不新增插件能力或第三方依赖。

## 4. 渲染质量与实施顺序

新页面默认采用线性体插值；兼容页面保留原插值和质量行为，允许用户主动切换。

统一主视图与出版图的质量配置，以当前网格最小间距为基准：

- **交互预览**：步长为最小间距的 2 倍。
- **静止标准**：步长为最小间距的 0.5 倍。
- **静止精细／新模式出版图**：步长为最小间距的 0.25 倍。
- 新质量模式关闭自动步长调整，明确设置实际 mapper 参数；停止交互后恢复对应静止质量。
- 修正原生 interactor 的访问方式，验证刷新率设置实际生效，不再静默吞掉错误。
- 不扩展现有数据降采样范围；精确结果和导出保持原生采样。

实施顺序：先确定统一样式与数值契约，再并行实现计算和控件，随后接入状态、导出与质量策略，最后集成验收。主窗口、复现格式和正在修改的 Blender 文件由集成负责人统一协调，避免并行覆盖。

## 5. 测试与验收

**自动化测试使用合成数据：**

- 固定归一化范围时，调整颜色参数不改变 alpha；调整透明度不改变颜色坐标。
- 覆盖阈值、过渡、密度为零、高强度、极弱信号、负值、NaN/Inf、常量数据，以及 CPU/GPU 一致性。
- 检查原始科学数组不变；验证网格分辨率和裁剪变化后的密度语义，以及区域混合、插件倍率只应用一次。
- 验证跨页、跨源、派生、复制、锁定、旧状态迁移和新旧复现文件往返。
- 验证屏幕、出版图和 Blender 使用一致的颜色/alpha；检查 VDB 密度换算及旧 Blender 工程创作内容保护。
- 实际读取 VTK 属性，确认插值、采样步长、预览到静止的切换生效。

**真实数据与视觉验收：**

- 使用默认 WSe₂ 数据检查动态帧、局部增强及交互性能；显式使用本次 Au_cut、NiHITP_cut 检查显示效果。
- 从同一冻结数据生成 VTK 与 Blender 对照，统一相机、坐标比例、归一化和透明度；既有示例作为观感参考，不作为逐像素标准。
- 展示连续体、突出强信号、相同绝对色阶和 E–k 切片，记录背景遮挡、弱带可见性、体素台阶及耗时；不以数据平滑制造“更锐利”的结论。
- 核心验收条件：颜色与透明度可独立调节，新模式无阈值以下的底雾，旧状态不被静默改写，所有输出可复现。
- 运行受影响模块测试及全量 `python -m unittest discover -s tests -t . -v`；补充 CPU/NVIDIA 开发冻结包启动与显示/导出检查。人工视觉与未执行项如实记录，本计划不包含发布。
