03 · 现状 → 目标 对照
维度现状目标
色彩系统 7 个文件散落 30+ 个硬编码颜色，仅深蓝灰就有十余个近似值（#2A2A3A / #2B2B45 / #2E2E48…） theme.py 单一来源：5 级背景 + 3 级文本 + 1 主色 + 4 语义色，全部命名引用
按钮语义 所有按钮统一 #E81123 红色，"加载/确定"与"删除"无法区分 Primary（粉）/ Secondary（灰）/ Danger（红描边）三级，红色只给不可逆操作
布局弹性 左右 7:4 写死、窗口 1550×950 写死、右栏最小 430px；小屏放不下 QSplitter 自由拖拽 + QSettings 记忆分栏；面板可折叠为 40px 窄条
自适应实现 每页手写 _apply_adaptive_layout + 6 个 _adaptive_* 列表 + 十余个 MIN/MAX 常量 居中容器 + setMaximumWidth + QSizePolicy.Expanding，Qt 布局引擎原生完成
用户反馈 39 处模态 QMessageBox，"无法粘贴曲线"也要点确定 轻提示走 Toast（左缘语义色条、3 秒自消）；仅删除/覆盖保留模态确认
全局操作 加载 / 截图 / 保存 / 返回埋在"图像控制"页底部一排红按钮里 上移至顶部工具栏；控制页只保留与当前标签页上下文相关的操作
状态可见性 渲染设备只有一个右上角浮层；无光标坐标、无数据信息 底部状态栏：光标物理坐标 / 强度 / 缓存占用 / 计算后端 / 自动保存状态
键盘操作 无快捷键，逐帧只能拖滑条 方向键逐帧、Ctrl+S/O/1-3/W/C/V 全套快捷键
控件补丁 sync_slider_visual / sync_switch_visual 补丁散在各页 restore_state 里，靠人肉记得调用 封装 SyncedSlider / SyncedSwitch 子类，视觉同步收进控件内部
代码结构 refactored_app.py 7169 行 God Class，UI / 事件 / 分析逻辑混合 拆分为 ui/ 包：theme、widgets、pages、controllers；主窗口只负责装配
