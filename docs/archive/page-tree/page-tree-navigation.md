## 目标与交互（已实施）

将原有窄图标栏和树浮层替换为常驻页面树，采用 Windows 文件导航的操作方式，保留深色主题。

- **完整层级**：按 `source_page_id` 显示父子关系；拥有子节点的页面显示展开箭头，
  点击箭头只展开或收起，点击名称切换页面。
- **拖动调宽**：树与画布之间的分隔条初始 240 像素、最小 180 像素，画布至少保留 320 像素；
  栏宽写入 `QSettings` 的 `result_workspace/nav_width`，跨重启保存。
- **长名称**：列宽跟内容走（`QHeaderView.ResizeToContents` + `Qt.ElideNone`），
  长名称可以横向滚动看全，并保留完整名称提示与页面类型图标。
- **状态记忆**：展开状态按 `page_id` 在会话内保留，排序沿用 `_tab_order`（跨重启保存），
  滚动位置跨重建还原；新增页面自动展开祖先并定位。
- **辅助操作**：树上方提供“全部展开”“全部折叠”“定位当前页”。上下键移动选择，
  左右键收展，Enter 切页。

## 改名、删除与搜索（已实施）

### 改名

- 右键“重命名”或 F2 在树内直接编辑；Enter 或失焦保存，Esc 取消。
- 树内编辑框是挂在树视口上的 `QLineEdit`，提交后才重建树，避免编辑器在重建中被销毁。
- 复用命名规则：`unique_title_among` 是唯一的去重实现，工作区与主窗口共用；
  去首尾空白、空名称保持原名、重名追加编号。
- 右键提供“恢复自动名称”；页眉改名弹窗保留，两个入口都走
  `ResultWorkspace.apply_page_rename`。改名同步树、页眉与导出名称，页面身份与来源关系不变。
  主页可改名，工具页沿用现有限制（`page_kind == "control_panel"` 不可改名）。

### 删除

- 右键“删除页面”、树内 Delete、页眉关闭按钮及 Ctrl+W 走同一个核心 `delete_page`。
- **所有删除都确认**：确认框显示目标名称与删除总数，默认按钮与 Escape 都是“取消”。
  父页连同全部后代删除，数量包含被搜索隐藏的页面。
- 主页及不可关闭页面受保护；包含受保护节点的整支删除不可执行。
- 删除集合包含当前页时，切换到删除根的最近存活父页，没有则回到主页；删除其他分支保持当前页。
- 删除只作用于当前会话的页面和相关状态，原始数据文件不受影响。

### 搜索与排序

- 树顶部按名称做不区分大小写的包含匹配；显示命中页面及其祖先，并临时展开路径。
- 清空搜索后恢复原来的展开状态与滚动位置；无匹配时显示空结果提示，画布保持当前页面。
- “定位当前页”清空搜索并展开祖先。当前页被搜索隐藏时（含新建、外部切换），
  自动清空搜索后定位。
- 支持同级拖拽排序，父节点携带整支移动；跨父节点移动被拒绝。搜索期间禁用排序。

## 实现与接入

- 新增 `bandscope/ui/page_tree.py`：`PageTreePanel`（搜索框 + 工具条 + 树 +
  空结果提示）、`PageTreeView`（点击、键盘、受限拖拽）、`InlineRenameEditor`、
  `PageTreeEntry`（只承载展示数据）。
- `ResultWorkspace` 继续持有页面记录：`QSplitter` 左侧是页面树、右侧是画布与页眉；
  以 `page_id` 关联节点，`set_pages()` 每次喂进最新快照，只在内容或结构变化时重建。
- 删除统一走 `page_delete_plan()` → `_confirm_delete()` → `_apply_delete()`：
  先确定完整集合，按子页到父页清理，逐页发出既有关闭通知，最后统一刷新并激活存活页面。
  `_order_for_removal()` 按层级深度由深到浅排序，父页排在最后。
- 确认弹窗由宿主提供：`set_delete_confirm_handler(handler)`，未设置时（脚本、测试）直接删除；
  `reset_to_home()` 是内部复位，不弹确认。
- 树及编辑框获得焦点时方向键归树或文本编辑；`_focus_blocks_frame_step()` 的类名标记
  增加 `Tree`，并把焦点控件作为可选参数以便离屏测试。数字切页按树中可见行顺序。

### 实施中发现并修掉的问题

- **箭头点击被抵消**：Qt 自身的分支点击也会翻转展开状态，与自定义处理叠加后“看起来毫无反应”。
  改为在 `mousePressEvent` 里处理箭头并吃掉整条事件，Qt 不再参与分支点击。
- **重建时被强制展开**：`_apply_filter()` 在非搜索分支里对所有可见行调用 `_expand_ancestors()`，
  导致每次重建都把整棵树撑开、平时记住的折叠状态失效。只在搜索时展开命中路径。
- **搜索清空后未还原**：退出搜索时没有把 `_expanded_ids` 刷回树，改为调用 `_apply_expansion()`。
- **`_apply_expansion()` 的展开状态没有落库**：新增页面的祖先只在局部变量里展开，
  改为写回 `_expanded_ids`，使其成为唯一来源。
- **长名称滚不到**：隐藏表头时列宽固定，横向滚动条行程为 0，长名称只能靠提示看到；
  把第 0 列设为 `ResizeToContents` 后真正可滚。
- **测试隔离未生效**：`QSettings.setDefaultFormat(IniFormat)` 对两参数构造器无效
  （`format()` 仍是 Native），整套测试一直在读写用户的真实注册表。
  `tests/support/environment.py` 增加构造参数重定向，测试不再触碰注册表。
