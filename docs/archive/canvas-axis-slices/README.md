# 第一阶段：将坐标轴积分迁入画布切片

2026-11-20 · 已实施并完成自动化与真实窗口验收。

本轮移除右侧「对坐标轴积分」卡片。XY、XZ、YZ 成为生成二维切片的入口，切片厚度和位置都在画布底栏调整。「处理分析」页暂时保留时间积分、其他分析动作和插件面板。

## 切片入口与导航

- 在 3D 画布点 **XY、XZ、YZ**，分别沿 **E、Y、X** 轴积分。每次点击都在当前 3D 来源页下新建并打开独立结果页，同一方向可以保留多个区间作比较。
- 新页的白、黑端点分别放在当前有效法向范围的 **25% 和 75%**，初始显示中间一半范围的积分图。按物理坐标跨度计算，缺少标定时使用索引坐标。来源仅有一个可用位置时，以重合锁定状态打开。
- 保留「裁剪」入口。在 3D 裁剪浮窗把一根轴的上下限设为同值并应用，生成该位置的单层切片，底栏初始重合锁定。解锁后可以加厚，另两轴选定的面内范围和后续裁空继续生效。
- 新切片的画布右上角显示 **3D** 返回按钮，点击回到创建它的三维来源页。再次打开该切片时，恢复它自己的端点和锁定状态。三维页上的 3D 按钮继续用于等轴视角。

## 双端区间条

| 操作 | 行为 |
|---|---|
| 拖动端点 | 左端为白色胶囊，右端为黑色胶囊。拖到另一端时停在接触位置，白色外壳包住可见的黑色内芯，长度归零，合并手柄上方出现闭锁浮标。 |
| 拖动中间线段 | 两端按相同的物理位移平移，保持长度。任一端触及轴边界时整段停下。锁定时拖动合并手柄，可以连续浏览单层。 |
| 点击锁浮标 | 播放开锁动画，两端暂时保持原位。随后从重合处向左拖出白端、向右拖出黑端；分开后再次相遇才重新锁定。 |
| 悬停或拖动端点 | 在对应胶囊上方显示可编辑的坐标浮框。鼠标移入浮框可继续编辑，回车或失焦提交，Esc 撤销本次输入。锁定时编辑共同坐标会移动整张单层切片。 |
| 编辑右侧输入框 | 显示区间长度 `上限 − 下限`，沿用当前轴单位。输入长度时以区间中心扩缩，触边后整体移入有效范围。输入零即合拢锁定；锁定期间长度框只读，点击浮标解锁后可输入正长度。 |

## 数据与兼容

- 复用现有 `AxisInterval` 作为每页唯一的区间状态。移除主窗口对旧选轴下拉框、上下限滑条和「应用」按钮的依赖。拖动时走预览刷新，释放或提交数值时做一次精确刷新。
- 切片从**来源页实际用于绘图的三维数值数据**计算，涵盖当前帧、时间积分体、裁剪、裁空和三维二阶导。保存可重建的来源参数和有效坐标范围，使切页、导出和配方恢复都能重现同一结果。
- 保留精确物理端点，计算时各自映射到最近采样层。映射到同一层时直接取该层；跨层时对包含两端的各层强度求和。自动锁定依据两个**物理端点重合**，因此两个不同坐标即使落在同一采样层，也仍可独立编辑。
- 沿用 `axis_integral` 结果类型和现有插件接口。已有积分页、裁剪单层页及其二维二阶导可从旧配方恢复，并使用新底栏。旧非零定宽锁迁移为可编辑区间，保留原端点和结果。同步更新切片、裁剪和 EDC 的使用说明。

## 验收

- 用合成数据逐方向核对初始四分位端点、单层取值和多层求和。覆盖非均匀轴、降序轴、索引轴、E 翻转，以及从裁空体和三维二阶导建页时的实际数值。
- 用 Qt 鼠标事件验证两端相遇、白包黑、解锁后首次分离、整段触边、浮框编辑和长度输入。检查重复建页、3D 返回、跨数据源切换、旧配方恢复，以及加厚后面内裁剪、路径切片和导出的一致性。
- 实施时以当前工作树为基线，保留主窗口、画布工具条和折线路径等已有未提交改动。运行受影响模块测试和全量回归 `python -m unittest discover -s tests -t . -v`，再用 `.local/data/WSe2_step.npz` 验收真实窗口中深浅主题、窄窗口、浮框遮挡和开锁动画。
