# 等能面折线路径切片

2026-11-20 · 已实施，自动化与真实窗口验收通过。

在二维等能面上连续选取并命名路径节点，例如 Γ–K–M–Γ，右键生成独立的 E–k 结果页。横向距离对应沿折线走过的累计动量距离，纵轴沿用源数据的能量坐标，各段可独立调整厚度和显示参数。

## 选点与建页

- 切到可用的 kx–ky 等能面时，在画布右上角现有工具栏显示折线图标。用户点亮工具后，左键才开始落点。按实际视图和数据来源判断可用性，支持从三维谱得到的 E 单层切片、沿 E 积分的动量图及其有效裁剪区域。只有单层数据、无法取得能量维度时，不提供建页入口。
- 左键在图内依次加点并连线，默认命名为 P1、P2……，双击已有点原位改名，允许路径首尾都叫 Γ。双击改名不追加点。右键菜单提供「生成路径切片」和「撤销上一点」，至少有两个位置不同的相邻点才能建页。
- 选点与裁剪、裁空等画布编辑模式互斥。点击色条、轴标题或绘图区之外不会落点。未完成的路径按数据源和页面保留。生成后自动切到来源页下的新子页，保存创建时的节点。回到来源页可继续修改并生成另一张切片。

## 取样与拼接

- 从等能面对应的三维谱提取能量剖面。选点所用的 E 层或 E 积分区间用于定位路径，结果使用来源体中有效的 E 范围。保留来源的数据域、动量裁剪、旋转和去噪语义。四维数据从创建时的帧开始，拖动结果页时间轴可沿同一路径切帧。时间积分来源沿用创建时的积分区间。
- 按各段实际动量长度采样，在 kx–ky 平面做双线性插值。厚度是沿各段法线对称展开的总宽度，默认 0 表示中心线。增厚后对带内有效信号取平均。越界样本不计入平均，无有效样本处显示为空白。
- 横轴从 k = 0 开始累计段长。共享节点只占一列，内部节点归前一段，折返到起点仍保留末端 Γ。动量轴有兼容标定时使用源坐标与单位；缺少可比较的标定时，两轴统一使用网格坐标并在厚度框标明单位。拾取与绘图使用同一坐标变换，覆盖非均匀轴、倒序轴和裁剪后的坐标偏移。

## 结果图与底部工具栏

- 默认在各节点的累计 k 位置绘制竖虚线，点名位于虚线正下方，横轴省略常规数字刻度。右键菜单放置两个独立勾选项「显示竖虚线」「显示点名」，支持四种组合。底部选段条始终保留点名。
- 画布底条增加一行紧凑控件，左侧路径按实际段长比例绘制，节点下标名称；右侧固定放置「切片厚度」输入框及单位。沿用现有图标、数值输入框与深浅主题。选中段以强调色和加粗线条表示，短段扩大点击热区，密集标签错层显示，窄窗口优先给路径条独立一行。
- 默认选中第一段。普通点击切为单选，Shift 点击逐段加入或移除，支持跳选。厚度、黑场、灰场、白场和强度映射只作用于选中段，色带配色整页共享。多选时各控件分别回显共同值或「多值」，只写入用户改动的字段。取消全部选择后禁用分段编辑。单选时色条标明对应段，多选且映射不同时隐藏单一色条。
- 根据绘图区高度、能量采样行数和沿路径的采样间距确定横向显示尺度。路径超出可见宽度时，用水平滑条平移 k 窗口，E 轴和底条保持固定。底条保留整条路径概览，点击视口外的段会将该段滚入视野。

## 接入与验收

- 新增内置结果类型 `path_slice`。页面模型保存来源、节点、分段参数及两个标注开关。数值采样、二维绘制和选段控件分别放入 processing、rendering 和 ui，主窗口负责接入。原始强度与显示映射分开缓存，改厚度只重算受影响段，改黑灰白场只刷新显示。
- 接通页面复制、数据源切换和视图复现。数值导出包含完整累计 k、E、原始强度及路径元数据，出版图按完整路径和当前标注设置出图。
- 合成数据验收覆盖直线、折线、闭合路径、不同段宽、边缘取样、非均匀及倒序坐标。用已知强度分布核对选点位置、节点累计距离和拼接列数，用均匀信号验证增厚不改变均值，用横向有变化的信号验证厚度确实生效。
- 交互验收检查双击改名不会多出一点、Shift 跳选只改指定段、虚线与点名可独立开关、时间切帧保留路径，以及窄窗口滚动前后同一谱带宽度一致。运行受影响模块测试及全量 `python -m unittest discover -s tests -t . -v`，再用 `.local/data/WSe2_step.npz` 在深浅主题下做真实窗口验收。
