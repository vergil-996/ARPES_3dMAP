# BandScope v1.17.4

本版让复现文件与数据源位置解耦，并统一时间轴的单位约定。

- **复现文件不再保存数据源路径**：`.bsview.json` 的来源记录只保留 SHA-256、数组 key、形状、轴映射与坐标来源，不再写入 NPZ 路径。加载时每次都要求用户通过原生对话框选择主原始 NPZ，程序随后核对摘要与解析信息；取消选择、摘要不符或提交失败都保留现有数据源与后台任务。旧版 JSON 里遗留的 `path` 读入时被忽略，不再用于自动定位；仅用于快照引用的额外数据无需选择。
- **时间轴单位约定**：新增 `bandscope.core.axis_units`，`resolve_axis_unit` 只给时间轴（`delay`）补默认单位 `fs`，其余轴继续只转述显式单位元数据、缺省不猜。宿主在时间滑条读数、出版图 Delay 轴标签、插件 `AnalysisInput2D` / `DerivedAxis` 边界统一走这一处；文件声明了时间单位时如实使用。
- **修正时间轴标题**：切片积分曲线的标题之前写死 `Delay (ps)`，现在按同一单位约定生成，缺单位时显示 `Delay (fs)`。
