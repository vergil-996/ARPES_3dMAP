# BandScope v1.13.0

本版把 EDC 瀑布图迁移为独立插件（插件接口新增 API 3），并统一瀑布页的 E 翻转口径。

- **EDC 瀑布图迁入插件（`edc_waterfall` 1.0.0）**：「其他积分」里的入口由插件注册，未安装或未启用时不出现；创建时冻结来源（时间帧或时间积分区间、积分范围、矩形裁剪范围与数据域），采样、逐曲线归一化与自动命名由插件完成。绘图、裁剪、出版与数值导出仍由宿主负责，插件不建页、不写文件。带擦除区域的来源按分析插件同样的契约拒绝。
- **插件管理新增「插件设置」页**：EDC 瀑布图提供自动 / 手动 k 步长（自动 = 完整未裁剪 k 轴的中位相邻间距，下限 0.0001、回退 0.01；手动 0.0001–10）。「保存为新建默认值」写入本机设置，对之后新建的瀑布页立即生效；「应用当前瀑布图」先按新参数试算，通过后只更新当前页，其他页面保留各自参数，失败时保留上次成功结果并在图上标注。用户改过页面名时，自动标题只更新底层默认名。
- **瀑布页 E 翻转改为定向翻转**：能量轴与采样一起反序，同一个 E 坐标在翻转前后对应同一强度，屏幕、出版图与数值导出因此保持一致；数值导出保持原始坐标排列。同时修复二维分析插件快照与画面方向不一致的问题（数组与坐标一起翻转，`data[i, j]` 与 `(x[i], y[j])` 一一对应）。
- **「其他积分」下拉改用稳定动作键**：插件动作以 `插件ID:动作ID` 进入下拉并随页面状态保存，按权重与内置项统一排序；插件缺失时回退到可用内置项，旧状态按展示文本恢复，不再因下标漂移误选其他功能。
- **插件接口新增 API 3**（能力 `integration_action` / `derived_result` / `plugin_settings`），继续支持 API 1 与 2；新插件按 `.bsplugin` 单独签名发布，本版 Release 首次包含 `edc_waterfall`。
