# BandScope v1.14.5

本版修复局部增强区域的右键删除与数字键输入冲突，并把区域下拉框改为 SiliconUI 可编辑框。

- **局部增强区域下拉框**：改用 SiliconUI 可编辑胶囊下拉框，仍可在框内重命名当前区域；条目右侧的 × 删除入口移到左侧视图右键，菜单显示「删除增强区域「R1」」。下拉框悬停气泡提示已移除。
- **3D 右键删除**：`vtkPropPicker` 原先只能命中区域框轮廓线；现在框内部（空白体素）也会按八个角点的屏幕投影凸包做命中测试，右键区域框内部即可删除对应区域。
- **数字键输入冲突**：可编辑下拉框现在可正常输入 `1`–`4`。数字键 `1`–`4` 只按页面树可见顺序切换左侧结果页，不再切换右侧「渲染控制 / 处理分析」；右侧仍可用 `Ctrl+1` / `Ctrl+2`。

验证（Windows、仓库 `.venv` Python 3.12、原生 Qt 窗口、可用 OpenGL）：

- 全量 `python -m unittest discover -s tests -t .`：**1308 项通过**。
- 真实数据 `.local/data/WSe2_step.npz`：`scripts/validation/verify_local_enhancement.py` **160 个检查通过**，覆盖 2D/3D 右键命中与删除、SiliconUI 下拉框、删除后的色带/轮廓与科学数据不变。
- `scripts/validation/verify_enhancement_outline_visibility.py` **24 项通过**；`scripts/validation/verify_page_shortcuts.py` 全部通过，确认数字键只切左侧、不再切换右侧控件页。
