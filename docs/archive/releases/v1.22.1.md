# BandScope v1.22.1

本版是 v1.22.0 的发布修正：修正积分区间控制器在底栏控件已被销毁后仍访问控件导致的进程崩溃——该缺陷使 v1.22.0 的 CI 全量回归在 `tests.integration.test_axis_interval_pages` 处中断，v1.22.0 未产出 Release。功能与 v1.22.0 相同，另补两条回归覆盖。

## 发布修正（相对 v1.22.0）

- **积分区间控制器**：底栏区间条的输入框与滑条在底栏销毁后 C++ 对象已不存在，控制器却仍持有其 PyQt 包装；迟到的 `editingFinished` 会在同步中访问已销毁控件并抛 `RuntimeError`。该异常从 Qt 槽冒出会终止进程，CI 上表现为全量回归在区间模块处以 exit code 1 结束。现在所有控件访问先判断 `sip.isdeleted`，销毁后一律跳过；`attach()` 重新装配前先断开旧控件，避免旧控件把信号送进新状态。
- **测试清理**：区间页面集成测试不再把无父控件的底栏留给循环 GC 回收，改为每个测试结束显式 `deleteLater()` 并处理事件队列，避免 GC 在别的测试绘制中途销毁控件（Windows 原生 `0xC0000005`）；另新增「控件销毁后同步与迟到信号不访问已销毁对象」「重新装配断开旧控件」两项单元测试。

## v1.22.0 功能

本版重做数据轴分配与画布交互：加载后自动分配 Kx／Ky／E／扫描轴并可在数据源卡片重设；扫描轴支持时间、角度、温度与自定义。画布视图控件移到右上角悬浮工具栏，Z 轴旋转改为旋钮弹层，底栏改为位置与时间两组双端区间，并新增折线路径 E–k 切片与画布轴切片。外观控制改为累计直方图输入色阶、可编辑不透明度曲线与「输出色带」菜单，计算后端、渲染质量与去噪参数收进分级设置窗口。视图复现文件与 Blender 工程格式同步升级，旧文件仍可打开。

- **自动轴分配与数据源卡片**：加载 NPZ／MAT 后先自动分配 `Kx / Ky / E / 扫描轴` 并直接打开工作区，左栏「搜索页面」下方的数据源卡片显示当前分配与「待确认」状态（例如「Kx、Ky 等长，按文件顺序分配」）；无法识别第四轴时显示「扫描轴（索引）」按帧号浏览。点击整张卡片或用键盘激活可打开「重新分配轴」窗口，即使当前在裁剪页也显示原始数组的维度与长度；每个槽位可选原始维度及等长的文件坐标或索引，扫描轴另可选类型、名称与单位，窗口预览坐标首末值并支持恢复自动分配，提交前校验维度唯一、坐标有效且长度匹配。MAT 与 NPZ 共用同一套规则，转换时保留长度匹配的坐标候选、原键名与单位（含行／列向量）。
- **扫描轴（时间／角度／温度）**：底条扫描区间控件、←／→ 快捷键、区间求和、「切片内强度积分」、图题与轴标签、出版图、数值导出及插件可选 `scan_axis` 统一使用实际轴名与单位，例如温度扫描可逐点查看、对所选温区求和，并生成横轴为「温度 / K」的强度曲线；时间数据保留缺省 `fs` 与旧导出字段，角度和温度缺单位时只显示名称。只有原始主页时在当前源应用重设；已有裁剪、ROI 或派生页时以「作为新数据源打开」，取消或应用失败保留原工作区。手工分配随当前源与普通／Blender 配套复现文件保存，同一文件两种分配互不串源，直接重开原始文件会重新自动识别。重排使用原始强度数组的转置视图，不复制整块数据体。
- **画布悬浮工具栏与 Z 轴旋钮**：「显示坐标」「图像翻转」「Z 轴旋转」从底栏移到画布右上角悬浮工具栏，前两项改为图标开关并在开启时高亮。Z 轴旋转改为按需展开的原生旋钮弹层：拖动外圈从当前角度连续旋转（跨过顶部保持连续，到 ±360° 停止），中央可直接输入两位小数的带符号角度，上下键按 `1°` 步进，回车或结束编辑提交，「归零」立即回到 0° 且不改变相机位置与朝向；再次点击 Z、点面板外或按 Esc 收起。拖动期间只预览，松手提交一次精确刷新。底栏宽度因此全部留给位置与时间滑条；窗口高度不足时视角预设组自动收起，右侧面板标题区重复的「重置视角」按钮移除。
- **坐标轴切片与位置区间条**：3D 画布右上角的 XY／XZ／YZ 从视角预设改为切片入口，分别沿 E／Y／X 轴积分，并在来源页下新建独立结果页，同一方向可保留多个区间比较；新页默认只显示有效法向范围的 25%–75%，右上角出现 3D 按钮返回来源页。原「对坐标轴积分」卡片的选轴、上下限与「应用」按钮移除，位置与厚度改由底栏双端区间条控制：黑白两枚胶囊手柄拖到接触即停并自动锁定，重合时显示白壳黑芯与锁浮标，点浮标播放开锁动画后再向两侧拖开；拖中段整体平移，悬停端点出现可编辑坐标浮框（回车或失焦提交、Esc 撤销），右侧长度框按「上限 − 下限」输入并以中心扩缩。每个切片页保存自己的端点与锁定状态。
- **时间区间并入底栏**：时间轴改为同一套双端区间控件，两端合拢时逐帧，分离后对当前视图做时间积分；拖动合并手柄或按 ←／→、Shift+←／→ 逐帧，解锁后两端可分别展开，长度框输入 0 恢复单帧。原来「先在处理分析页设积分再生成独立结果页」的流程取消，积分直接作用于当前视图；3D、2D、EDC、能级态密度、二阶导、路径切片与可重算的插件派生页都可直接调整，完整时间曲线与纯曲线快照页不显示该控件，每页独立保存区间。底条只排布位置与时间两组：同时显示时等分宽度、空间不足换两行、只有一组时占满、都隐藏时折叠；同时修正时间轴选区在部分主题下被画成黑色的问题。
- **折线路径 E–k 切片**：在 kx–ky 等能面或 E 积分动量图上点亮画布右上角的折线工具后，左键依次落点连线，双击节点原位改名，右键可生成路径切片、撤销上一点、清除选点或退出；至少两个位置不同的相邻点才能建页，生成后自动进入来源页下的 E–k 子页。横轴是沿折线累计的动量距离，纵轴沿用来源体有效能量范围；按各段实际动量长度采样并做双线性插值，支持闭合路径、非均匀／倒序坐标、裁剪、旋转、去噪、时间切帧与增厚平均（厚度为沿段法线对称展开的总宽度，0 表示中心线）。底部选段条按真实段长绘制整条路径，普通点击单选、Shift 点击跳选；厚度与黑灰白场、强度映射只写入选中的段，多选时回显共同值或「多值」并只写入改动字段；长路径可用水平滑条平移 k 视口，底条保留整条路径概览。数值导出、出版图、页面复制、数据源切换与复现都保留完整路径与分段参数。
- **右键「创建结果页」**：右侧不再有独立的「处理分析」页，直接显示外观控制，原下拉入口与 `Ctrl + 2` 一并移除。切片内强度积分、能级态密度、EDC 瀑布图、单条 EDC 曲线、二阶导与 API 3 插件结果改为在来源树或「我的分组」的页面副本上右键「创建结果页」：菜单按父页页型、时间轴、已保存裁剪参数与插件就绪状态动态过滤，只显示合法动作，打开菜单不切页，点击后才激活父页并再次校验。新复现文件不再保存旧的类型下拉选择，读取旧文件时忽略该选择。
- **输入色阶与输出色带**：「色阶调整」改为上下两组。上组是「输入色阶 · 累计直方图」加黑、灰、白三枚胶囊手柄（与时间轴区间滑块共用 10×16 样式），直方图柱高表示强度不低于该阈值的累计点数，悬停显示阈值和点数；黑白点设定输入强度上下限，灰点决定映射到色带中点的强度（向左提亮、向右压暗），拖黑白点时保留当前 Gamma，三枚手柄始终有序并支持方向键微调。下组「输出色带」横向铺满当前色带，下方两枚小房屋标记选择原色带的输出子区间（默认 0%–100%），选区外淡遮罩并显示百分比；截断只改颜色，不改变透明度的强度坐标。统计对象跟随当前帧与调整目标（三维统计有效体素、二维统计当前切片、局部区域、全部显示），使用上色前强度并排除 NaN／无穷；二维图、三维体、屏幕色标、出版与 Blender 导出共用同一截断结果。
- **「输出色带」菜单**：删除原来的「色带选择」卡片及其「确定」按钮，色阶卡片内的「输出色带」标题行成为主界面唯一的色带入口：右侧显示当前色带名与下拉箭头，点击展开带完整渐变色样、名称与当前项勾选的可滚动单列菜单；列表以 `magma`、`coolwarm` 开头，其余保持原有相对顺序，`coolwarm` 只出现一次，默认 `magma`。选中另一条色带后菜单收起、渐变条立即更新、当前视图只精确刷新一次；悬停、取消或再次选择当前项都不触发渲染。换色带保留当前输出区间（例如 `magma` 的 15%–80% 切到 `coolwarm` 后仍停在 15% 和 80%），缺少色带值的旧状态回落到 `magma`，Blender 导出窗口复用同一份列表。
- **三维不透明度曲线直接编辑**：删除「强度归一化」「显示模式」「强度映射方式」及「独立不透明度」的黑场、过渡宽度、Gamma、整体密度四个输入框，三维不透明度改为一根可直接编辑的曲线，新页面默认三点 `(0%, 0) / (50%, 0.5) / (100%, 1)`，默认色阶下与旧「兼容映射 → 线性」逐体素一致。底轨圆点水平定位强度，向上拖时黑点脱离轮廓、沿竖直虚线随光标上移，碰到曲线即插入并选中新点，原位轮廓约 200 毫秒回填；碰线前松手不生成点，拖回底轨可继续水平拖动。曲线上的点同时调整强度与 α（横向限制在相邻点之间），两个端点固定在 0%／100% 强度并可上下调整，内部点可拖到 α＝0 并保留；右键「删除控制点」或焦点在曲线上时按 `Delete` 删除内部点，端点始终保留。强度范围统一为完整范围，颜色与透明度独立计算；CPU、CUDA、出版导出与 Blender 体密度换算共用同一条曲线与参考距离，Blender 工程编辑窗口复用该控件。二维与路径切片页面只显示适用的颜色控件，新建路径段默认线性，旧分段映射仍按保存值还原。
- **分级设置窗口**：右上角齿轮从菜单改为非模态「设置」窗口，左侧按「计算与显示」「数据处理」「应用管理」分级，重复点击复用同一窗口。计算后端（Auto／CPU／NVIDIA GPU，GPU 不可用时禁用并说明原因）与 3D 渲染质量（质量模式、体插值、静止质量）移入「计算与显示」，即时作用于当前 3D 视图并记住，跨数据源与重启共用；渲染质量改为全局本机设置，不再随页面或复现文件变化。去噪参数内嵌到「数据处理 → 去噪参数」，不再弹独立小窗；插件管理与更新设置移入「应用管理」，原齿轮菜单的三个入口不再存在。
- **复现文件与 Blender 工程格式**：视图复现升到 schema 5，不透明度保存为按强度排序的归一化 `(强度, α)` 点列并保存输出色带区间；读取 schema 1–4 时先按原格式校验原始摘要再迁移，旧四参数／兼容曲线按原公式转换并自适应补点（参考距离下 α 误差不超过 `1/255`），旧百分位／手动强度范围转为完整范围，旧锁定按恢复帧重建，旧时间积分页恢复为当前视图的时间积分状态。Blender 工程升到 schema 12、显示编辑格式 3，编辑窗口直接编辑同一条曲线；schema 7–11 工程仍可打开并原位更新（7–9 保留原预设，10–11 继续以四参数与格式 2 更新，需要自由控制点时重新导出），Blender 配套复现升到 schema 2（内嵌视图配方 schema 5），schema 1 仍可读取。
- **其他**：出版图与 Blender 导出对均匀网格的判定放宽到 `float32` 坐标舍入——步长差异只来自低精度坐标舍入时不再误报「非均匀网格」，原坐标与强度不被重采样，真正非均匀的轴仍给出明确提示。EDC 瀑布图插件升至 1.0.1，代码不变、仅同步新宿主「右键 → 创建结果页」入口的说明（旧宿主仍在「其他积分」下拉提供同一动作）；`flat_band_opacity` 仍为 1.2.3。
