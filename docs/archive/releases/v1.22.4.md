# BandScope v1.22.4

本版为第四轴滑块加入停靠与平移设置，把三维不透明度曲线升级为可切换平滑／直线并支持垂直阶跃，并把 24 个 Fluent 按钮图标改为按实际物理像素绘制的可缩放图标。视图复现升到 schema 6、Blender 工程升到 schema 13（显示编辑格式 4）；旧复现文件与 Blender 工程仍可打开并按原有格式回读。

## 主要变更

- **第四轴滑块停靠与平移**：页面树上方数据源卡片新增「滑块」菜单，提供「滑块停靠」（自动／离散停靠／连续拖动）与「连续拖动时整段平移」（保持物理宽度／保持帧数）。自动模式按采样点数选择：少于 30 点离散停靠、30 点及以上连续拖动，菜单始终显示当前生效的模式。设置按数据源保存在本次会话，同源页面共用；修改不影响当前选区，从下一次拖动生效，单独改拖动设置不必重新应用轴分配。离散模式下手柄吸附最近的采样坐标，整段移动按相同帧数平移；连续模式下可停在两个采样点之间，整段平移按「保持物理宽度」或「保持帧数」执行；整段拖到轴端时一起停止，升序、降序与不等间距坐标同样适用。
- **不透明度曲线平滑、直线与垂直阶跃**：「不透明度」标题行右侧新增「平滑／直线」双段选择器，新曲线默认平滑。平滑采用保形三次插值（PCHIP），经过各控制点、保留平台且峰谷无过冲；直线沿用逐段线性。相邻点强度相同时形成垂直阶跃，精确命中该强度时取最后一个点的 α。移除固定最小间距、近邻合并与端点吸附，控制点可任意接近甚至重合，拖到邻点即停、反向拖动可重新拉开。沿平滑曲线加点会精确拆分原三次曲段并保留两侧切线，连续加点、平滑／直线往返与保存重开都保持原曲形；CPU、CUDA、编辑器绘制、出版导出与 Blender 体密度共用同一套曲段求值与阶跃规则。插值模式与曲段系数随显示样式、页面复制、视图复现与 Blender 编辑保存；视图复现升到 schema 6，Blender 工程升到 schema 13、显示编辑格式 4，旧点列、旧四参数与兼容映射曲线读取时明确还原为直线。
- **按钮图标高 DPI**：24 个 Fluent 按钮图标改为从现有 SVG 资源实时绘制的 `QIconEngine`，按目标物理像素绘制，100% 缩放下与旧版逐像素一致，125%、150%、175%、200% 按目标尺寸重绘。主窗口顶栏、画布工具条、页面树、数据源与工作区标题、出版导出、Blender 标题及宿主插件列表统一走公共图标入口，并按用途显式设置 14／15／16／18／20 逻辑尺寸；深浅主题、禁用／活动／勾选状态、专注模式切换与图标缺失回退保持原行为。数据源数据库、工作区页面类型与 Blender 标题三个装饰标签改为在重绘时绘制图标，跨屏移动跟随所在窗口的当前绘制设备。
