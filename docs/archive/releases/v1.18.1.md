# BandScope v1.18.1

本版在左侧页面树下方加入应用级「我的分组」，可把任意数据源的页面复制成相互独立的副本集中存放，并修复来源树拖动排序的时序问题。

- **我的分组**：左侧页面树下方新增「我的分组」区域，「+」新建分组，默认名「新建分组」、重名自动编号；`F2` 或右键可改名，右键可删除分组。分组不属于任何一份数据源，切换数据源时保持显示，也不进入数据源会话状态包。
- **复制页面到分组**：把来源树中的页面拖到分组上，或在来源树选中页面后 `Ctrl+C`、选中分组后 `Ctrl+V`（右键菜单同样提供「复制页面」「粘贴页面到此分组」），都会生成一份带新 `page_id` 的深拷贝副本，标题追加「 副本」并自动去重。原页面留在原树，顺序与参数不变；副本的改名、参数修改和删除都独立。拖放只复制，来源树内的拖动排序仍是移动。
- **副本跨数据源激活**：分组副本记录所属数据源。激活属于另一份数据源的副本时，宿主先切回该数据源，并在这一次安装中直接选中副本，不在错误的数据上刷新。关闭数据源只删除它自己的副本，其他数据源的副本与分组保留；删除分组会删除组内副本，不影响原页面。搜索仍只过滤来源树。
- **拖动排序时序修复**：来源树内的排序请求改到 Qt 完成 `InternalMove` 源行清理之后重发，避免拖动后按旧记录重建、丢掉一行；分组区域只接收投放，从不移动来源页面。
- **分组生命周期**：分组与副本只存在于本次运行内，重启后清空；分组不写入 QSettings，也不进入复现文件。
