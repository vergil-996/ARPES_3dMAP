# BandScope v1.23.2

本版修正大数据连续拖动旋转旋钮时中间预览可能一帧都不出、只能看到松手后最终结果的问题：同一次旋转中，已经计算完成且未被更新输入超越的预览会实际呈现；更新的已呈现帧、其他交互或精确刷新派发仍会丢弃旧预览。

## 主要变更

- **连续拖动中间帧交付**：刷新协调器记录每页最新的交互原因、已呈现代次与精确派发代次。同一次旋转中，最近完成且尚未被超越的预览可以晚于更新的拖动输入交付，并按该请求自己的旋转角度构建画面，交付后恢复旋钮的最新输入角度；`axis_integral`／`axis_integral_crop` 的数组、法向区间与坐标语义不变。
- **旧预览阻断与缓存命中**：更新的已呈现帧、其他交互、页面取消或精确刷新派发都会让旧预览失效；不经过工作队列的缓存命中帧也计入已呈现代次，避免随后重绘同一帧。精确结果完成前，对确认裁剪／裁空和需要精确来源的局部增强的保护保持不变。
