# BandScope v1.16.0

本版新增多数据源工作区与顶部数据源切换器：每次成功加载数据都新增独立工作区，保留此前的数据与分析。

- **多数据源工作区**：`npz`、经转换的 `mat` 与 `.bsview.json` 复现文件都会新增独立工作区，不再覆盖已打开的数据。每份数据保留自己的页面树、帧号、参数、相机、裁剪、轴标题、插件面板与出版草稿；多份数据共用一套窗口、渲染器和插件实例，原始数据只保留一份缓冲区。
- **顶部可编辑切换器**：位于「加载数据」右侧，默认显示文件名（复现文件去掉 `.bsview.json`）。只有两份及以上数据时以 220 ms 宽度展开＋淡入，返回一份时反向收起；框内可直接改名，`Enter` 或失焦提交，`Esc` 撤销，空名称恢复默认名，重名自动追加序号。提示气泡区分入口文件与实际主 NPZ。
- **源级关闭**：删除左侧根视图等于关闭整份数据源，级联清理隐藏后代、固定工具页、裁剪、轴标题、出版草稿、缓存和所属任务，然后切到前一份数据源（没有前一份则切到后一份）；最后一份关闭后回到未加载界面。
- **复现文件改为新增数据源**：打开 `.bsview.json` 不再提示替换当前分析。预检全部成功后恢复来源分支、目标页、显示、相机与出版草稿；预检失败、重新定位取消或提交失败都不会改变已有数据源和后台任务。导入时页面 ID 重新分配为全局唯一，后续配对导出仍按现有捕获与校验流程生成新文档。
- **后台任务与缓存归属**：切源使旧源的显示预览与未完成去噪失效，配置保留、切回按需重算；已提交的插件分析继续执行，完成后核对所属数据源、页面与处理代次，登记回原工作区且不抢焦点，来源关闭或结果过期则丢弃。跨源复制曲线保留不可变来源闭包。可重建 CPU 缓存共用全应用预算 min(4 GiB, 物理内存×20%)，不随数据份数倍增。
- **默认视角修正**：新数据首次 3D 渲染完成后再执行默认取景，避免加载途中场景尚无体积时 `reset_camera()` 取到空包围盒导致首屏看不到数据。
