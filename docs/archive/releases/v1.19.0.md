# BandScope v1.19.0

本版新增独立的 Blender 工程导出入口：多页面跨数据源导出、四项预设、八材质薄层长方体，以及工程回读和显示参数的原位更新；出版图导出同时增加 PDF／SVG／AI 矢量输出、标题与轴名拖动、坐标轴主刻度数量设置，分组支持嵌套子分组。

- **Blender 工程导出**：顶部新增独立的「导出 Blender 工程」入口（与「截图样式」并列），按「数据源 → 3D 页面」勾选，可跨数据源、同源多页导出。每个选中页面生成独立数据组、父对象、体材质与 VDB，按页面树顺序沿世界 X 排布并自动避让；沿用该页自己的色带、色阶、gamma、不透明度、局部增强、插件倍率、裁剪与时间帧。导出前在 GUI 线程逐页精确冻结，成功、失败或取消都恢复原数据源、页面、参数与相机。工程通过相对路径引用同名 `.assets/`，移动或分享时需携带整个目录。
- **四项预设与八材质薄板**：预设合并为四项——坐标轴及文字、辅助盒框、方向标、薄层长方体，默认全选。勾选薄层长方体后每个条目生成八块独立薄板，统一使用默认橙色与各材质默认参数；四种自发光／透射材质在右侧，四种受光材质与配套 Area 灯在前侧并上移半层，两组移到数据体后八层高度交替；导出面板不再提供材质与布局设置区。
- **工程回读与原位更新**：可打开 BandScope 导出的 `.blend`（含 Zstandard／gzip 压缩工程），恢复强度、色阶、色带、不透明度、相机与已有创作对象，在宿主内调整显示参数后「更新工程」。更新只替换条目 VDB、数组与 `scene.json`，不改写 `.blend`，保留在 Blender 中新增的相机、灯光、排版、附加对象与材质编辑。工程 schema 升为 8，仍可读取 schema 7 并保留其原版本与薄板配置；schema 6 及更早只做有限恢复。
- **出版图矢量输出**：图片导出新增 SVG 与 AI（Adobe Illustrator），PDF 扩展到 3D 视图。3D 的 PDF／SVG 为混合输出：体渲染主体是栅格，文字、坐标与色条保持矢量；PNG／PDF／SVG 支持透明背景。AI 由本机 Illustrator 把 PDF 转为原生 `.ai`，未检测到 Illustrator 时该项禁用并回退 PNG。
- **标题与轴名可拖动**：大图预览中可直接拖动图标题、各轴标题、色条与三轴方向标，松手后重新生成完整预览；手动位置随当前样式保存并用于正式导出，拖出画布会被收回可见区，调整标题排版会清除标题的手动位置。
- **坐标轴主刻度数量**：「微调」新增 2–8 的主刻度数量，2D／3D 的刻度、网格与标签一起调整；1D 在「坐标」页单独设置的轴刻度数量优先。
- **嵌套子分组**：分组右键可「新建子分组」，子分组可继续嵌套并接收页面副本；删除父分组级联删除整支子分组及其副本，不影响原页面；切换数据源后分组保持不变。
- **数据源名称同步根页面标题**：修改数据源别名后，左侧根页面标题同步更新为同一名称，不再出现下拉框与页面标题两套名字。
- **其他**：主窗口「E轴翻转」开关更名为「图像翻转」；同步滑块的数值标签随程序设值刷新；保存对话框按 PDF／SVG／AI 过滤器补全扩展名。
