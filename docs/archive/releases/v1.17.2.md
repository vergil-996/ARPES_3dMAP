# BandScope v1.17.2

本版修正出版图的跨 DPI 排版：排版按固定物理字形度量，输出 DPI 只决定栅格分辨率。

- **排版与输出 DPI 解耦**：预览、夹取与正式导出共用一条测量路径，按固定 150 DPI 的物理字形度量计算注记包围盒；输出 DPI 只决定最终位图分辨率。同一份样式在 80 / 150 / 180 / 600 DPI 下主图区与色条位置、完整注记夹取到图幅内的结果一致。
- **色条边界余量**：完整色条包围盒增加 1pt 余量，吸收不同分辨率下字形栅格的取整差异，避免高 DPI 时标签被裁切或位置漂移。
- **方向标与 E 轴镜像兼容**：3D 方向标跟随相机姿态；2D 色条图层提取与位置调整不改变图像数组、原始坐标或显示轴方向，导出面板沿用冻结快照，主窗口翻转后可用「更新预览」重新捕获。

验证（Windows、仓库 `.venv`、原生 Qt 窗口、NVIDIA OpenGL）：

- 全量 `python -m unittest discover -s tests -t .`：**1451 项通过**（2026-10-21）。
- 导出模块 214 项通过，覆盖方向标投影、色条位置、跨 DPI 排版一致性、E 轴镜像兼容与 Qt 鼠标拖动。
- 80 / 150 / 180 / 600 DPI 下主图区与色条位置、完整注记夹取结果一致，输出 PNG 分辨率正确；临时测量后恢复目标 DPI。
- 真实窗口脚本 34 项通过、2 项失败。失败为既有布局边界——`body_size=250` 且同时开启带刻度坐标轴时报「画布尺寸过小」，关闭方向标的对照同样失败，详见 [截图方向标交接](https://github.com/vergil-996/ARPES_3dMAP/blob/v1.17.2/docs/handoffs/screenshot-orientation.md)。
