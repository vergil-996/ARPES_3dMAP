# BandScope v1.21.0

本版重做桌面界面：新增深色／浅色双主题（新环境默认浅色），把工具栏、参数面板、页面树、结果页标题、状态栏与各次级窗口统一为中性黑白灰样式；画布顶部新增视角预设与常用操作工具条，数值输入框支持按光标所在数位滚轮微调，2D／3D 画布背景与坐标轴配色跟随主题；多视图 Blender 工程的辅助预设改为只生成一组。

- **深色／浅色主题**：顶部工具栏新增「深色／浅色」分段按钮，新环境默认浅色。切换时重着色已创建控件：改写控件 QSS 中的颜色令牌、刷新 SiUI 色板与 Qt 调色板、重取图标颜色、更新 2D／3D 画布背景；出版导出、扩展管理、Blender 工程、更新设置与弹层等次级窗口一并跟随。当前页面的数据、参数与相机保持不变，选择写入本机设置（`ui/theme`）供下次启动恢复。界面强调色随主题取深灰或浅灰，删除等不可逆操作仍用语义色。
- **主窗口与面板布局**：顶部工具栏、右侧检查器、结果页标题与状态栏重新排布并收紧间距；结果页标题显示数据源面包屑、页面标题、视图类型标签（3D VOLUME／2D MAP／1D CURVE）与数据域标签；页面树新增「工作区／PAGES」标题与数据源摘要卡片（别名、文件名、形状与计算后端），仅有一个数据源时在工具栏显示数据源徽标。参数分组改为可折叠的扁平分组，标题可点击展开／收起，滚动区在折叠后重新计算高度；控件宽度、按钮与下拉框尺寸同步收紧。
- **画布工具条**：画布顶部新增悬浮工具条，集中提供 3D／XY／XZ／YZ 视角预设、重置视角、裁剪、裁空、导出结果与「专注画布」；视角预设按钮随实际相机姿态回读切换，专注模式隐藏分析与页面侧栏，再次点击恢复。
- **数值输入滚轮**：新增应用级滚轮过滤器。光标停在数值框的某个数位上时，滚轮按该位步进（整数、小数与科学计数法均适用），执行后光标停留在同一数位；滑块与数值输入的双向同步、裁剪弹层与插件面板中的数值框保持一致。
- **画布与曲线配色**：2D 预览的背景、坐标轴、刻度与标题颜色改为跟随主题，3D 背景使用主题画布色，并在加载数据与切换主题后恢复，不再固定黑底；屏幕坐标轴与曲线身份色改用与主题一致的中性色板，出版图仍使用独立的白底曲线身份色，本版未改变出版配色。
- **次级窗口**：出版导出窗口改为左侧预览、右侧可滚动选项的双栏布局，标题改为「出版级导出」，样式卡片缩小并保留原有选项；扩展管理、Blender 工程窗口增加图标标题与说明文字，标签页、表格与按钮风格统一；勾选框图标按主题提供 `assets/ui/check-light.svg` 与 `check-dark.svg`。
- **Blender 多视图共享预设**：多页面工程只在首个视图生成一组五类辅助预设（坐标轴及文字、辅助盒框、方向标、薄层长方体、文本预设），其余视图只创建数据体、备用相机和自身需要的数据体灯；`project.layout.preset_owner` 记录持有者，组间距按首组实际边界计算，后续纯数据视图沿 +X 依次排列且不与共享预设重叠。旧工程仍按原配置回读和原位更新，缺少 `preset_owner` 时回退到首个条目；导出面板的预设分组标题改为「工程级共享预设（多视图仅生成一组）」。
- **兼容与打包**：未修改数据格式、视图复现文件格式、插件 API 与运行依赖；Blender 工程 schema 仍为 11（新增 `layout.preset_owner`，旧工程回退首条目）；PyInstaller 打包新增 `assets/ui` 资源，旧兼容导入（`theme`、`ui_controls`、`plugin_api`）仍指向新模块。
