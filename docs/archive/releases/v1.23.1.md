# BandScope v1.23.1

本版让 Z 轴旋转作用于数据本身而不再只是转动画面：主页与直接切片按当前角度重建来源体，非零角度下可直接裁剪、裁空并继续建立分析页；裁剪、裁空移到画布右侧初级工具栏，旋转旋钮改为可与空间工具并存的模式less浮窗。

## 主要变更

- **直接切片实时旋转**：主页及 `axis_integral`／`axis_integral_crop` 直接切片改为先按当前旋转角度重建完整来源体，再从原法向 `axis_interval` 提取或积分；拖动旋钮期间持续给出合并、丢弃过期任务的节流预览，松手后提交一次精确结果，法向区间、坐标上下限与页面区间保持不变。预览缓存不能替代最终精确数组，精确结果完成前确认裁剪／裁空及需要精确来源的局部增强仍按既有保护等待。切页恢复、导出和视图复现使用同一当前角度；新建 EDC、路径等派生子页记录创建当时的有效角度。
- **旋转后的裁剪、裁空与派生分析页**：空间选区保存创建角度、完整网格上的逻辑边界、操作类型与提交顺序，转到某角度时按该角度精确重建选区几何并重放裁剪／裁空，往返不累计重采样误差；非零角度不再被「请先将 Z 轴旋转恢复为 0°」拦截。EDC、切片内强度积分、多选区 EDC、XY／XZ／YZ 切片、能级态密度、二阶导、折线路径与对数页按冻结来源的角度、数据域与裁剪历史逐帧重建。旧全帧 ROI 仍先裁后转，缺少角度的旧 `crop_regions` 保持既有当前渲染网格语义。
- **旋钮与空间工具共存**：旋转面板改为模式less原生浮窗，普通外部点击不再自动关闭；再次点击 Z、按 `Esc`、切页／切源或工具条隐藏时关闭。面板可与框选、裁剪／裁空范围浮窗、局部增强框和折线路径选点同时使用，按屏幕边界与矩形避让选择位置，按钮高亮与面板显隐同步。2D 矩形保持轴对齐边界、3D 裁剪／增强盒保持原逻辑边界、路径节点保持原坐标，只有框内数据随角度变化。
- **裁剪、裁空入口**：裁剪与裁空从框选次级栏移到画布右侧初级工具栏，点击不再联动勾选框选或展开次级栏；框选已展开时再次点击只收起范围浮窗，未展开时关闭对应交互并保留草稿。
- **局部增强与路径草稿刷新**：存在就绪或常量增强图层时 2D 预览改走完整渲染，避免 blit 后区域图层与主图错位；路径草稿节点加入旋转预览的 blit 覆盖列表，预览后不残留旧节点。色阶手柄在失焦时结束编辑；不透明度插值开关移除获得焦点时的描边。
