# BandScope v1.17.0

本版把 E 轴翻转统一为纯显示镜像，并给 3D 截图加了三轴方向标、给 2D / 3D 截图色条加了拖动定位。

- **E 轴翻转改为显示镜像**：翻转把图像连同 E 轴刻度一起反向，图上每个像素仍对应它自己的 E 读数；数据数组、坐标、选区、数值导出与插件输入一律保持原始排列，翻转前后同一 E 坐标对应同一份强度。2D 的像素与 E extent 同步反向；1D 与比较页反向能量横轴；瀑布图反向能量纵轴；3D 由相机镜像整个场景，不再反序坐标数组。
- **翻转一致性修复**：删除裁剪、擦除、局部增强、积分区间与插件倍率里按显示方向镜像下标/坐标的补偿层。3D 裁剪框与 ROI、Energy DOS 数值导出、插件 ROI 范围在翻转后与画面不一致的问题随之消除；区间控件改按原始坐标工作，切换翻转不再改变积分区间与选中的采样，插件倍率也不再按显示方向倒序。数值导出保持原始坐标排列。
- **截图三轴方向标**：3D「截图样式 → 微调」新增默认关闭的「三轴方向标」。方向标保留当前相机的投影倾角与纵深缩短，只选择横向朝右半边、竖向朝上半边、纵深朝观察者的一端，不表示坐标递增；轴名按当前视角对应 kx / ky / E，正对纵深轴时以圈点表示朝屏幕外。设置按截图样式记忆，独立于主视图的坐标轴开关。
- **方向标与色条拖动**：大图预览中可直接拖动方向标与 2D / 3D 色条，刻度和标题随色条一起移动；中心 X / Y 输入框以整个图幅百分比定位并与拖动双向同步，松手后重新生成完整预览，正式导出沿用相同位置。支持「自动位置」与整组夹取在图幅内，方向标与色条独立命中。

验证（Windows、仓库 `.venv`、原生 Qt 窗口、NVIDIA OpenGL）：

- 全量 `python -m unittest discover -s tests -t .`：**1448 项通过**（2026-10-21）。
- 真实窗口 `scripts/validation/verify_e_axis_consistency.py`：12 项通过（`WSe2_step.npz`，150×150×200×25，E 为索引坐标）。覆盖 3D 快照坐标、翻转后的裁剪与裁空体素、真实 ROI 下标、插件 ROI 范围、2D 图片快照与插件方向、Energy DOS 数值导出。
- 渲染层与出版图：2D 翻转前后「像素值 == 所在位置 E 读数」的最大误差一致（0.04，既有半格采样约定）；2D / 1D 出版图翻转后轴方向正确、峰位 E 不变，出图已人工查看。
- 截图方向标与色条：导出模块 188 项自动化通过；真实窗口脚本 20 项通过、2 项失败。失败为既有布局边界——`body_size=250` 且同时开启带刻度坐标轴时报「画布尺寸过小」，关闭方向标的对照同样失败，本版未修改该逻辑，详见 [截图方向标交接](../../handoffs/screenshot-orientation.md)。
