# BandScope v1.23.3

本版恢复底栏双端区间条的长度输入框，并让画布框选次级栏的「生成 EDC」与「切片内强度积分」按钮改用区分度更高的字母图标。

## 主要变更

- **区间长度输入恢复显示**：主页时间轴与画布切片底栏的双端区间条重新显示长度输入框，数值为上限减下限；输入后以当前中心对称扩缩区间，触边时整段平移容纳目标长度，输入 0 合拢并锁定，锁定期间输入框只读。滑块拖动、端点浮框与长度框继续共享同一个 `AxisInterval`，窄窗下轨道相应收窄。
- **框选工具按钮字母图标**：画布右侧框选次级栏的两个动作按钮不再使用相近的数据趋势图标，分别显示 E（生成 EDC）与 T（切片内强度积分）字母图标；主题切换时同步重绘，按钮尺寸、提示与可访问名称不变。
