# BandScope v1.22.5

本版重做去噪管线：三级每级可从六种方法中任选一种或关闭，参数按方法分组可调。顶栏深浅主题按钮换成昼夜动画开关，不透明度插值选择换成图标动画开关，扫描轴滑块的停靠与整段平移设置移入「重新分配轴」窗口。

## 主要变更

- **三级去噪管线与六种方法**：去噪仍按一、二、三级依次生效，每级新增「None」选项，可选高斯平滑、中值滤波、Savitzky-Golay 滤波、小波去噪、非局部均值与低秩 SVD，同一方法可在多级重复。高斯平滑按 Kx／Ky／E 分别设置标准差（采样点，`0` 关闭对应轴）；中值滤波按轴设置 1–31 的正奇数邻域（`1` 关闭）；小波去噪新增噪声标准差（`0` 为最细细节子带 MAD 自动估计）；非局部均值使用块大小、搜索距离、强度倍率与噪声标准差；低秩 SVD 对每个时间帧独立压缩 Kx×Ky 空间与能量构成的矩阵，秩上限为 `min(Kx×Ky, E)`。逐帧方法不跨时间帧混合信息，静态 3D 与 `[Kx, Ky, E, T]` 4D 数据均可使用；原「卡尔曼滤波」不再作为可选方法，旧文件中的该选择回退为 None。
- **参数校验与整次预检**：应用前按所有仍被页面引用的完整数据域或紧凑 ROI 预检方法与参数，任一数据域不兼容即整次拒绝并保留上一套结果。中值邻域上限 31、非局部均值块 15、搜索距离 20 与 SG 阶数 4 等限制在界面与直接计算 API 共用；SG 窗口按实际滑动轴长度校验；小波按各数据域的 `shape[:3]` 与所选基函数计算可用分解层数，超出上限或该 ROI 上限为 `0` 时报出请求值与可用上限并拒绝整次应用，不再静默降层；Bayes／SURE 阈值按细节子带计算。
- **旧算法名兼容**：旧复现文件中的「频域平滑」「滑动平均」「贝叶斯去噪」与历史乱码的 SG／小波名称分别识别为正名算法；修正后的小波与非局部均值不承诺与旧版逐值一致，也不保留旧数值分支。
- **昼夜动画开关**：顶栏原「深色／浅色」双按钮换成 96×38 自绘开关，浅色显示太阳与云层、深色显示月亮与星空，切换播放 560 ms 主题过渡，并含悬停回弹、焦点与禁用状态；鼠标、空格与外部主题变更共用原有主题入口，仍保存 `ui/theme`，不重建页面或请求数据重渲染。
- **不透明度插值动画开关**：「不透明度」标题行右侧的「平滑／直线」文字选择器换成 72×28 自绘滑块，左端为扭曲三角函数曲线、右端为三段折线图标，带纵深导槽与滑块切换动画；点击即切换并保持控制点原位与曲形，模式仍随显示样式保存与恢复。
- **扫描轴滑块设置移入轴分配窗口**：「滑块停靠」（自动／离散停靠／连续拖动）与「连续拖动时整段平移」（保持物理宽度／保持帧数）从数据源卡片菜单移入「重新分配轴」窗口，只影响扫描轴。自动模式按采样点数选择：少于 30 点离散停靠、30 点及以上连续拖动。设置按数据源保存在本次会话，同源页面共用；「应用」后从下一次拖动生效，「取消」保留原设置；只改这两项不重新应用轴分配或新建数据源，同时修改轴分配时随重设事务应用到目标源。
