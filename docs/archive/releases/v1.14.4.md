# BandScope v1.14.4

本版修复弱信号在色阶调整后不可见的问题，并优化局部增强的拖动帧时与 ROI 去噪期间的界面响应。

- **弱信号色阶修复**：黑白场滑条现在选择强度窗口而不是裁剪色带，Gamma 在查色带与基础透明度曲线之前求值；去掉 2D 查表前的 256 档量化。非线性 3D 色阶把最终颜色坐标与 alpha 写入独立显示通道，避免 GPU 在原强度轴上重采样 Gamma 曲线；区域不再编码偏移。弱谱、亮异常点与区域交界处不再被压成黑色，色条按同一 Gamma 展开并标注黑、灰、白的物理强度，出版导出沿用同一映射。
- **局部增强拖动帧时**：参考机（WSe₂ 150×150×200）3D 拖动整次刷新由约 78 ms 降到约 47 ms，空闲刷新约 4 ms。NVIDIA 版将逐体素颜色/透明度映射迁移到 CUDA，与 CPU 结果逐位一致；显示通道按数组身份缓存并只在变化时上传，一帧只渲染一次；区域框、标签与色带分开签名增量更新；2D 区域图层与区域色带复用。非 NVIDIA 环境保留 CPU 参考路径，`BANDSCOPE_DISABLE_GPU_DISPLAY=1` 可强制对照。
- **ROI 去噪后台化**：增强区域的 ROI 去噪在独立后台线程执行（每次提交带 token，按数据源、去噪版本与 ROI 键校验），等待期间使用缓存数据继续渲染且界面可操作；结果就绪后自动转为完整结果，完成前不开放导出与色带冻结，过期结果直接丢弃。

- 全量 `python -m unittest discover -s tests -t . -v`：**1299 项通过**，新增 GPU 等价、显示通道跳过重传、单次渲染、辅助对象增量、2D 复用与 ROI 异步提交/过期共 9 项。
- 真实数据 `.local/data/WSe2_step.npz`：`scripts/validation/verify_local_enhancement.py` **156 个检查通过**；`verify_color_lock.py`、`verify_enhancement_projection.py`（22 项）、`verify_enhancement_outline_visibility.py`（24 项）通过。
- ROI 异步原生烟测：刷新 57.6 ms 返回，ROI 去噪 288.9 ms 后台完成并自动转完整结果。
