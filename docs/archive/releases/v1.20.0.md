# BandScope v1.20.0

本版重做 3D 体渲染的显示控制，颜色与透明度可以独立调节，并新增强度归一化与渲染质量设置；Blender 导出新增「柔和受光」数据体外观、十种可编辑文本预设和配套复现文件，工程 schema 升为 11、视图复现文件升为 schema 2。

- **体渲染独立透明度与强度归一化**：右侧「渲染控制」新增「显示模式」（独立透明度／兼容映射）、「强度归一化」（完整范围／百分位 P0–P99.5／手动范围，并显示实际强度范围）与「独立透明度」卡片（阈值、起始过渡宽度、透明度 Gamma、整体密度，滑条与数值输入双向同步）。颜色与透明度各自独立计算：黑场、白场与颜色 Gamma 只改颜色，阈值以下体素完全透明，弱信号不再带一层底雾。新页面默认独立透明度与百分位归一化，旧页面、旧复现文件和旧 Blender 工程保持兼容映射；样式随页面复制、派生与跨源恢复，并写入复现文件、出版图和 Blender 导出。
- **渲染质量**：新增「渲染质量」卡片，可切换明确采样／兼容质量、线性或最近邻体插值、静止标准（0.5 × 最小间距）或精细（0.25 × 最小间距）；交互拖动时按 2 × 最小间距预览，停止后恢复所选静止质量，原生 interactor 的刷新率设置不再被静默忽略。
- **Blender 数据体外观**：导出窗口新增「数据体外观」下拉框。自发光（默认）保持原外观；柔和受光以散射为主并保留少量自发光，按条目自动创建主光、补光与轮廓光三盏 Area 灯，用 Cycles 灯光链接只照射该条目数据体，散射与吸收之和保持原总消光。两种外观共用同一份强度、颜色、alpha 与密度数组，模式在提交时冻结、任务期间禁用，不跨重启记忆。
- **十种文本预设**：预设增至五项，新增「文本预设」，一次生成十个可编辑 Text 对象（统一大写 `A`、0.12 Blender 单位字高、两行五列），包含平面、立体、空心描边、发光、金属与玻璃样式；DejaVu 字体及许可证写入 `fonts/` 并打包进 `.blend`，每个文本有独立的文字曲线、材质和只照文本的辅助灯。
- **Blender 配套复现文件**：导出面板新增默认勾选的「同时保存复现文件」，额外生成 `名称.blend.bsview.json`，保存逐页科学配方、显示与质量、来源会话分组、条目顺序和全部导出设置。可通过「加载数据」单独打开：按原来源会话逐组主动选择 NPZ，全部来源校验和预计算成功后才整体新增工作区；工程、资产与配置统一暂存和提交，失败或取消整体回滚，覆盖旧工程时提示旧配置也会移除。
- **格式与兼容**：新 Blender 工程为 schema 11、显示编辑格式 2，视图复现文件为 schema 2；schema 7–10 工程仍可打开并原位更新，保持原版本、原预设与自发光外观，不补柔和受光灯组，需要新外观时重新导出。
