# BandScope v1.14.3

本版修正 v1.14.1 二次调整把黑白灰场滑条与强度映射误做成全局调控的问题：色阶与强度映射重新跟随增强区域下拉框选择的对象，只有「全部显示」下的实际调节才批量生效。

- **色阶与强度映射跟随调整对象**：下拉框选中 R1、R2 等区域时只写该区域，选中「全局（背景）」时只写背景。切换对象前先提交当前设置，再用阻断信号的方式回显目标对象的值，来回切换不会互相覆盖。
- **「全部显示」保持查看语义**：仅切换查看全部色带、换页或保存状态不会抹平各对象原有设置；在「全部显示」下拖动滑条或应用强度映射时，才同时写入背景与全部增强区域（以背景当前参数为批量起点）。锁定色带仍统一锁定各对象自己的强度范围。
- **区域增删与回显**：新增区域继承当前参数；删除选中区域后回显接替的区域，删完回显背景；「全部显示」下在 2D / 3D 视图点击任一区域可切回该区域单独调节。
- 界面提示与代码注释同步改为按对象调节的口径。

验证（Windows、原生 Qt 窗口、可用 OpenGL）：增强控件集成测试 30 项、相关模型 / 处理 / 渲染测试 26 项、全量 `python -m unittest discover -s tests -t . -v` 1266 项全部通过。真实数据 `.local/data/WSe2_step.npz` 的 `scripts/validation/verify_local_enhancement.py` 146 个检查通过，覆盖 2D / 3D 独立调节与其他对象显示通道不变、切换回显、「全部显示」批量调节、锁定、区域交互与删除、出版导出及科学数据不变。
