# BandScope v1.21.1

本版修正 v1.21.0 界面重做后的入口与主题细节：把更新、插件与去噪入口集中到顶部齿轮菜单，画布工具条改为右上角竖排，色带锁定按钮改为动画图标开关，并修复浅色主题下下拉框文字、画布坐标与色条配色、切换主题时的重绘与黑角问题。

- **齿轮设置菜单**：顶部工具栏新增齿轮按钮，集中「更新设置…」「插件管理…」「去噪参数设置…」三个入口；移除原「扩展」按钮与右侧版本按钮，版本号移到状态栏。画布右键菜单不再重复这些入口。插件管理入口在扩展模块不可用时保持禁用并说明原因。
- **更新设置与检查**：更新设置窗口显示当前版本，并新增「检查更新」按钮；点击后先保存窗口里的更新源与账号、关闭窗口，再启动手动检查。「保存」「取消」语义不变，检查或下载期间仍不能修改设置。
- **新版本提示**：更新说明与插件影响收进「详细信息」，默认折叠，长说明不再把确认弹窗撑高；需要时展开查看。
- **画布工具条**：工具条从画布左上角横排改为右上角竖排，3D 视角预设按画布高度自动收起；圆角改用原生窗口遮罩绘制，VTK 画布透出时不再出现直角黑边。
- **色带锁定开关**：渲染控制里的锁定按钮改为只显示图标的动画开关，切换时锁钩在 180 ms 内开合；主题切换与状态恢复都保持图标一致，不再改写按钮文字。
- **主题切换修正**：应用样式改用 `palette(...)` 角色，切换主题时不再整表重设应用样式与调色板；浅色主题下可编辑下拉框、弹出列表和新建菜单项的文字保持黑色，深色主题跟随窗口文字色。2D 画布的标题、坐标轴、刻度、图例、色条与裁剪选择框随主题刷新，3D 标量条文字与坐标轴一并更新；切换主题不重新渲染数据，不改变当前参数与相机。
- **其他**：勾选图标统一为 `assets/ui/check.svg`；主窗口事件过滤器只处理按键、鼠标、进入 / 离开、失焦与右键事件，减少无关事件进入裁剪与增强逻辑。
