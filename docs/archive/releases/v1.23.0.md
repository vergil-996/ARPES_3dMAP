# BandScope v1.23.0

本版新增能量两点定标：在轴分配窗口按 E1 零点与 E1–E2 目标间距重新生成均匀能量坐标，强度数据不变。Kx/Ky 与能量两个定标窗口统一为共享双端滑条并去掉长度输入框；EDC 与曲线比较页随本页时间区间重算；修正 2D 增强区域的预览刷新，底栏区间条不再显示长度输入框。

## 主要变更

- **能量两点定标**：数据体卡片的「重新分配轴」窗口新增「能量定标」按钮，打开默认 XZ 切片（可切 YZ、可垂直翻转）的定标窗口；两条水平虚线表示 E1／E2，拖动图外手柄选层，输入目标间距与单位后应用。应用后 E1 为零点、E2 等于目标间距，按逻辑索引重新生成均匀且只读的能量坐标，强度数组不变；同一数据源的页面保留，页面能量区间、轴域与裁剪区域按新坐标重映射，保存入口沿用定标后完整数据体的 NPZ／MAT 导出。
- **定标窗口交互统一**：Kx/Ky 定标与能量定标共用双端滑条（黑白端点、中点整体拖动与合拢锁定徽章），不再显示长度输入框；两个窗口的 figure 只保留一个 axes 且不添加 colorbar。Kx/Ky 窗口的切片副标题注明取区间中心最近采样、不做积分。
- **EDC 与曲线比较按时间区间重算**：单选区 EDC、EDC 比较页（含基准曲线）与对数曲线页随本页时间区间重算，重算基于冻结的空间选区、旋转角与数据域；复制粘贴与跨文件的曲线保持冻结。出版导出中这些页按可重算区间标注时间信息，EDC／对数曲线导出附带当前帧与 `index_bounds`。
- **2D 增强区域预览刷新**：存在就绪或常量增强图层时，2D 预览改走完整渲染，避免 blit 后区域图层与主图错位；没有区域图层时 blit 预览不再排队多余重绘，显示统计只在精确渲染时等待。
- **底栏区间条与裁剪弹窗**：双端区间条不再显示长度输入框，仅保留程序化同步，轨道相应加宽；移除活动选区后裁剪弹窗自动关闭。
