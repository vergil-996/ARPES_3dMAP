# BandScope v1.22.3

本版把插件管理与更新设置收进「设置」窗口、把分析结果创建入口从页面树移到视图右键，并整理外观面板、底栏区间条与出版导出窗口里的重复标题和提示。功能与数据格式不变，视图复现与 Blender 工程 schema 未升级。

## 发布修正（相对 v1.22.2）

v1.22.2 的标签在 CI 聚合插件目录时失败：`edc_waterfall` 1.0.1 的入口说明改动改变了包内容却没有提升版本，历史目录按「同一 id/version 不可换内容」拒绝合并，Release 未产出。按仓库约定不覆盖已推送的 v1.22.2 标签，本版把该插件升至 1.0.2 后重新发布；其余功能与格式与 v1.22.2 相同。

## 主要变更

- **设置内嵌插件管理与更新设置**：「设置 → 应用管理」下的「插件管理」「更新设置」改为左侧二级内嵌页，选中即显示；原「打开…」按钮与独立功能窗口删除，重复进入仍复用同一设置窗口。插件管理保留「已安装」「官方插件」「插件设置」三页签及安装、启用／停用、卸载、重试加载与恢复上一版本。更新设置「保存」后留在当前页，「取消」恢复已保存值，「检查更新」先保存当前设置再启动手动检查，主设置窗口不关闭。检查或下载期间两个页面的编辑控件被禁用；更新页处于活动状态时暂停后台自动检查，用户仍可手动检查。关闭或隐藏设置窗口会协作式取消目录获取与插件下载线程并清理临时下载目录，再次打开仍复用同一面板。
- **视图右键「处理分析」**：切片内强度积分、能级态密度、EDC 瀑布图、单条 EDC 曲线、二阶导与 API 3 插件动作，从页面树右键「创建结果页」移到当前页 2D／3D 视图右键的「处理分析」子菜单；裁剪／裁空模式的紧凑右键菜单同样提供该入口。菜单只对当前活动页过滤合法动作，打开菜单不切页，点击后才激活并再次校验；页面树与「我的分组」副本右键只保留改名、复制、删除等页面操作，`Ctrl + 2` 仍不切换控件页。
- **外观面板整理**：色阶与不透明度上方新增「显示对象」行（原「区域」下拉与锁定按钮），两者共用该调整对象；分组标题改为「色阶」「不透明度」「去噪」，去噪组标注「当前数据范围 · 全局共享」，色带选择行说明全部显示对象共用同一输出色带，锁定按钮提示改为「锁定全部强度范围」。移除色阶与不透明度控件里的中轴分割线。
- **视角卡片精简**：「相机视角」更名为「视角」，移除卡片内与画布工具条重复的「重置视角」按钮，恢复默认视角统一用画布右侧工具条。
- **底栏与区间条**：位置／时间区间条去掉「合拢逐帧 · 分离积分」「沿 X 积分」等副标题与「区间长度」标签，单行高度 64→74、两行 40→60；锁定浮标缩小，合拢锁定后整体平移时坐标浮框跟随手柄移动。
- **出版导出窗口精简**：移除窗口顶部重复的图标标题、当前视图族徽标、来源说明与「冻结快照」提示，以及「主视图坐标轴开关已关闭」提示和每 600 毫秒轮询来源是否过期的逻辑；垂直空间留给预览与参数区。
- **后台线程收尾**：插件管理的官方目录获取与插件下载线程改由模块级强引用持有，`finished` 后释放；关闭面板只做协作式取消和有界等待，晚到结果按发送者身份丢弃。更新检查与下载线程同样按发送者收尾，旧线程结束不会清空当前线程引用或覆盖新状态。
- **EDC 瀑布图插件 1.0.2**：代码不变，仅同步视图右键「处理分析」入口的说明；`flat_band_opacity` 仍为 1.2.3。
