## 交付功能

1. 单曲线、比较叠加、既有 log 结果及瀑布图使用稳定曲线身份。可逐条或多选批量修改颜色、线型、线宽、透明度、点形状/大小/空心/间隔、显隐、名称、图例资格和绘制顺序；默认基准加粗可被显式线宽覆盖。
2. 图例支持独立排序、列数、字号、边框/背景/间距、内外位置和自动避让。图外布局避开科学计数指数及轴名，画布空间不足明确报错。修复科学计数公共指数被实际绘制清除的问题。
3. 横纵轴可独立设置自动/手动范围、反向、主次刻度、刻线和网格；增加字号、色彩、四边留白和布局。标题、轴名和字体统一放入右侧分页编辑区。
4. 瀑布图增加统一色、分类色、灰度线型与按原始采样位置绑定的渐变，标签支持全部/关闭/每 N 条/自动稀疏。隐藏或重排保留原偏移和轴范围。
5. 文本、箭头、参考线和区间阴影可通过数值输入编辑。增加统一撤销/重做、最新预览队列和过期结果拦截。
6. 页面会话保留草稿，关页或加载新数据时清理；命名通用预设跨页面和重启复用。预设不保存曲线身份、科学名称、显隐、手动范围或注记；取消/导出失败不提交通用偏好。
