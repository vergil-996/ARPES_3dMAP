## 目标与现状

建立完整的 1D 出图编辑能力，覆盖单曲线、叠加比较、log 结果和瀑布图。按照已确认的范围，只影响截图与导出；不新增归一化、平滑、强度缩放或偏移计算。

现有三套模板、字体选择、标题与轴名编辑、透明背景、尺寸/DPI、PNG/PDF 导出继续保留。主要缺口是逐曲线设置、稳定身份、图例管理、坐标排版和样式复用。

规划阶段完成只读调研，现有导出测试 **103 项通过**。以下保留确认后的方案；最终实施与验收结果见同目录完成记录。

## 分期交付

### 第一阶段：可靠性与逐曲线编辑

- **先修复刻度数值表达。** 绘制检查发现，小数值范围的科学计数公共指数可能在实际绘制后消失；修复并增加绘制后的断言，避免截图表达错误数量级。
- **增加曲线列表与属性编辑器。** 列表显示来源、名称、样式样例、基准标识及可见性；支持单选、多选和批量设置。
- **逐条设置外观。** 支持颜色、实线/虚线/点划线/点线、线宽、透明度、标记形状与大小、空心/实心标记、标记间隔，以及仅线、仅点、线点组合。
- **管理叠加关系。** 支持隐藏曲线、调整绘制顺序、编辑图例名称、单独关闭某条图例。基准身份与绘制顺序分离，移动曲线后仍保持正确身份。
- **补齐草稿行为。** 切换模板、关闭重开窗口、同页更新预览均保留本次会话设置；提供“恢复所选曲线”和“恢复整图默认”，输出尺寸/DPI 独立保留。

**完成标准：** 多条同名曲线和重复粘贴曲线都能独立设置；隐藏、重排、刷新后，颜色与名称不会错配。

### 第二阶段：图例、坐标与科研排版

- **完整图例控制。** 支持自动位置、图内固定位置、图外上/下/左/右侧，以及列数、字号、边框、背景和间距。默认图例顺序跟随曲线列表，可单独调整。
- **处理图例遮挡。** 自动模式测量图例与曲线的重叠；图内候选位置均有遮挡时移到右侧图外，并重新分配绘图区。长名称自动换行，空间不足时明确提示。
- **坐标轴控制。** 横纵轴分别支持自动/手动范围、显示方向、刻度密度、次刻度、刻线方向/长度/宽度/颜色、刻度文字显隐，以及主次网格。手动范围必须有限且下限小于上限，反向显示使用独立开关。
- **细化排版。** 分别调整标题、轴名、刻度、图例及面板编号字号；增加轴名间距、坐标框线宽、文字颜色、背景颜色和四边留白。
- **调整编辑窗口。** 1D 使用左右分栏：左侧保留预览，右侧通过“曲线、图例、坐标、排版”分页编辑；设置区可滚动，输出操作始终可见。

**完成标准：** 89 mm、183 mm 和自定义尺寸下，长中文图例、较大字号及图外图例不会被静默裁切，预览与导出保持同一排版。

### 第三阶段：瀑布图、预设与编辑效率

- **瀑布图配色。** 在逐曲线编辑之外，增加统一色、分类配色、灰度线型和序列渐变；默认保留当前黑色外观。颜色按原始采样位置绑定。
- **瀑布图标签。** 支持关闭、全部显示、每 N 条显示及自动稀疏显示，并可调整字号、旋转、颜色与距离。自动模式按文字实际占用空间保留不冲突的标签；标签取舍不影响曲线数据。
- **通用外观预设。** 支持保存、命名、应用、覆盖和删除，跨页面及重启复用。预设包含模板、曲线默认规则和通用排版，不携带曲线身份、名称、显隐、手动轴范围或科学注记。
- **科研注记。** 增加文本、箭头、水平/垂直参考线及区间阴影，通过列表和数值输入编辑位置与样式；不自动识别峰或生成分析结论。
- **撤销与预览效率。** 支持撤销/重做，一次批量编辑对应一次撤销；沿用 200 ms 防抖，优先处理最新预览请求，旧结果不得覆盖新设置。

**完成标准：** 密集瀑布图可读；通用预设不会把另一页面的曲线名称或范围带入；连续编辑后最终预览准确。

## 结构与状态规则

- **统一曲线身份。** 单曲线使用页面内固定身份；比较曲线创建独立 `curve_id`，重复粘贴分配新身份；瀑布曲线使用“采样轴＋绝对采样索引”。复制、比较和 log 链路透传身份，禁止使用名称或当前行号匹配样式。
- **独立出图配置。** 在 `bandscope/exporting/` 建立曲线身份、逐曲线外观及整图配置模型。解析顺序为“模板默认 → 整图设置 → 逐曲线覆盖”；显式线宽优先于默认基准加粗。
- **兼容现有接口。** 为渲染和保存入口增加可选关键字参数 `presentation`；未传入时保留现有行为。科学数组继续使用冻结快照，插件公开 API 无需变化。
- **页面会话记忆。** 配置归属于页面；关闭页面或成功加载新数据时清理。去噪、裁剪或时间变化只标记来源过期，同页刷新按身份恢复仍存在的曲线设置，新增曲线使用默认值。
- **保存语义明确。** 普通编辑只更新会话草稿；导出成功后提交通用样式偏好，取消路径选择或导出失败不提交。“保存预设”是独立的明确保存操作。
- **保护科学内容。** 隐藏或重排瀑布曲线不重新计算偏移；标记稀疏不删减折线采样；NaN 缺口保持断开；log 结果不重复取对数。全部曲线隐藏或均无有效数据时，禁用导出并说明原因。
- **集成边界。** 主窗口仅补充身份元数据、来源修订和会话清理接入，由集成任务统一修改；保留当前工作区已有字体、刻度及区间修复。

## 验收与交付

- **身份与状态：** 同名、重复粘贴、超过调色板长度、重排、隐藏、模板切换、关闭重开、同页刷新、跨页切换及重新加载数据。
- **数值与渲染：** 绘制后的科学计数指数；NaN 缺口；降序和非均匀坐标；单/多条 log；插件曲线；瀑布采样步长变化和全 NaN 槽位。
- **出图质量：** 长中文图例、图外多列图例、不同尺寸、透明底、PNG/PDF、密集标签及注记；确认主窗口和原始数组保持一致。
- **自动化检查：** 使用合成数据及隔离设置，先运行导出与相关集成测试，再运行 `python -m unittest discover -s tests -t . -v`。
- **人工验收：** 使用 `.local/data/WSe2_step.npz` 生成样例和对照图，记录实际检查范围；未执行的视觉或打包检查明确标记。
- **文档交付：** 本文件是本功能唯一当前计划，实施时记录阶段状态、接口和验收结果；完成后连同视觉材料归档。
