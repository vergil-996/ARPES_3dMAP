### 与计划的差异

- “裁剪模式下保留轴标题菜单入口”实现为：右键仍把范围窗口移到光标处（原有行为不变），随后在同一位置弹出只含轴标题条目的菜单。3D 主画布同理。**注意**：裁剪模式下每次右键都会多出一个待关闭的菜单，这是为了满足“裁剪模式下也保留入口”而付出的代价；`scripts/validation/verify_crop_window.py` 仍然全过，原有“右键把窗口移到光标处”的行为没有被破坏。
- 新增了两处计划未点名的改动：页面名纳入导出快照的过期判定；matplotlib 字体回退表（中文验收时发现 DejaVu Sans 缺 CJK 字形）。

### 代码评审后补修的缺陷

一轮独立代码评审（含复现）找出并已修复的问题：

1. **轴标题位置会漏进 1D 页**：`ax_2d` 是 2D 图像与 1D / 瀑布 / 对比页共用的坐标系，拖动调用的 `set_label_coords` 会把 mpl 的 `_autolabelpos` 关掉，而只有 2D 渲染路径会清回来。修复：新增 `VisualEngine.reset_2d_axis_labels`，1D 三处渲染在写自己的轴标签前调用。
2. **裁剪模式下的轴标题入口其实不可达**：应用级事件过滤器吞掉了 `ContextMenu`，`customContextMenuRequested` 不再触发，原先只写在菜单回调里的入口永远不会执行。修复：由 `_crop_event_filter` 自己把菜单排到过滤器之外弹出（`QTimer.singleShot(0, ...)`，避免在过滤器里开嵌套事件循环）。验收脚本也改成走真实右键路径。
3. **取消拖动不回滚画面**：失焦/切页取消时只丢弃了草稿位置，标签却停在拖动落点，与状态不一致且下次整帧重绘会跳回去。修复：按下时记下标签的变换/位置/自动排布标志，取消时原样放回。
4. 清理：`_append_axis_title_actions` 的 `crop_mode` 死分支与未使用的 `HIDDEN_TEXT` 常量；工具页页眉不再提示“双击重命名”。
5. 新增一条护栏测试：`theme.MPL_FONT_FAMILIES` 必须与截图样式的 `font_family` 同源（两处字面量，改一处忘另一处会让中文一边正常一边变方块）。

## 功能与交互

- **2D 图**：切片、积分、裁剪和二阶导图默认显示横、纵轴标题。双击标题弹出改名框，按住左键拖动位置。
- **3D 图**：主画布右键菜单增加“轴标题…”入口，编辑 X、Y、E 三个轴名；标题位置继续随相机自动排布。
- 提供“恢复默认文字”和 2D“恢复默认位置”。清空文字表示隐藏标题，仍可通过右键菜单重新编辑。
- 本次不扩展 1D 图、图顶部标题和色条标题。

## 页面标题编辑（补充需求）

- 页面标题指工作区顶部的页面名称。主页和全部数据结果页均可改名，包括 1D、2D、3D；控制面板等工具页不提供改名。
- 双击顶部页面名称打开改名框；名称区域右键菜单提供“重命名…”和“恢复自动名称”。取消编辑不改变原名。
- 输入去除首尾空白，空名称不允许提交；重复名称复用现有 `_make_unique_page_title` 规则追加编号，排除当前页面自身。
- 自定义名称按 `page_id` 在当前会话中保存，切页、切帧和参数刷新均保留；加载新数据后清理，派生的新页面仍使用自己的自动名称。
- 区分自动名称和用户覆盖：自动命名逻辑继续更新底层默认值，但不得覆盖用户命名；“恢复自动名称”采用当前最新默认值并执行去重。
- 改名后同步顶部标题及提示、导航按钮提示、页面树和当前来源名称显示；通过 `source_page_id` 关联已有来源页面，不按标题识别页面，不批量重命名派生页面或改写历史数据快照。
- 导出快照的 `source_page_title` 和默认文件名采用有效页面名称；图内顶部标题保持现有生成规则，用户已填写的导出文件名不强行替换。
- 接入现有 `ResultWorkspace.update_page` 更新路径，补齐当前页面页眉刷新与改名通知。检查已有标题索引、页面复用和自动更新调用，确保重命名不改变页面身份、计算参数或来源关系。
- 页面标题编辑属于本次追加范围；上文对 1D 的范围限制仅指轴标题编辑与拖动。

## 默认文字与状态

- 2D 默认轴名按切面确定：X 切面为 `ky / E`，Y 切面为 `kx / E`，E 切面为 `kx / ky`；有 `plot_axes` 时以其实际轴映射为准。
- 复用现有坐标标签规则：单位来自数据元信息；缺少单位时不推测，索引坐标标注 `index`。3D 保留现有默认文字。
- 使用会话内状态，以页面、视图类型及 2D 轴组合区分设置。刷新、切帧、调整色带、切换页面后保留；关闭页面或加载新数据时清理。
- 新建结果页使用自动标题；同一页面的 2D 与 3D 设置分别保存。

## 实现与接口

- 在 `bandscope/ui/` 增加独立标题交互控制器，负责文字命中、双击编辑、拖动、恢复和会话状态；主窗口仅负责接入与生命周期。
- 拖动位置使用相对绘图区坐标，保持横轴水平、纵轴竖直；限制标题留在可见画布内。支持鼠标移出绘图区，并在释放、失焦或切页时结束拖动。
- 2D 渲染接口增加可选轴标题和位置参数；完整重绘后恢复设置，标题变化时使快速刷新缓存失效。维持现有等比显示和图像缓存复用。
- 标题命中优先于裁剪，拖动期间锁定冲突交互；未命中标题时维持原有裁剪操作。裁剪模式下也保留轴标题菜单入口。
- 3D 渲染接口增加可选三轴标题，并将文字纳入坐标轴刷新判定。坐标轴隐藏时允许预先改名，再次显示时生效。
- 导出快照采用主画布的自定义轴名，截图样式中的显式覆盖优先；拖动位置仅用于主画布，导出继续由样式排版。
- 涉及 `ui`、`rendering`、`exporting` 及对应测试；共享接入为主窗口和裁剪集成。不改变插件公开 API、依赖或打包配置。
