# 第四轴滑块停靠与平移设置

2026-11-22 · 已实施；定向测试与 2011 项全量回归通过。

## 目标与设置入口

在页面树上方的数据标签中提供两项设置。每个数据源在本次会话内独立保存设置，同一数据源的页面共用。修改设置从下一次拖动生效，当前选区保留原位。单独修改拖动设置无需重新应用轴分配。

| 设置 | 选项 | 默认行为 |
|---|---|---|
| 滑块停靠 | 自动、离散停靠、连续拖动 | 自动。第四轴少于 30 个采样点时离散停靠，30 点及以上时连续拖动。自动项显示当前生效的模式。 |
| 连续拖动时整段平移 | 保持物理宽度、保持帧数 | 保持物理宽度，沿用现有平移手感。 |

## 拖动行为

- **离散停靠**时，拖动单帧滑块或单个端点，手柄吸附到最近的实际采样坐标。整体移动选区时，两端按相同帧数移动，保持选中帧数。
- **连续拖动**时，手柄可以停在两个采样点之间。整段平移选择“保持物理宽度”时，例如宽度为 100 fs 的选区在拖动全程保持 100 fs。选择“保持帧数”时，例如选中 3 帧，拖动全程都取连续 3 帧，物理宽度可随采样间距变化。
- 整段拖动触及轴端时，整个选区一同停止。上述规则适用于升序、降序和不等间距的采样坐标。
- 改动范围为第四轴滑块的拖动行为及数据标签里的设置，沿用现有刻度、数值输入和图像刷新方式。

## 验收与下一步

1. 接入数据源设置和第四轴拖动逻辑，用 3、29、30、31 点的合成数据验证自动阈值与手动覆盖。3 点时自动模式只能停在三个采样坐标，30 点时可停在两点之间。
2. 在非均匀升序和降序坐标上逐步拖动，核对单端吸附位置、整段移动的实际帧数或物理宽度，以及首尾触边行为。
3. 验证更改设置后当前选区保留原位，下一次拖动采用新规则。同源切页共用设置，切回其他数据源可恢复其设置，也可手动切回自动模式。
4. 实施后运行受影响模块测试，再运行全量回归 `python -m unittest discover -s tests -t . -v`。
