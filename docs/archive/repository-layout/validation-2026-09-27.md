## 环境与限制

- Windows、Python 3.12.10、PyQt5 / Qt 5.15.2、PyVista 0.47.1、VTK 9.6.0、Matplotlib 3.10.8。
- 完整 VTK 窗口在 Qt `offscreen` 平台下无法初始化 Windows OpenGL；改用 `windows` 图形平台后通过。纯自动化测试仍使用离屏模式。
- Qt `QWidget.grab()` 对嵌入 OpenGL 区域可产生黑块；已用 VTK 独立截图和导出渲染图确认体数据图像，界面整窗截图只用于控件布局复核。
- 本机未安装 Inno Setup；安装器路径已同步修改，安装器编译和真实安装升级未执行，由发布 CI 和后续发布验收覆盖。
- PyInstaller 对当前环境中的可选 SQL / cuTENSOR 库产生缺失警告，但两套构建均成功；本轮不将这些环境警告当作迁移回归。
- 本轮检查不代替平带增强的实测数据物理效果验收，也不自动关闭旧裁剪交接中的专项视觉验收事项。
