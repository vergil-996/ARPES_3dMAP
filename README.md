# BandScope

BandScope 是面向本地桌面实验环境的多维 ARPES 可视化与分析工作台，提供 `npz` / `mat` 数据加载、多数据源工作区、全局 ROI 数据域、3D 体渲染、2D 切片、折线路径 E–k 切片、交互裁剪、去噪、积分分析、DOS 分析、EDC 曲线、EDC 瀑布图、二阶导锐化、曲线比较、截图与结果导出、多页面 Blender 工程导出／回读与原位显示更新，以及可独立安装的官方扩展等能力。当前源码版本为 **v1.23.0**。

> 本项目 GUI 基于 [ChinaIceF/PyQt-SiliconUI](https://github.com/ChinaIceF/PyQt-SiliconUI) 开源项目修改而来。

### v1.22.5 更新

本版重做去噪管线：三级每级可从六种方法中任选一种或关闭，参数按方法分组可调。顶栏深浅主题按钮换成昼夜动画开关，不透明度插值选择换成图标动画开关，扫描轴滑块的停靠与整段平移设置移入「重新分配轴」窗口。

- **三级去噪管线与六种方法**：去噪仍按一、二、三级依次生效，每级新增「None」选项，可选 **高斯平滑**、**中值滤波**、**Savitzky-Golay滤波**、**小波去噪**、**非局部均值** 与 **低秩 SVD**，同一方法可在多级重复。高斯平滑按 Kx／Ky／E 分别设置标准差（采样点，`0` 关闭对应轴）；中值滤波按轴设置 1–31 的正奇数邻域（`1` 关闭）；小波去噪新增噪声标准差（`0` 为最细细节子带 MAD 自动估计）；非局部均值使用块大小、搜索距离、强度倍率与噪声标准差；低秩 SVD 对每个时间帧独立压缩 Kx×Ky 空间与能量构成的矩阵，秩上限为 `min(Kx×Ky, E)`。逐帧方法不跨时间帧混合信息，静态 3D 与 `[Kx, Ky, E, T]` 4D 数据均可使用；原「卡尔曼滤波」不再作为可选方法，旧文件中的该选择回退为 None。
- **参数校验与整次预检**：应用前按所有仍被页面引用的完整数据域或紧凑 ROI 预检方法与参数，任一数据域不兼容即整次拒绝并保留上一套结果。中值邻域上限 31、非局部均值块 15、搜索距离 20 与 SG 阶数 4 等限制在界面与直接计算 API 共用，不能绕过；SG 窗口按实际滑动轴长度校验；小波按各数据域的 `shape[:3]` 与所选基函数计算可用分解层数，超出上限或该 ROI 上限为 `0` 时报出请求值与可用上限并拒绝整次应用，不再静默降层；Bayes／SURE 阈值按细节子带计算。
- **旧算法名兼容**：旧复现文件中的「频域平滑」「滑动平均」「贝叶斯去噪」与历史乱码的 SG／小波名称分别识别为正名算法；修正后的小波与非局部均值不承诺与旧版逐值一致，也不保留旧数值分支。
- **昼夜动画开关**：顶栏原「深色／浅色」双按钮换成 96×38 自绘开关，浅色显示太阳与云层、深色显示月亮与星空，切换播放 560 ms 主题过渡，并含悬停回弹、焦点与禁用状态；鼠标、空格与外部主题变更共用原有主题入口，仍保存 `ui/theme`，不重建页面或请求数据重渲染。
- **不透明度插值动画开关**：「不透明度」标题行右侧的「平滑／直线」文字选择器换成 72×28 自绘滑块，左端为扭曲三角函数曲线、右端为三段折线图标，带纵深导槽与滑块切换动画；点击即切换并保持控制点原位与曲形，模式仍随显示样式保存与恢复。
- **扫描轴滑块设置移入轴分配窗口**：「滑块停靠」（自动／离散停靠／连续拖动）与「连续拖动时整段平移」（保持物理宽度／保持帧数）从数据源卡片菜单移入「重新分配轴」窗口，只影响扫描轴，不改变 Kx／Ky／E 轴的连续拖动。自动模式按采样点数选择：少于 30 点离散停靠、30 点及以上连续拖动，选项始终显示当前生效的模式。设置按数据源保存在本次会话，同源页面共用；「应用」后从下一次拖动生效，不改变当前选区，「取消」保留原设置。只改这两项不会重新应用轴分配或新建数据源；同时修改轴分配时随重设事务应用到目标源。离散模式下手柄吸附最近的采样坐标，整段移动按相同帧数平移；连续模式下可停在两个采样点之间，整段平移按「保持物理宽度」或「保持帧数」执行；整段拖到轴端时一起停止，升序、降序与不等间距坐标同样适用。

### v1.21.2 更新

本版修正大数据加载与 GPU 体渲染：超大 MATLAB v5 数值矩阵改走只读内存映射，加载与转换不再为转连续内存额外复制整块数组；带 NaN 掩膜的体渲染在显式质量设置下改为在体属性上设置插值，不再调用 GPU 光线投射映射器没有的接口。

- **超大 MAT v5 导入**：MATLAB v5 用 32 位长度字段记录数据字节数，单个数值矩阵超过 4 GiB 时长度回绕，`scipy.io.loadmat` 读取失败。现在识别这种文件后按列主序（`order="F"`）只读内存映射打开，仅支持单个、未压缩、非复数的数值矩阵且数据位于文件末尾；其他 MAT 文件仍走原读取路径，行为不变，转换失败时仍会清理未完成的输出文件。
- **加载与转换的内存占用**：NPZ 加载去掉强制 `ascontiguousarray`，保留原数组布局，不再生成整块连续副本；MAT 转换中的 float32 样本不再复制。大数组的峰值内存相应降低，显示与导出结果不变。
- **GPU 体渲染插值**：含 NaN 掩膜的体数据必须使用 `vtkGPUVolumeRayCastMapper`，该映射器没有 `SetInterpolationMode`；显式质量设置改为在体属性（`GetProperty().SetInterpolationType`）上设置线性／最近邻插值，并跳过不存在的交互采样接口，掩膜体不再因设置插值失败；自动调整、采样距离与静止／预览切换仍按所选质量生效。

### v1.11.0 更新

- **积分区间只有一份真值**：原来「积分上限 / 积分下限 / 中心位置」三个控件各自维护状态，拖动一侧会用旧值回写另一侧，计算又反过来从输入框反算下标，同一份区间在控件、页面参数和计算之间可以互不一致。现在收敛成一个物理区间模型（端点、长度、中心、锁定），控件只提交操作意图，模型负责约束后统一同步全部控件、输入框、锁定按钮与状态灯。
- **积分卡片换成「上下限 + 可输入长度 + 锁定」**：删除中心位置控件，新增可直接输入的**积分长度**与**锁定区间**按钮。锁定后改任一端都是整体平移，长度保持不变；未锁定时端点各自独立，不能越过另一端，允许零长度（对应单层采样）。
- **位置控制移到画布底栏**：当前轴向的 `kx / ky / E` 位置滑条与输入框放在时间轴左侧，控制积分区间中心。数据没有时间轴坐标时它直接占用原时间轴的位置，左侧不留空位；两条轴同排时分享可用宽度，窗口不够宽时「显示坐标 / E轴翻转 / Z轴旋转」整组下移到第二行，底栏高度同步增加。呼出与收起是 220 ms 的宽度 + 透明度过渡，快速切页或反向收起从当前进度继续。
- **左下角状态栏新增区间锁定指示**：「● 区间已锁定 / ● 区间未锁定」跟在运行状态灯旁边，分别用绿色和灰色。
- **保留精确物理区间**：端点可以落在采样点之间，计算时才映射到最近采样点，按原始下标排序后包含两端求和，等距时取较小下标。数值输入框按坐标分辨率设置精度与步长，不再固定两位小数——细步长坐标（如 `0.001`）之前会被显示舍入掉真实值。单位沿用数据元信息（缺单位不猜，索引回退坐标标注 `index`）。
- 单层切片页的位置输入保留物理值，实际切片取最近采样点，区间端点、长度与锁定操作禁用；移动位置时会更新产生该切面的源范围，同时保留面内裁剪与裁空链，旧的裁剪参数不会把位置覆盖回去。

### v1.10.0 更新

- **左侧换成常驻页面树**：原来 56 像素的图标栏和树浮层替换为一棵常驻的页面树，按来源关系显示层级，操作方式与 Windows 文件导航一致。点击名称切换页面，点击展开箭头只展开或收起；名称过长时可以横向滚动看全，并保留完整名称提示和页面类型图标。

- 修复**删除非当前祖先后当前后代未切页**的问题；删除现在先算出完整集合，再按子页到父页清理，逐页发出关闭通知，最后统一刷新并激活存活页面。数字键切页改按页面树中可见行的顺序。

- **底部 — 状态栏**：运行状态、当前结果页、2D 光标坐标、数据形状与计算后端。

## 安装与运行

### Windows 安装包（推荐）

正式发布后可从 [GitHub Releases](https://github.com/vergil-996/ARPES_3dMAP/releases) 下载与电脑环境对应的安装包：

- `BandScope-<版本>-Windows-x64-CPU-Setup.exe`：通用 CPU 版
- `BandScope-<版本>-Windows-x64-NVIDIA-Setup.exe`：包含 NVIDIA CUDA 数值后端的版本

安装器默认安装到当前用户的 `%LocalAppData%\Programs\BandScope`，不要求管理员权限。CPU 与 NVIDIA 安装包使用相同的应用标识，可以直接互相覆盖升级，用户设置仍保存在独立的 `QSettings` 中。

以前使用压缩包的用户需要手动运行一次 BandScope 安装器；自动更新能力从这次安装完成后开始生效。

安装版启动约 5 秒后会在后台检查 GitHub 最新正式 Release，每 12 小时最多自动检查一次；也可以通过顶部工具栏右侧的齿轮按钮进入「设置 → 应用管理 → 更新设置」，直接在内嵌页点击「检查更新」手动检查。自动检查失败时会弹窗提示原因，并建议在开启 VPN 或网络代理后手动检查，弹窗中的「三天内不再提示」只会静音后续失败提示，后台检查仍照常进行。发现新版后，BandScope 会：

1. 选择与当前 CPU / NVIDIA 构建一致的安装包
2. 下载到当前用户的更新缓存目录
3. 使用 GitHub Release API 返回的 SHA-256 摘要校验完整性
4. 经用户确认后启动安装器并退出，由安装器在原目录完成覆盖升级

新版本提示框中的「一周内不再提示」会让此后一周的自动检查不再弹窗（检查本身继续执行），从「更新设置…」手动检查仍然正常提示；「跳过此版本」则只针对当前这一个版本生效。

从源码运行时只会提示新版并打开 Release 页面，不会尝试覆盖源码目录。尚未配置代码签名证书时，更新确认框会明确警告；正式对外分发前建议签名安装包，并在 `bandscope/app_metadata.py` 中填写发布证书的 SHA-256 指纹。

## 支持的数据格式

### 推荐的 `npz` 字段

推荐输入字段如下：

```text
sample : 3D (Kx, Ky, E) 或 4D (Kx, Ky, E, T)
kx     : Kx 坐标，一维数组
ky     : Ky 坐标，一维数组
E      : 能量坐标，一维数组
time   : 时间 / delay 坐标，一维数组
```

说明：

- 程序会自动搜索 `npz` 中的主数据数组，优先识别 4D，再识别 3D
- 若坐标缺失，程序会按像素索引自动生成默认坐标
- 读入后内部会统一整理为 `(Kx, Ky, E, T)` 的分析格式
- 对于静态数据，程序会自动补一条长度为 1 的时间轴

### `.mat` 导入

导入 `.mat` 时，程序会先转换为 `.npz`。当前转换逻辑会优先识别以下常见字段别名：

- 主数据：`sample` / `binned` / `data`
- Kx 坐标：`kx` / `X`
- Ky 坐标：`ky` / `Y`
- 能量坐标：`E` / `energy`
- 时间坐标：`time` / `delay` / `t` / `T`

转换逻辑位于 [data_trans.py](bandscope/core/data_trans.py)，如需要添加字段可自行更改。

## 控件功能说明

### 1. 画布底条与悬浮视图工具

先从顶部工具栏加载数据，再用画布下方底条调整位置与时间，用画布右上角悬浮工具栏调整坐标、翻转和旋转：

- 点击顶部 **加载数据** 导入 `npz`、`mat` 或 `.bsview.json` 复现文件；每次成功加载都新增一份独立数据源，原有数据和全部分析保留
- 加载两份及以上数据后，**加载数据** 右侧出现数据源下拉框：切换数据源会恢复该数据上次的页面、帧、参数和相机；框内文字可直接改名（`Enter` 或失焦提交，`Esc` 撤销，空名称恢复默认名，重名自动追加序号），只改显示别名
- 删除左侧根页面（原始视图）等于关闭整份数据源，属于它的派生页、裁剪、轴标题、出版草稿与任务一并清理，然后切到相邻数据源；最后一份关闭后回到未加载界面
- 使用时间组的滑块或帧号输入框切换时间帧；静态数据收起时间组，若位置组也不可用，整条底栏折叠
- **Z 轴旋转**：点击悬浮工具栏的 Z 图标，在按钮左侧展开旋钮。拖动外圈从当前角度连续旋转，范围为 -360° ~ 360°；中央输入保留两位小数，上下键每次调整 1°，回车或结束编辑提交，「归零」立即恢复 0°
- 点击 **显示坐标** 图标开关物理坐标轴
- **图像翻转** 开关把画面连同 E 轴刻度一起镜像：图上每个像素仍对应它自己的 E 读数，数据、坐标、选区与数值导出保持原始排列。3D 视图保持 X/Y 数据轴不动并自动应用等价于上下拖动 180° 的相机视角；含能量轴的 2D/1D 结果只反向显示方向
- 3D 的默认视角与 **重置视角** 会按 E 轴方向自动摆正：E 升序数据直接使用等轴视图，E 降序数据则上下翻转，保证较小的 E 值始终在画面下方
- 悬浮工具栏的三个视图控件独立成组；非零旋转角度会持续高亮并在悬停提示中显示当前值。底条宽度全部留给位置和时间滑条，两组同时显示时等分，窄窗只换成两行；路径页的选段条独立显隐
- 切换到其他结果页用左侧页面树（点击名称切换、点箭头收展，`Enter` 切页，`Ctrl+W` 删除当前页并先弹确认，数字键按树中可见行顺序跳页）；当前视图的截图与数据导出统一使用顶部工具栏

#### 多框选与裁剪

点击画布右侧悬浮工具栏的 **框选范围** 进入多选区模式，主按钮左侧展开次级栏，提供 **裁剪**、**裁空**、**生成 EDC** 和 **新增框选范围**；顶部工具栏不再单独放置裁剪、裁空按钮。

- 3D 体渲染中显示交互包围盒，拖拽手柄调整范围；2D / 1D / 瀑布图上直接用鼠标左键框选。点击 **新增框选范围** 可保留已有选区并新建活动选区，因此同一页面可建立多个 2D 选框或 3D 盒；点击已有选区可将其切换为活动选区
- 次级 **裁剪** 或 **裁空** 只作用于当前活动选区，不会把其他选区一起提交。点击后打开对应的范围浮窗，可直接输入活动选区各轴上下限，与框选双向同步；右键画布可把窗口移到光标处
- 再次点击已展开的次级裁剪／裁空按钮只收起范围浮窗，不退出框选模式，也不删除任何选区草稿。再次点击主 **框选范围** 按钮退出工具；各页面的全部选区草稿仍独立保留，重新开启即可恢复
- 点击浮窗中的 **裁剪** 生成新的裁剪结果页，来源页保持不变；按 `Esc` 可先关闭浮窗，草稿不会丢失
- 3D 中将活动选区任一轴的上下限设为同一位置时，裁剪生成该单层的 2D 结果页；底栏初始为零长度锁定状态，点击锁浮标解锁后可拖动端点加厚，面内裁剪与后续裁空继续生效
- 3D 中活动选区三个轴都有厚度且旋转角为 `0°` 时，裁剪会提交一个覆盖全部 delay 帧的全局 ROI 数据域
- 坐标轴积分结果页上框选矩形并裁剪，生成裁剪后的结果页（`axis_integral_crop`），可用于限制 EDC 瀑布图的 k 值取值范围；生成 EDC 不要求先创建该裁剪页，直接在 E（Z）轴积分来源页框选即可

#### 折线路径切片

在 kx–ky 等能面或 E 积分动量图上，点击画布右上角的 **折线路径** 工具后左键逐点连线；双击节点原位改名，右键可选择 **生成路径切片**、**撤销上一点** 或 **清除所有选点**。路径草稿按来源页保留；关闭工具或按 `Esc` 会隐藏点、连线和标注但不删除草稿，重新开启工具即可恢复。生成后自动进入该来源下的 E–k 子页；选点与裁剪、裁空互斥。

- 横轴是沿折线累计的动量距离，纵轴使用来源体的有效能量范围；支持闭合路径、非均匀／倒序坐标、数据域、动量裁剪、旋转、去噪和时间切帧
- 底部路径条按真实段长显示完整路径。普通点击单选，`Shift` 点击跳选；厚度、黑灰白场和强度映射只修改选中段，多值字段只有用户改动后才写入
- **切片厚度** 是沿当前段法线对称展开的总宽度，`0` 为中心线；增厚后对有效样本取平均，越界样本不计入
- 长路径可用底条水平滑条移动 k 视口，底部概览始终保留整条路径；右键分别开关 **显示竖虚线** 与 **显示点名**
- 数值导出包含完整累计 k、E、原始强度与路径元数据；出版图按完整路径和当前标注生成；页面复制、数据源切换和 `.bsview.json` 复现均保留路径与分段参数

#### 裁空

在 **框选范围** 左侧次级栏点击 **裁空**，使用与裁剪相同的拖选方式，在范围窗口中输入活动选区范围后点击 **裁空**。操作只清空活动选区并生成新的结果页，选区内显示为空白，选区外的数据及原有坐标范围保留，其他选区草稿不变。支持 3D、2D、1D、比较曲线和瀑布图，可连续清空或继续裁剪；导出数据以 `NaN` 表示清空的采样点。再次点击次级按钮只收起窗口并保留草稿，裁剪和裁空操作模式互斥。

#### 全局 ROI 数据域

全局 ROI 用于将后续分析限制在感兴趣的三维空间范围内，适合费米面以下强带掩盖弱激发态等场景。

- 原始四维数据始终只读保留；每次新 ROI 都按照交互盒在原始 X/Y/E 索引中的绝对边界重新提取，不会相对上一个 ROI 继续裁剪
- ROI 只限制 X、Y、E，delay 轴保持完整
- 内部仅保存紧凑 ROI，不创建同尺寸的四维零背景副本
- 3D 使用带原始绝对索引 `extent` 的紧凑网格；2D/1D 在显示阶段嵌回完整坐标域，因此 ROI 外视觉强度为 0
- 时间积分、坐标轴积分、DOS、EDC、瀑布图和二阶导等后续计算只读取页面所属 ROI 与请求范围的交集
- 去噪和二阶导在紧凑 ROI 的局部边界内执行，避免把 ROI 外的虚拟零当成真实数据并在边缘制造伪峰
- 已存在的结果页固定使用创建时的数据范围；新页面继承直接来源页的数据范围。更换主页 ROI 不会修改旧页面
- 单层平面截取只生成临时 2D 视图，不会提交全局 ROI
- 非零旋转角下不能提交 ROI；ROI 页面需要旋转时，仅临时构造当前三维帧的零背景体，不创建全尺寸四维副本

### 2. 外观控制

右侧直接显示外观控制内容，可进一步调整显示效果：

- **视角**：只在左侧实际显示 3D 场景时平滑展开，切到 2D / 1D / 比较页 / 空结果时平滑收起。四个数值框与真实相机双向同步；恢复默认视角统一用画布右侧工具条上的 **重置视角** 按钮，卡片内不再重复该入口。默认视角和重置都会按 E 轴方向摆正：E 降序数据自动上下翻转，保证较小的 E 值在画面下方

  | 参数 | 含义 |
  |---|---|
  | 方位角 | 绕世界 +Z 轴（数据体 E 轴）的水平方位角，0° = 相机在 +Kx 一侧，+90° = 转到 +Ky 一侧，范围 -180° ~ 180° |
  | 仰角 | 相机相对 Kx-Ky 平面的仰角，0° = 平视，+90° = 从 +E 方向俯视（极点），范围 -90° ~ 90° |
  | 滚转角 | 画面绕视线方向的旋转角，0° = 画面向上对齐 E 轴，范围 -180° ~ 180° |
  | 距离 | 相机到观察中心的距离（渲染坐标单位，场景为 200×200×200 的立方体） |

  数值可直接键入（回车或失焦提交，等价角度自动折进规范区间），也可用 ↑↓ 或滚轮微调；鼠标旋转 / 滚转 / 缩放 / 平移后输入框跟随真实相机，平移过的观察中心会被保留
- 切换色带（33 种 colormap，含 magma / inferno / viridis / coolwarm / jet 等）
- 调整 **黑场** / **灰场** / **白场**（0-100 滑块，灰场对应 Gamma 校正，50 为线性映射）
- 右键任意可见色带（背景或增强区域）可复制/粘贴黑、灰、白场色阶；粘贴保留目标自己的强度范围、锁定与强度映射方式，不复制 colormap
- 切换强度映射方式：**线性** / **对数** / **幂函数** / **sigmoid**
- 三级去噪管线（每级可选 **None** 或以下六种方法，按顺序依次生效）：
  - **高斯平滑** — 按 Kx / Ky / E 轴分别设置高斯标准差，适合常规连续噪声平滑；单位为采样点，`0` 关闭对应轴
  - **中值滤波** — 按轴设置正奇数邻域尺寸，适合抑制脉冲噪声与孤立异常点并保留边缘；单位为采样点，`1` 关闭对应轴
  - **Savitzky-Golay滤波** — 沿所选轴做多项式平滑，适合尽量保留峰形与曲率；可调窗口长度、阶数和滑动轴
  - **小波去噪** — 按细节子带进行多级阈值收缩，适合分离不同尺度的噪声；可调小波基、分解层数、阈值规则、阈值模式、强度和噪声标准差
  - **非局部均值** — 利用相似空间块进行保结构去噪，适合具有重复或局部相似特征的谱图；可调块大小、搜索距离、滤波强度和噪声标准差
  - **低秩 SVD** — 对每个时间帧独立压缩 Kx×Ky 空间与能量构成的矩阵，适合抑制不集中于主要低秩结构的噪声；秩越小压缩越强但可能损失精细能带，秩越大保留的结构与噪声也越多
- 去噪参数跨页面共享。应用后当前页面立即刷新，其他页面在再次激活时按照各自的数据范围延迟计算；曲线比较页保持创建时的快照
- 应用前会按所有仍被页面引用的完整数据域或紧凑 ROI 预检方法与参数；任一数据域不兼容时整次应用会被拒绝并保留上一套结果
- 渲染插件卡片只在 3D 视图显示；分析插件（API 2）卡片也位于外观控制，但只在二维结果页显示。可提交的输入须为已完成的精确二维结果，卡片可提交、取消后台分析并由宿主新建一维结果页

### 3. 创建分析结果

在当前页的视图区域（3D 或 2D 画布）右键，选择「处理分析」即可生成对应分析结果。菜单每次按当前页页型、时间轴、已保存裁剪参数和已就绪插件动态过滤，只显示合法动作；打开菜单本身不会切换页面。切换到别的页面后菜单按新的当前页重新过滤；取消方向选择或创建失败时不新增页面。EDC 曲线不在此菜单中，需先在当前页建立选区，再点击「框选范围」次级栏的 **生成 EDC**。

每个生成的结果页独立管理，可关闭、可切换。生成结果后，使用顶部“截图样式”保存图像，或使用“导出结果”保存数据。

#### 3.1 时间轴区间

对 4D 数据的指定时间范围求和积分，**只更新当前视图，不生成独立时间积分页**。

- 时间双端合拢并锁定时显示单帧，拖动合并手柄或使用 ←/→、Shift+←/→ 逐帧浏览
- 点击锁浮标后分离端点，当前视图立即改为所选闭区间的时间积分；拖动时预览，释放或提交数值时精确刷新
- 分离端点后拖动任一胶囊即可改变区间，输入框已不再显示；端点弹窗使用真实延迟坐标
- 3D、2D、EDC、能级态密度、二阶导、路径切片和可重算的插件派生页都可直接调整；2D 空间区间与时间区间共同作用
- 每个页面独立保存自己的时间区间。完整时间曲线、插件曲线、对数与曲线对比页不显示时间区间控件

#### 3.2 画布坐标轴切片

在 3D 画布右上角点击 **XY、XZ、YZ**，分别沿 **E、Y、X** 轴积分。每次点击都在当前三维来源页下新建并打开独立结果页，同一方向可保留多个区间作比较；新页默认积分有效法向范围的中间一半（25%–75%）。切片使用来源页实际的当前帧、时间积分体、三维二阶导、裁剪与裁空结果，而不是绕过这些参数直接读取原始体。

画布底栏的双端区间条统一控制位置和厚度：

- 黑色胶囊是下端，白色胶囊是上端；拖到接触位置停止并自动锁定，重合手柄显示白壳黑芯与锁浮标
- 拖动中间线段保持长度平移，任一端触边时整段停止；锁定时拖动合并手柄可连续浏览单层
- 点击锁浮标播放开锁动画，端点先保持重合；随后向左拖黑端、向右拖白端，分开后再次相遇才重新锁定
- 悬停或拖动端点会显示可编辑坐标浮框，回车或失焦提交，`Esc` 撤销；锁定时编辑共同坐标会移动单层
- 拖动黑色／白色胶囊分别调整上下限与区间长度；拖动中点圆点整体平移，触边后整段移入有效范围；长度输入框不再显示
- 切片右上角 **3D** 返回创建它的三维来源页；重新打开切片会恢复它自己的精确端点和锁状态

切片及其二维二阶导继续使用 `axis_integral` 结果类型。开启「框选范围」后可框选面内矩形，并通过次级「裁剪」生成 `axis_integral_crop` 页，用于限制 EDC 瀑布图的 k 值范围；每个页面的多个框选草稿独立保留。E（Z）轴积分页无需先裁剪，也可直接用已有选区生成 EDC。

#### 3.3 处理分析菜单

在当前页的视图区域右键，选择「处理分析」中的对应动作：

| 菜单项 | 当前页页型与功能 |
|---|---|
| **切片内强度积分** | 数据含有效时间轴，且当前页为可形成有效 2D 来源的主页（含裁剪折叠及已有裁剪范围），或任意轴的坐标轴积分／矩形裁剪页；将切片范围内各时间采样的强度积分成时间曲线。静态数据不显示 |
| **能级态密度** | 主页，或 X/Y 轴的坐标轴积分／矩形裁剪页；按能量积分强度生成一维曲线。E 轴积分及其他结果页不显示 |
| **EDC 瀑布图** | 已安装、启用并成功加载 EDC 瀑布图插件，且当前页为无擦除区域的 X/Y 轴坐标轴积分／矩形裁剪页；按 k 步长选取动量采样并生成错位堆叠曲线。插件未就绪或其他页型不显示 |
| **二阶导** | 3D 主页、含能量轴的 X/Y 2D 主页，或 X/Y 轴坐标轴积分／矩形裁剪页；2D 来源沿能量轴锐化，3D 主页可选择 X、Y 或 E 方向。E 切片、E 积分及其他结果页不显示 |

非法动作会隐藏而不是置灰；当前页已删除、插件动作已失效或保存的动作键过旧时不会回退执行其他功能。新页仍挂在当前父页下，创建成功后自动展开祖先并选中新页。

## 结果工作区（左侧）

每个分析操作会生成一个新的结果页，显示在左侧页面树中（派生页挂在生成它的页面下，逐级展开）：

- **原始视图**（Home，不可关闭）— 初始数据显示页，可直接在单帧与时间积分之间调整
- **坐标轴积分 / 裁剪** — 2D 图像结果
- **切片内强度积分** — 1D 曲线（时间 vs 强度）
- **能级态密度** — 1D 曲线（能量 vs 强度）
- **EDC 瀑布图** — 堆叠曲线
- **EDC 曲线** — 单选区时为 1D 曲线（能量 vs 强度，`edc_curve`）
- **二阶导** — 2D 图像或 3D 体渲染结果
- **曲线比较** — 1D 多曲线叠加对比；多选区 EDC 直接生成同页比较（`curve_comparison_1d`）

每个结果页独立管理：

- 切换页面时自动保存 / 恢复该页面的显示、空间区间、时间区间和分析控件状态
- 每个页面持久保存自己的数据域编号；新派生页继承直接来源页的数据域
- 去噪参数全局共享，但去噪结果按页面数据域缓存并在需要时计算
- 曲线比较页是快照，不随之后的去噪或数据域调整重新计算
- 可关闭的页面点击 X 按钮删除
- 加载新数据时自动清除所有结果页，重置为原始视图

2D 图像的比例只由数据决定，不跟随窗口宽高比：

- **kx–ky 面**（沿能量轴切片或积分的 2D 结果）两轴同为动量，按物理坐标 1:1 显示，动量空间的圆保持为圆；窗口变宽只在图像两侧留白，图像不会被拉扁
- **含能量轴的图像**（X / Y 切片与积分）横纵单位不同，等比没有物理意义，继续铺满画布
- 色条是图像的子坐标系，始终紧贴图像右缘并与其等高；1D 曲线与瀑布图不受影响，仍铺满画布

## 曲线比较功能

支持将同类型的 1D 曲线（能级态密度、切片内强度积分、单条 EDC 曲线）进行叠加比较：

1. 在 1D 曲线结果页下按 `Ctrl + C` 复制当前曲线
2. 切换到另一个同类型 1D 曲线结果页，按 `Ctrl + V` 粘贴
3. 自动生成「比较」结果页，基准曲线与叠加曲线以不同颜色和线型区分，并显示图例

也可在 2D 曲线图上右键选择「复制」/「粘贴」。这种手动比较仍要求曲线类型和横轴采样匹配。

多选区来源点击 **生成 EDC** 时会自动把全部选区曲线放进同一个比较页，不需要逐条复制粘贴。此类 EDC 比较使用 `x_match_policy='per_curve'`，每条曲线保留自己的能量坐标与采样长度；特别是 3D 各盒的 E 范围不同，也不要求重采样到共同 E 轴。

## 去噪参数设置

点击右上角的齿轮按钮，在「数据处理 → 去噪参数」中编辑参数。三级去噪方法及其应用按钮位于右侧外观控制。

可调参数：

| 方法 | 参数 |
|---|---|
| 高斯平滑 | Kx / Ky / E 标准差（采样点，≥0，默认均为 1；`0` 关闭对应轴） |
| 中值滤波 | Kx / Ky / E 邻域尺寸（采样点，1–31 的正奇数，默认均为 3；`1` 关闭对应轴） |
| Savitzky-Golay滤波 | 滑动窗口长度（采样点，≥3 的奇数，且不超过当前数据域的实际滑动轴长度）、多项式阶数（无量纲，`0 ≤ polyorder ≤ min(4, window_length − 1)`）、窗口滑动轴（E / Kx / Ky） |
| 小波去噪 | 小波基（haar / db2 / db4 / sym4 / coif1）、分解层数（1–6，且不超过按当前数据域 `shape[:3]` 与所选小波基计算的 `dwtn_max_level`）、阈值规则（universal / SURE / Bayes）、阈值模式（soft / hard）、强度（无量纲，0-10）、噪声标准差（强度单位；`0` 为最细细节子带 MAD 自动估计，正值为手动指定） |
| 非局部均值 | 块大小（1–15 的正奇数采样点，默认 5）、搜索距离（1–20 的正整数采样点，默认 3）、滤波强度倍率（无量纲，默认 1.15）、噪声标准差（强度单位；默认 `0` 为自动估计，正值为手动指定） |
| 低秩 SVD | 秩（无量纲正整数，默认 3），每帧上限为 `min(Kx×Ky, E)`（Kx、Ky、E 取对应轴采样点数）；不跨时间帧混合信息 |

执行顺序固定为“提取页面数据域 → 在紧凑数据域内按三级顺序执行所选方法 → 原子提交结果”，静态 3D 与 `[Kx, Ky, E, T]` 4D 数据均可使用；逐帧方法只独立处理各时间帧。中值窗口与 NLM 块大小、搜索距离的上限是有意的桌面工作量限制，界面和直接计算 API 都执行同一范围检查，不能通过直接 API 绕过。SG 窗口超长时按实际滑动轴报错。小波会按每个被引用的完整数据域或紧凑 ROI 分别预检；请求层数超过可用上限，或该 ROI 的可用上限为 `0`，都会明确给出请求值与可用上限并拒绝整次应用，不再静默降层。小波的 Bayes / SURE 阈值按细节子带计算。非局部均值需要逐帧搜索相似块，计算与内存开销会随数据尺寸、块大小和搜索距离明显增加。旧复现文件中的“频域平滑”“滑动平均”“贝叶斯去噪”分别识别并迁移为“高斯平滑”“中值滤波”“非局部均值”，SG、小波的历史乱码名称也分别迁移到对应正名算法；这些别名只保证算法身份兼容。修正后的小波与非局部均值不承诺与旧版逐值一致，也不保留旧版数值分支。异步任务失败或被新任务取代时，界面继续显示上一套完整结果，不会出现半处理状态。

## 导出结果说明

### 截图

点击顶部工具栏的 **截图样式**，或按 `Ctrl + S`，预览并导出当前图像或曲线；3D 支持 PNG，2D 与 1D 还支持 PDF。

2D 和 3D 出图仍要求绘制轴为均匀网格。如果步长差异仅来自 `float32` 等低精度坐标的舍入，出版图和 Blender 导出可以继续，原坐标与强度不会被替换或重采样。

3D 截图的「微调」中可勾选 **三轴方向标**（默认关闭），在图像左下显示三轴箭头。三轴的具体倾角与投影长度随相机视角变化，只将横向轴的箭头选在右半边、竖向轴选在上半边、纵深轴选在朝观察者的一端；轴名按当前视角对应到 kx、ky、E，箭头不表示坐标递增方向。正对纵深轴时以圈点表示朝屏幕外。该选项按截图样式记忆，可独立于主视图的「坐标轴」开关开启。

方向标可在大图预览中直接拖动，也可用旁边的 **中心 X / 中心 Y** 精确设置位置（占整个图幅的百分比，X 向右增大，Y 向上增大）。拖动时数值同步，松手后预览和正式导出使用同一位置；「自动位置」恢复默认布局。方向标始终完整留在图幅内，关闭后重新开启仍保留手动位置。

2D / 3D 截图的色条也可在大图预览中拖动，刻度和标题随色条一起移动，并同步色条的 **中心 X / 中心 Y** 输入框（支持两位小数）。拖动不改变主图区位置，整组色条注记限制在图幅内，松手后重新生成预览，导出沿用相同位置。

当前源码默认勾选“同时保存复现文件”：导出 `figure.png` 时，同目录保存可编辑的 `figure.png.bsview.json`，记录有效处理链、相机、色阶、映射和出版设置，不包含原始 NPZ 路径。通过“加载数据”打开该文件时必须自行选择原始 NPZ；校验通过后新增一份数据源，恢复来源树和目标视图并保留已打开的分析。详见[视图复现文件说明](docs/development/view-recipes.md)。

### 数据导出

点击顶部工具栏的 **导出结果**，可选择导出为 `.mat` 或 `.npz`；支持表格化的结果还提供 `.txt` / `.csv` 格式。数据尚未就绪或当前页不支持数据导出时，按钮禁用。普通曲线比较页可截图，暂不导出叠加曲线数据；多选区 EDC 比较支持 MAT／NPZ 数值导出，按曲线分别保存能量轴、强度和来源元数据。

不同结果页导出不同结构的数据：

| 结果页类型 | 导出字段 |
|---|---|
| 完整数据主页 | `sample`、`kx`、`ky`、`E`、`time` |
| ROI 主页 | 紧凑 `sample`、ROI 对应的 `kx`、`ky`、`E`、完整 `time` |
| 坐标轴积分（X） | 当前视图二维 `sample`、`ky`、`E`、`integrated_axis`、`integrated_range`、`integrated_center`、`source_t_indices`、`source_t_range` |
| 坐标轴积分（Y） | 当前视图二维 `sample`、`kx`、`E` 及同样的空间／时间区间元数据 |
| 坐标轴积分（Z） | 当前视图二维 `sample`、`kx`、`ky` 及同样的空间／时间区间元数据 |
| 坐标轴积分裁剪 | `sample`、`k`/坐标标签、`E`/坐标标签、`integrated_axis`、`integrated_range`、`crop_range` |
| 切片内强度积分 | `time`、`intensity` |
| 能级态密度 | `E`、`intensity`（含 `time` 或 `time_range` 元数据） |
| EDC 瀑布图 | `k`、`E`、`intensity`、`integrated_axis`、`integrated_range` |
| 单选区 EDC 曲线 | `E`、`intensity`、`kx_range`、`ky_range`、`energy_range`、`source_t_index`、`source_t_indices`、`source_t_range` |
| 多选区 EDC 比较 | 第 N 条曲线分别导出 `E_N`、`intensity_N`，并以相同后缀保存 `kx_range_N`、`ky_range_N`、`energy_range_N` 及时间等可用元数据，例如 `E_1`、`intensity_1`、`E_2`、`intensity_2`；各曲线 E 轴可具有不同坐标与长度 |
| 二阶导（2D） | `sample`、`E`（含对应动量坐标标签） |
| 二阶导（3D） | `sample`、`kx`、`ky`、`E`、`derivative_axis`、`source_t_index`、`source_t_indices`、`source_t_range` |

ROI 来源页面还会写入 `data_scope_id`、`data_scope_label`、`roi_index_bounds` 和 `roi_physical_bounds` 元数据。页面专属的 2D 矩形裁剪会继续在该页面的数据域基础上裁剪。

## 性能与缓存

- 原始四维数组作为只读数据源保留，不因 ROI 切换而复制或覆盖
- ROI、去噪结果和派生计算均使用包含数据域签名的缓存键
- 处理结果缓存采用按字节计量的 LRU，上限为一个原始四维数组的大小
- 3D 零旋转 ROI 使用紧凑计算与紧凑 VTK 网格；只有非零旋转需要临时构造一个全尺寸三维体
- 计算任务异步执行，并采用“最新请求优先”的原子提交方式，避免旧任务覆盖新的页面状态
- 2D 坐标气泡和矩形拖选使用局部 blit，鼠标移动时不会重复重绘整张 Matplotlib 图
- NVIDIA CUDA 可用时可选择 GPU 后端；不可用或运行失败时会自动回退到 CPU

## 扩展（插件）

基础安装包**不包含**任何扩展，只提供通用扩展接口、扩展管理入口与渲染支持。官方扩展以 `.bsplugin` 包的形式与主程序一起发布在同一个 Release 里，CPU 与 NVIDIA 安装版共用同一个扩展包。

插件可提供三类能力：**渲染效果**（API 1，如平带增强）在 3D 视图里改变显示效果；**分析任务**（API 2）在已完成的二维结果上做后台数值计算，交回一维曲线，由主程序新建结果页，卡片位于外观控制且仅在二维结果页显示；**派生结果动作**（API 3，如 EDC 瀑布图）在视图右键的「处理分析」子菜单中出现，由宿主冻结来源、调用插件计算并新建结果页。处理分析菜单只对当前活动页提供合法动作。分析任务在后台线程运行，过程中界面仍可操作，结果挂在来源页下。

### 安装与卸载

1. 从本项目的 Release 下载与当前主程序版本匹配的扩展包。
2. 点顶部工具栏的齿轮按钮，选择「设置 → 应用管理 → 插件管理」，在内嵌管理页点「安装插件…」选择下载的文件。
3. 按提示重启 BandScope，扩展即可用。

卸载、启用 / 停用同样在「插件管理」里操作，也是重启后生效：确认后**当前会话的效果保持不变**，重启时才切换；页面里的状态列会写明待生效的操作（例如「运行中；待重启停用」）。插件加载失败时，页面提供「重试加载」与「恢复上一版本」。扩展安装在 `%LOCALAPPDATA%\BandScope\extensions`，与主程序安装目录分开存放，因此升级主程序不会影响已安装的扩展；主程序升级后不兼容的扩展会保留在磁盘上但停止加载，界面会说明需要安装兼容版本。

扩展不带自己的 NumPy / Qt / VTK / CUDA，全部复用主程序已有的运行环境，因此不额外占用磁盘，也不需要联网安装依赖。

### 来源与官方目录

「插件管理」内嵌页包含「已安装」「官方插件」「插件设置」三个页签：「已安装」管理本机插件，「官方插件」列出当前 Release 提供的签名目录，「插件设置」集中放置已加载插件提供的设置。目录里显示每个插件对本机主程序的兼容结论（可安装 / 可更新 / 不兼容及原因），安装与更新都由你确认后才下载。

官方发布的包带 Ed25519 签名，页面里显示「官方已验证」；本地自行导入的未签名包显示「本地未验证」，默认不安装，需要你明确确认。来源状态只说明包从哪里来，不改变插件行为。

> 当前仓库尚未配置发布签名密钥，因此本轮还没有可用的官方在线插件安装：发布工作流会在签名检查处失败，直到维护者按[构建与发布](docs/development/releasing.md)配置密钥与内置公钥。

### 平带增强（flat_band_opacity）

让指定的能带在 3D 体渲染里突出显示。在外观控制的「平带增强」卡片里：

- **添加平带**：条数由你决定，每条独立设置能量中心、厚度（高斯半高全宽）与增强量；
- **背景保留**：0%–100%，控制远离目标能量处的不透明度倍率；
- **总开关**：随时与原图比较，关闭时恢复原有渲染并完整保留参数；
- **重置显示参数**：恢复背景、增强量与厚度的建议值，保留已添加的数量与峰位；
- **导出 / 导入预设**：把整套条目参数存成 JSON；预设只记录单位信息，导入时不作隐含单位换算。

建议起始设置是背景保留 20%、每条增强量 0.8。对于分离良好的峰，中心倍率是 0.2 + 0.8 = 1，主要通过压低背景来突出能带；弱带再单独提高增强量即可。厚度初值按当前能量采样间距给出，只是可修改的建议，不是测得的线宽。

效果**只改变显示用的不透明度**：原始强度数组逐位不变，颜色映射、色阶（含色带锁定）、色条刻度、分析结果与所有数据导出的数值都不受影响。3D 截图与图片导出沿用同一效果。参数按页面独立保存，裁剪派生页拿到的是独立副本。

### EDC 瀑布图（edc_waterfall）

EDC 瀑布图由独立插件（API 3）提供：创建动作、采样、归一化与自动标题由插件注册或计算，绘图、裁剪、出版与数值导出仍由宿主完成。

- **创建入口**：插件就绪后，切到无擦除区域的 X/Y 轴积分页或其矩形裁剪页，在视图区域右键并选择「处理分析 → EDC瀑布图」；未安装、未启用、加载失败或当前页不合法时该项不出现。旧复现文件中的下拉选择不会触发创建，已有瀑布页与科学参数仍可恢复；
- **来源与时间状态**：创建时固定空间积分范围、矩形裁剪范围与数据域；新瀑布页继承来源页当前时间区间，之后可在本页独立调整并重算，不受来源页后续编辑影响；
- **插件设置**（「插件管理 → 插件设置」）：自动 / 手动 k 步长。「保存为新建默认值」写进本机设置，对之后新建的页面立即生效；「应用当前瀑布图」先按新参数试算一遍，通过后才更新当前瀑布页，其他页面保留各自参数。失败时保留上次成功结果并在图上标注；
- **坐标一致性**：插件的输入与结果都用原始坐标排列；E 轴翻转时屏幕、出版图和数值导出在同一个 E 坐标下给出同一强度；
- **参数隔离**：每页参数独立保存；用户改过页面名后，自动标题只更新底层默认名，不会覆盖显示名。

## 各分析功能的详细说明

### 1. 切片内强度积分

将用户设置的切片立方体内所有点按强度积分，横轴为时间，纵轴为总强度。

- 在含有效时间轴、可形成有效 2D 来源的主页，或任意轴坐标轴积分／矩形裁剪页的视图区域右键，选择「处理分析 → 切片内强度积分」
- 静态数据不显示该动作；没有有效切片范围时仍按原创建校验提示，不会生成空结果
- 可被画布底条上的「E轴翻转」开关调控
- 可被外观控制中的去噪设置调控

### 2. 能级态密度

将等能面内所有点按强度积分，横轴为能量，纵轴为总强度。

- 在主页或 X/Y 轴坐标轴积分／矩形裁剪页的视图区域右键，选择「处理分析 → 能级态密度」；E 轴积分及其他结果页不显示
- 从坐标轴积分结果页生成时，自动使用该积分页的积分范围和裁剪区域
- 可被画布底条上的时间轴滑条调控
- 可被画布底条上的「E轴翻转」开关调控
- 可被外观控制中的去噪设置调控

### 3. EDC 瀑布图

将坐标轴积分（仅限 Kx 或 Ky 轴积分）后的 2D 图像内按照步长选取一组动量值，画出这些动量值上的能量分布曲线（横轴为强度，纵轴为能量），曲线自动错位堆叠，并在底部标注对应动量值。本功能由 **EDC 瀑布图插件**提供（见「插件管理」一节）：插件未就绪或父页不合法时菜单里没有这一项。

- 在 YZ（沿 X 积分）或 XZ（沿 Y 积分）结果页及其无擦除区域的矩形裁剪页的视图区域右键，选择「处理分析 → EDC瀑布图」；创建后自动进入瀑布页
- 创建时固定空间积分范围、矩形裁剪范围与数据域；时间区间由瀑布页独立保存，可通过底条直接调整当前曲线族
- k 步长在「插件管理 → 插件设置」里设置：**自动**（按完整 k 轴的中位相邻间距）或**手动**（0.0001–10）
- 「保存为新建默认值」让之后新建的瀑布页立即使用该设置；「应用当前瀑布图」只更新当前打开的瀑布页，其他页面保留各自参数
- 带擦除区域的来源页不能创建瀑布图，请改用矩形裁剪后的二维结果
- 可被画布底条上的时间轴区间调控，每个瀑布页保存自己的时间范围
- 可被外观控制中的去噪设置调控

___开启画布右侧“框选范围”后，可用鼠标左键在 2D 视图内框选矩形区域，通过左侧次级“裁剪”打开浮层微调数值并生成裁剪结果页，用于限制 EDC 瀑布图 k 值的取值范围。___

### 4. 二阶导

用于生成强度的负二阶导锐化结果：

- 在 3D 主页、含能量轴的 X/Y 2D 主页，或 X/Y 轴坐标轴积分／矩形裁剪页的视图区域右键，选择「处理分析 → 二阶导」；E 切片、E 积分及其他结果页不显示
- 含能量轴的 2D 来源固定沿能量轴计算，生成 2D 图像
- 3D 主页会弹窗选择 X、Y 或 E 求导方向；程序沿所选方向处理当前时间范围的体数据并生成新的 3D 结果页，取消时不建页
- 3D 计算在数值上等价于对包含所选方向的所有 2D 切片逐一求导后重新堆叠
- X/Y 切片及其轴积分生成的 2D 二阶导页共用画布底栏的双端区间条，可移动单层，也可解锁加厚为区间积分
- 区间拖动使用合并预览刷新，释放端点或提交数值时立即完成精确刷新

- 可被画布底条上的时间轴滑条调控
- 可被画布底条上的「E轴翻转」开关调控
- 可被外观控制中的「输出色带」菜单调控
- 可被外观控制中的去噪设置调控

### 5. EDC 曲线与多选区比较

在当前页建立一个或多个选区后，点击画布右侧 **框选范围** 左侧次级栏的 **生成 EDC**。该动作读取当前页的全部选区，不再位于视图右键「处理分析」菜单，也不要求先裁剪出 `axis_integral_crop` 页。

- **3D 主页直接生成**：可在主页建立多个 3D 盒，每条曲线按对应盒的 X／Y／E 范围积分；不同盒可保留不同 E 范围和采样长度，无需先创建坐标轴积分页
- **2D 来源限制**：仅支持 E（Z）轴积分的 kx–ky 页面及其矩形裁剪页，在面内建立一个或多个 X／Y 选区后直接生成；沿用该积分来源的有效 E 范围，不支持从其他方向切片生成
- **单选区与多选区结果**：一个选区生成 `edc_curve` 单曲线页；多个选区生成一个 `curve_comparison_1d` 同页比较，`comparison_kind='edc_curve'`，而不是拆成多个结果页
- **逐曲线能量轴**：多选区比较采用 `x_match_policy='per_curve'`，各曲线保留自己的 E 坐标；MAT／NPZ 导出使用 `E_1`、`intensity_1`、`E_2`、`intensity_2` 等字段及对应后缀的来源元数据
- 结果冻结创建时的时间区间、数据域与去噪状态；E 轴翻转只改变显示方向，数值导出保留原始坐标排列

## 已知限制与说明

- 静态 3D 数据无法真实展示时间积分与切片内强度积分的动态能力
- README 中提到的样例路径仅用于说明截图来源，不要求用户按该绝对路径组织数据
- 非局部均值的去噪开销高于基础逐点或邻域滤波；处理大型 4D 数据时，可先缩小 ROI，或减小块大小与搜索距离以控制计算和内存占用
- 手动复制／粘贴的曲线比较仅支持同类型且横轴匹配的 1D 曲线，不支持跨类型比较；多选区自动生成的 EDC 比较例外，可按 `per_curve` 保留不同 E 轴
- 泵浦前绝对差分 `ΔI` 与零中心发散色带尚未加入当前版本
- 平带增强等渲染效果只作用于 3D 体渲染；切到 2D / 1D / 比较页时对应卡片收起、效果不参与，切回 3D 时原样恢复。API 2 分析卡片则在二维结果页显示，API 3 动作按当前页出现在视图右键「处理分析」中
- 开启扩展效果后，即使倍率恒为 1，画面与关闭效果时也不是逐位相同：VTK 对二分量体数据的采样与单分量不完全等价（实测平均亮度差在 20% 以内，集中在强度梯度大的位置）。这是渲染通道本身的差异，关闭效果会逐位还原原图
