# 平带增强（flat_band_opacity）

BandScope 官方扩展。自行添加需要突出的平带、分别设定能量中心与增强量，并淡化
远离目标能量的背景，让弱带在 3D 体渲染里看得见。

**只改变显示用的不透明度。** 原始强度数组逐位不变，颜色映射、色阶（含色带锁定）、
色条刻度、分析结果与所有数据导出的数值都不受影响。

## 安装

1. 从 BandScope 的 Release 页面下载与本机主程序版本匹配的
   `BandScope-flat_band_opacity-<版本>.bsplugin`。
2. 点顶部工具栏的「插件管理」，在窗口里点「安装插件…」选择下载的文件。
3. 按提示重启 BandScope。重启后在「渲染控制」页会出现「平带增强」卡片。

CPU 与 NVIDIA 安装版共用同一个扩展包。扩展不带自己的 NumPy / Qt / VTK / CUDA，
全部复用主程序已有的运行环境。

卸载：插件管理里点「卸载」，同样重启后生效；重启前当前效果保持不变。

官方发布的包带有 `.bsplugin.sig` 签名，插件管理里会显示「官方已验证」；本地自行
导入的未签名包会显示「本地未验证」，需要你确认后才会安装。来源状态只说明包从哪
来，不影响插件行为。

当前版本 1.2.0：功能与 1.0.1 相同，兼容声明由「要求主程序 `1.11.2` 精确匹配」放宽为
`>=1.9.0,<2.0.0`——2.0.0 以前的主程序都在声明范围内。范围写法由 1.12.1 起的插件管理
解析，更早的主程序只认精确版本号，请配合 1.12.1 及以上的主程序安装本包。

## 使用

卡片只在左侧显示 3D 场景时出现；切到 2D / 1D / 比较页时收起，切回来参数原样恢复。

| 控件 | 作用 |
|---|---|
| 平带增强（总开关） | 关闭时绕过插件效果、恢复原有渲染，参数全部保留，随时与原图比较 |
| 添加平带 | 增加一条独立参数；条数由你决定 |
| 中心 | 该条能带的能量位置，与坐标轴同单位。新增条目留空，填写有效值后自动启用该行 |
| 厚度 | 覆盖范围，用高斯半高全宽（FWHM）表示，中心 ± 厚度/2 处的增强量是峰值的一半 |
| 增强 | 该条在中心处额外增加的不透明度倍率，0–5，各条独立 |
| × | 删除这条；其他条目的参数不受影响 |
| 背景保留 | 0%–100%。远离所有目标能量处的不透明度倍率；100% 表示不淡化背景 |
| 重置显示参数 | 恢复背景、增强量和厚度的建议值，保留已添加的数量与峰位 |
| 导出 / 导入预设 | 把整套条目参数存成 JSON 或读回来；带单位信息，不做隐含单位换算 |

建议起始设置：背景保留 20%、每条增强量 0.8。对于分离良好的峰，中心倍率是
0.2 + 0.8 = 1，主要通过压低背景来突出能带；弱带继续单独提高增强量即可。
新增条目的厚度初值按当前能量采样间距给出，只是可修改的建议，不是测得的线宽。

## 透明度模型

设用户添加 N 条能带，S 是其中已启用且参数有效的条目，第 i 条的中心为 E_i、
半高全宽为 w_i、增强量为 a_i：

```text
G_i(E) = exp[-4 ln(2) ((E - E_i) / w_i)^2]
m(E)   = b + max_i a_i G_i(E)
alpha  = clip(alpha_base * m(E), 0, 1)
```

`b` 是背景保留比例，`alpha_base` 是原有色阶与透明度映射给出的基础不透明度。
用最大值合并而不是相加：重叠或重复的条目不会在交叠处异常增厚。没有任何条目
启用时直接走原有渲染路径，不单独淡化整幅背景。

倍率定义在**完整**能量轴上：缩小 ROI 只做截取，不会把权重重新拉伸；预览降采样
时数据与权重使用同一组索引。E 轴翻转按当前显示坐标解释峰位，换算到体素由主程序
负责，插件不翻转数据。

## 已知差异

开启效果后，即使倍率恒为 1，画面与关闭效果时也不是逐位相同：VTK 对二分量体数据
的采样与单分量不完全等价，实测平均亮度差在 20% 以内，且集中在强度梯度大的位置。
这是渲染通道本身的差异，无法用参数消除；关闭效果会逐位还原原图。

体渲染的不透明度沿视线累积，能量方向上的差异才因此可见；如果某些设置下背景
压低得不明显，先确认当前 3D 视图的强度映射（强度映射方式）没有让整体过早饱和。

## 开发说明

- 协议使用 `bandscope.extensions.api`；主题与共享控件通过
  `bandscope.extensions.ui` 导入，这些依赖由宿主提供。
- 打包：`python scripts/release/build_plugin.py flat_band_opacity`，产物在 `release/`。
  清单里的 `requires_app` 必须覆盖当前主程序版本：裸版本按精确匹配，带运算符按
  PEP 440 范围解析，不通过构建会直接失败。
- 业务测试在 `tests/plugins/flat_band_opacity/`；宿主测试在 `tests/extensions/`。
  从仓库根目录运行 `python -m unittest discover -s tests -t . -v`。
